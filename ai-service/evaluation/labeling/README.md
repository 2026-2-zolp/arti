# 🏷️ 팀 태그 라벨링 (정답 만들기)

캡처 40점의 "정답 태그"를 팀원 여러 명의 **다수결**로 만드는 도구입니다.
지금 정답은 개발자 1명이 정한 것이라 「부드러운 색감」, 「빛」처럼 사람마다 갈리는 태그는 근거가 약해요.

## 팀원이 할 일 (약 40분)

1. 배포 ZIP(`ARTI-라벨링.zip`)을 받아 압축을 풀어요. 저장소가 있다면 이 폴더를 그대로 써도 돼요.
2. `labeling/라벨링.html`을 더블클릭하면 크롬이나 엣지로 열려요. 인터넷이 필요 없어요.
3. 이름을 넣고 **「본 라벨링 40점」**을 눌러요.
4. 그림마다 해당하는 태그를 모두 켜고, 그중 **대표 태그 1개**를 골라요.
5. 끝나면 **「CSV 내려받기」** → `labels_<이름>.csv`를 김광권에게 보내요.

> 혼자서, AI 결과를 보지 않고 붙여 주세요. 작품 제목도 판단에 영향을 줄 수 있어서 번호만 보여요.
> 사람마다 그림 순서가 다르게 섞여 나와요.

## 회의 진행 (약 2시간)

| 시간 | 단계 | 내용 |
|---|---|---|
| 0:00 | 1. 기준 맞추기 | 다 같이 **「연습 5점」**을 보며 태그마다 어디부터 O인지 정해요. 화면의 기준표를 바꾸기로 했다면 메모해 두세요. |
| 0:30 | 2. 따로 붙이기 | 각자 **「본 라벨링 40점」**을 해요. 말하지 않아요. |
| 1:10 | 3. 합치기 | CSV를 모아 아래 집계를 실행해요 (휴식). |
| 1:20 | 4. 갈린 그림 다시 보기 | `results/team_tags_disagreements.csv`의 **대표 태그가 갈린 그림**만 다시 봐요. 소수 의견이 이유를 30초 말하고 재투표해요. 바꾼 사람은 라벨링 화면에서 고쳐 CSV를 다시 내려받아요. |
| 1:50 | 5. 정리 | `--apply`로 정답을 확정해요. |

## 집계 (김광권)

```powershell
# CSV들을 ai-service/evaluation/labeling/responses/ 에 넣은 뒤, ai-service 폴더에서
python -m evaluation.team_tags            # 일치도 + 다수결 결과 + 갈린 칸 목록 (정답 파일은 그대로)
python -m evaluation.team_tags --apply    # 다수결 정답으로 tag_eval_set.json 교체 (예전 정답은 primaryDev·expectedDev로 보관)
```

- `results/team_tags_report.md`: 태그별 **Fleiss' kappa**(사람끼리 일치도, 0.6 이상이면 꽤 일치), 기존 정답과 달라진 작품
- `results/team_tags_disagreements.csv`: 의견이 갈린 칸 (4단계 회의 목록)
- 다수결 규칙: 절반이 넘게 O면 O예요. 동점(짝수 인원)이면 기존 정답을 따르고 목록에 표시해요.

## 그다음 (Claude에게 맡기기)

`--apply`까지 한 뒤(또는 CSV만 push한 뒤) 요청하면 새 정답으로 다음을 다시 해요.

1. 캡처 40점 정확도를 다시 계산해요 (`ai_validation.ipynb` 1-8, 교차검증 포함).
2. 태그별 기준값(`app/tag_calibration.json`)을 다시 정해요. 교차검증에서 나아진 태그에만 적용해요.
3. 사람끼리도 갈리는 태그(kappa가 낮은 태그)는 AI 목표를 "사람끼리의 일치도만큼"으로 잡아요. 필요하면 CLIP 문장(`app/tags.py`)을 고치거나, 태그 정의 자체를 바꾸자고 제안해요.
4. 문서와 노트북의 숫자를 갱신해요.
