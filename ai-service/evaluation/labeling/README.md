# 🏷️ 팀 태그 라벨링 (정답 만들기)

캡처 40점의 "정답 태그"를 팀원 여러 명의 **다수결**로 만드는 도구입니다.
지금 정답은 개발자 1명이 정한 것이라 「부드러운 색감」, 「빛」처럼 사람마다 갈리는 태그는 근거가 약해요.

## 팀원이 할 일 (약 40분)

1. 배포 ZIP(`ARTI-labeling.zip`)을 받아 압축을 풀어요. 저장소가 있다면 이 폴더를 그대로 써도 돼요.
2. `labeling/labeling.html`을 더블클릭하면 크롬이나 엣지로 열려요. 인터넷이 필요 없어요.
3. 이름을 넣고 **「본 라벨링 40점」**을 눌러요.
4. 그림마다 해당하는 태그를 모두 켜고, 그중 **대표 태그 1개**를 골라요.
5. 끝나면 **「CSV 내려받기」** → `labels_<이름>.csv`를 김광권에게 보내요.

> 혼자서, AI 결과를 보지 않고 붙여 주세요. 작품 제목도 판단에 영향을 줄 수 있어서 번호만 보여요.
> 사람마다 그림 순서가 다르게 섞여 나와요.

## 📱 구글 폼으로 하기 (폰에서 링크로 바로)

`labeling.html`은 다운로드해야 해서 폰에서 하기 불편해요. 구글 폼으로 만들면 팀원은 **링크만 누르면** 돼요.
폼은 `make_google_form.gs`를 한 번 실행하면 자동으로 만들어져요. 그림 40장, 질문 160개를 직접 만들 필요가 없어요.

**만드는 사람 (김광권, PC에서 5분)**
1. 구글 드라이브에 새 폴더(예: `ARTI-라벨링-그림`)를 만들고 `images/01.jpg ~ 40.jpg`를 올려요.
2. 그 폴더를 열면 주소창이 `https://drive.google.com/drive/folders/1AbC...` 모양이에요. 마지막 `1AbC...` 부분을 복사해요.
3. https://script.google.com → **새 프로젝트** → 기존 내용을 지우고 `make_google_form.gs` 내용을 통째로 붙여 넣어요.
4. 맨 위 `FOLDER_ID = '여기에_드라이브_폴더_ID'`의 따옴표 안에 2번에서 복사한 값을 넣어요.
5. 위쪽 함수 선택에서 `makeForm`을 고르고 **▶ 실행** → 「권한 검토」 → 내 계정 → 「고급」 → 「안전하지 않은 페이지로 이동」 → 허용해요. 내가 만든 스크립트라서 이 경고가 나와요.
6. 아래 **실행 로그**의 「응답 주소」를 팀원 단톡방에 보내요.

**팀원:** 링크 열기 → 이름 → 그림마다 「해당하는 태그」 여러 개 + 「대표 태그」 1개 → 제출. 제출한 뒤에도 응답을 고칠 수 있어요.

**모은 뒤:** 응답 시트 → 파일 → 다운로드 → **쉼표로 구분된 값(.csv)** → 파일 이름은 그대로 두고 `responses/` 폴더에 넣어요. 집계 명령은 아래와 같아요.

| | labeling.html | 구글 폼 |
|---|---|---|
| 폰에서 | 불편 (다운로드, 압축 풀기) | **링크로 바로** |
| 그림 순서 | 사람마다 다르게 섞임 | 모두 같은 순서 (같은 태그가 몰리지 않게 미리 섞음) |
| 결과 모으기 | 사람마다 CSV 보내기 | 시트에 자동으로 쌓임 → CSV 한 번 다운로드 |
| 대표 태그 확인 | 고른 태그 중에서만 고를 수 있음 | 아무거나 고를 수 있음 (집계할 때 대표 태그를 해당 태그에 자동으로 넣음) |

## 회의 진행 (약 2시간)

| 시간 | 단계 | 내용 |
|---|---|---|
| 0:00 | 1. 기준 맞추기 | 다 같이 **「연습 5점」**을 보며 태그마다 어디부터 O인지 정해요. 화면의 기준표를 바꾸기로 했다면 메모해 두세요. |
| 0:30 | 2. 따로 붙이기 | 각자 **「본 라벨링 40점」**을 해요. 말하지 않아요. |
| 1:10 | 3. 합치기 | CSV를 모아 아래 집계를 실행해요 (휴식). |
| 1:20 | 4. 갈린 그림 다시 보기 | `results/team_tags_disagreements.csv`의 **대표 태그가 갈린 그림**만 다시 봐요. 소수 의견이 이유를 30초 말하고 재투표해요. 바꾼 사람은 라벨링 화면에서 고쳐 CSV를 다시 내려받아요. |
| 1:50 | 5. 정리 | `--apply`로 정답을 확정해요. |

## 집계 (김광권)

```powershell
# CSV들(labels_이름.csv 또는 구글 폼 응답 CSV)을 ai-service/evaluation/labeling/responses/ 에 넣은 뒤, ai-service 폴더에서
python -m evaluation.team_tags            # 일치도 + 다수결 결과 + 갈린 칸 목록 (정답 파일은 그대로)
python -m evaluation.team_tags --apply    # 다수결 정답으로 tag_eval_set.json 교체 (예전 정답은 primaryDev·expectedDev로 보관)
```

- `results/team_tags_report.md`: 태그별 **Fleiss' kappa**(사람끼리 일치도, 0.6 이상이면 꽤 일치), 기존 정답과 달라진 작품
- `results/team_tags_disagreements.csv`: 의견이 갈린 칸 (4단계 회의 목록)
- 다수결 규칙: 절반이 넘게 O면 O예요. 동점(짝수 인원)이면 기존 정답을 따르고 목록에 표시해요.

## 그다음 (Claude에게 맡기기)

`--apply`까지 한 뒤(또는 CSV만 push한 뒤) 요청하면 새 정답으로 다음을 다시 해요.

1. 캡처 40점 정확도를 다시 계산해요 (`ai_validation.ipynb` 1-8, 교차검증 포함).
2. 태그별 기준값(`app/tag_calibration.json`)을 다시 정해요. 교차검증에서 나아진 태그에만 적용해요.
3. 사람끼리도 갈리는 태그(kappa가 낮은 태그)는 AI 목표를 "사람끼리의 일치도만큼"으로 잡아요. 필요하면 CLIP 문장(`app/tags.py`)을 고치거나, 태그 정의 자체를 바꾸자고 제안해요.
4. 문서와 노트북의 숫자를 갱신해요.
