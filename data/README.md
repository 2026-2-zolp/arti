# 작품 데이터 관리

실제 데이터를 넣기 전에 다음 사항을 기록해 주세요.

1. **출처**: 소장처/전시 공식 페이지/원본 URL, 확인 일자
2. **전시 소속**: 실제 전시 출품 여부를 별도로 확인 (소장품 정보만으로 확정하지 않음)
3. **이미지 사용권**: 다운로드 및 재배포 가능 여부 확인
4. **해설**: 공식 설명 / 팀 정리 / AI 생성 해석을 구분
5. **배치**: 실제 좌표 / 화면 시연용 가상 좌표를 구분
6. **검수**: `unverified`, `reviewing`, `verified` 등의 상태를 기록

처음에는 작품 3~5점으로 ID와 데이터 흐름을 검증합니다. **실제 작품을 조사하기 전 샘플을 사실처럼 채우지 않습니다.**
