# 유영국16점 식별·출처표

2026-11-09 / 기준4a9dbe9 / W06 AC18·AC19 관련 인수 조사. 유영국 유지 결정에 따라 작성했다. **조사표 작성 완료와 작품 승인·실제 전시 인수 완료는 다르다. 전체16점의 사람 검수·이미지 이용 조건은 아직 대기다.**

[기계 판독 인수표](inventory.json)는 현행 importer 입력이 아니다. 원본 ZIP/이미지/설명 전체는 Git에 넣지 않았다. 공식 페이지를 직접 확인한 메타데이터, 비교 이미지URL·해시, 전달 파일명·해시·크기와 대기 사항을 담았다. 원문 보관 위치는 이전 조사 기록을 따른다. inventory.json의 metadataEvidenceRef/comparisonImageEvidenceRef/originalImageEvidenceRef는 Git 제외 로컬 근거의 저장소 상대경로다. 해시 재검수용이며 새 체크아웃에서 파일 존재를 보장하지 않는다. 메타데이터만으로 이미지를 재배포하지 않는다.

## 판정 기준

- 개별 소장품 후보 대응9점: 공식 이미지와 구도가 대응하며 작품별 소장품 페이지를 확보. 진위 감정·사람 승인·사용 허락을 뜻하지 않는다.

- 캡션 대응2점: 공식 전시 이미지/캡션 대응. 재료·치수·독립 작품번호는 미확정.

- 도상 대응4점: 판화의 같은 도상 후보 확보. 다수 판본 중 해당 파일의 개별 판본/에디션은 미확정. 후보 페이지 치수를 전달 이미지의 확정값으로 사용하지 않는다.

- 식별 미해결1점:07번. 파일명상의 제목/연도 외에 공식 개별 식별 근거를 확보하지 못했다.

## 안정된 식별자와 전시 연결

recordId는 이번 인수 항목,assetId는 원본 파일 관리용 식별자다. 제목/연도/파일명을 바꿔도 재발급하지 않는다. 같아 보이는 작품을 자동 병합하지 않는다. linkedArtworkId는 전부null이며 DB 적재 시 별도 매핑한다. 파일 해시는 원본 무결성 확인용이며 작품 동일성의 고유키가 아니다.

exhibitionAssignments는 전부 빈 배열이다. 실제/시연 전시 선택 후 출품 근거와 방/배치 근거를 분리해 연결한다. 소장처는 전시관과 같지 않으며 현재 소장품 이미지가 존재한다고 특정 전시 출품이 증명되지 않는다. 나중에 여러 전시에서 재사용할 수 있도록 인수 원본을 한 전시ID에 종속시키지 않았다.

현행DB/API와 확장 경계는 [전시·작품 확장 방향](../../../docs/operations/전시작품확장방향.md)을 따른다. 이 인수표는 장래 DB/API 계약을 확정하거나 migration을 실행하지 않는다.
