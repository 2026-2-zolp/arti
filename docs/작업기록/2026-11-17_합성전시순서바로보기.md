# 합성 전시에서 전시 순서로 바로 보기

기준은 main `63aafe8`이다. 전시 첫 화면에서 한 번 눌러 첫 작품을 여는 흐름을 `fixture-ex01`에 적용했다. 개발·시험 환경에서 합성 자료와 직접 관람 옵션을 모두 허용할 때만 표시한다. 순서는 `fixture-art03 → fixture-art01 → fixture-art05`다.

- 공개 작품만 시작 목록에 넣고 좌표가 없는 공개 작품도 포함한다. 관람 시작 후에는 해당 순서를 탭 세션에 보관한다. 도중에 작품이 비공개되면 안내 후 건너뛸 수 있다. 감상 완료 처리와 작품 정보를 기존 영수증 경로에서 재사용한다.
- 직접 관람은 별도 취향·시간 선택 없이 시작한다. 영수증은 `visitMode=exhibition_order`, `selectedDuration=null`로 저장하며 실제 관람 시간을 표시한다. 재시도할 때 기존 기록의 관람 방식도 일치하는지 확인한다. 선택 시간을 담은 기존 영수증 형식은 계속 처리한다.
- 같은 전시의 ‘내 취향으로 추천’은 기존 로그인 선택과 V2 취향 흐름으로 연결한다. 운영자가 실제 전시의 순서를 편집하는 화면과 정식 순서 저장 API는 후속 범위다.

## 검수 결과

- 합성 PostgreSQL 17과 360px PC Chrome에서 한 번에 첫 작품 진입, 전시 첫 화면의 이어서 관람, 앱·브라우저 뒤로가기, 앞으로가기, 새로고침을 확인했다. 같은 관람 ID와 이미 본 작품이 유지됐다.
- DB에서 두 번째 작품을 비공개로 바꾸자 신규 진입 목록에서 제외됐다. 진행 중인 관람에서는 안내 뒤 세 번째 작품으로 갔고 영수증에는 03·05만 남았다.
- 회원의 첫 저장은 서버에서 201을 받은 뒤 Chrome에 전달되기 전에 끊었다. 다시 저장과 새로고침은 200이었고 동일한 영수증 ID 한 건만 남았다. 비회원은 새로고침 뒤에도 `POST /api/visits` 0건이었다.
- 같은 전시에서 V2 5쌍 선택 이후 30분 추천 3점을 확인했다. 직접 관람 옵션을 끈 기존 Chrome 검수에서 원 계정 만료 복구 1건, 다른 계정 저장 0건, 조사풀·지도 변경 후 비공개 건너뛰기도 통과했다.
- 프런트 빌드와 단위 검사 47건, Django PostgreSQL 기초·통합 검사 61건, 마이그레이션 변경 없음 확인을 마쳤다. 외부 모델 연결은 비활성화했고 실기기는 보류했다.

## 재현

1. 다른 검수와 분리된 루프백 PostgreSQL에 `arti_visit_boundaries_order` DB를 만들고 `PGHOST`, `PGPORT`, `PGDATABASE`, `PGUSER`, `PGPASSWORD`를 지정한다. `MEDIA_ROOT`도 별도 경로로 지정한다.
2. `ARTI_ENV=test`, `ALLOW_TEST_FIXTURES=true`, `ARTI_EXHIBITION_ORDER_DEMO_ENABLED=true`, `ARTI_TASTE_PROFILE_V2_ENABLED=true`를 설정한다. `ARTI_LLM_PROVIDER=disabled`로 두고 `ARTI_MODEL_SERVICE_URL`은 비운다. `ARTI_TEST_PYTHON`에 Django 가상환경의 Python, `ARTI_BOOTSTRAP_PASSWORD`에 합성 시험용 비밀번호를 지정한다. 운영 키가 든 환경 파일은 이 실행에 사용하지 않는다.
3. 해당 Python으로 `backend-django/manage.py migrate --noinput`, `backend-django/manage.py load_test_fixture`를 실행한다. 기존 전체 관람 회귀도 실행할 경우 `backend-django/manage.py bootstrap_admin --login-id visit-boundaries-admin --name 'Synthetic administrator'`로 합성 관리자를 생성한다.
4. `VITE_API_TARGET=django`, `VITE_API_BASE=/api`로 프런트를 빌드한 다음 저장소 루트에서 `node frontend/tests/runVisitBoundaries.browser.mjs exhibition-order`를 실행한다. 별도 경로로 빌드했다면 `ARTI_BROWSER_DIST`로 지정한다. 실행기가 Django·프리뷰를 루프백에 시작하고 종료한다.
5. 기존 관람 회귀는 직접 관람 옵션을 `false`로 바꾸고 `node frontend/tests/runVisitBoundaries.browser.mjs`를 실행한다.
