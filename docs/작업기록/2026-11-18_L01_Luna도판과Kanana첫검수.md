- `dev/임준억` `6c54e57` 기준으로 L01 v1 원문과 640×480 합성 도판의 SHA-256을 확인했다. 별도 합성 전시의 `fixture-art03`을 사용했다. 기존 확정 요약·가이드를 먼저 저장한 뒤 원문 버전을 고정했다. [원문·도판 manifest](../review/docent-2026-11-15/luna-fixtures/manifest.json)
- Luna는 같은 OpenAI 모델과 키로 A-04의 요약·가이드 각각 원문만, 원문+도판을 1회씩 실행했다. 도판 조건에서는 현재 ARTI의 도판 전용 안내 문구도 포함됐다. 지연은 브라우저에서 A-04 생성 버튼을 누른 시각부터 응답까지다. 조건별 한 번의 측정값이다.

## Kanana WSL 첫 요청

Ubuntu WSL의 전용 가상환경에 Python 3.12.3, Torch `2.8.0+cpu`, Transformers `4.57.3`을 사용했다. `kakaocorp/kanana-2-3b-instruct@6a5d788`의 공식 가중치 두 파일 약 7.02GB를 공식 SHA-256과 각각 대조했다. CPU 6스레드·BF16에서 ARTI 요약 프롬프트와 L01 원문·메타데이터로 로컬 루프백에 첫 요청을 보냈다. 출력 상한은 180토큰이며 생성은 샘플링 없이 진행했다. [Kanana 공식 고정 리비전](https://huggingface.co/kakaocorp/kanana-2-3b-instruct/commit/6a5d7889964c4c590299d16e309eabab1f73f8a9)

| 작업 | HTTP와 형식 | 모델 로딩 | 첫 토큰 | 전체 요청 | 입력 / 출력 토큰 | 최대 RSS |
| --- | --- | ---: | ---: | ---: | ---: | ---: |
| 원문 요약 | 200, 요약·키워드 JSON 통과 | 0.782초 | 8.262초 | 26.066초 | 302 / 45 | 6,560.4 MiB |

파란 바탕, 노란 원, 흰 여백, 빨간 선을 한 문장에 담았고 근거 밖의 형태나 작가 의도는 추가하지 않았다. 노란 원의 **왼쪽 위** 위치는 빠졌고 키워드는 추상적이었다. 실제 생성은 WSL의 시험용 루프백 서버에서 실행했다. 첫 전체 요청이 현재 ARTI 텍스트 연결의 25초 제한을 넘었다. A-04 운영 경로에 연결하기 전에 토크나이저 정규식·RoPE 경고를 확인하고 같은 설정으로 반복 지연과 JSON 형식을 대조한다. [ARTI 타임아웃 설정](../../backend-django/arti/llm.py)

공식 가중치·가상환경은 WSL `~/.local/share/arti-kanana-1118/`에, 로컬 첫 요청 실행기와 결과는 Git 제외 `data/private/arti-kanana-1118/first-request.py`, `kanana-first.json`에 보존했다. 첫 요청이 끝난 뒤 루프백 서버는 종료됐다.
