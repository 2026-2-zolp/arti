# A-05 저장 전 경로와 Luna 평가 준비

- 기준은 PR #50의 `a316d86`이다. A-05 **이동 구조 등록**에서 입구나 위치가 등록된 작품을 출발점으로, 다른 작품을 도착점으로 고른다. 편집 중인 지도에 U-09와 같은 경로 계산을 사용한다. 관람 가능 공간이 비어 있거나 문·통로·연결점을 통해 도착할 수 없으면 안내를 표시하고 이동선을 비운다.
- 출발·도착 선택은 같은 작품을 두 점으로 고르는 것을 막는다. 두 선택기의 접근성 이름은 연결된 레이블로 제공한다. 기존 지도 위에서 형상을 추가하거나 마지막 형상을 취소하면 미리보기도 갱신된다.
- 합성 PostgreSQL과 PC Chrome에서 기둥 우회, 두 실의 문·복도 통과, 마지막 문을 취소했을 때 선 제거와 문을 다시 그린 뒤 복귀를 확인했다. 선이 벽이나 기둥을 가로지르지 않는지 SVG에서 확인했다.
- 관리자가 도면을 그리고 미리 보는 동안 이동 구조 저장 요청은 **0건**이었다. 같은 관람 탭을 새로고침해도 지도와 전시 API 응답이 같았고, V2 추천 3·5·7점의 작품·순서도 같았다.
- 저장 요청 **1건** 뒤 관람자 탭을 다시 열어 같은 문·복도 구조와 이동선을 확인했다. 관람 시간별로 새로 요청한 V2 **3·5·7점은 작품 ID·점수·태그·추천 이유가 같았고 순서가 다시 계산**됐다. 관리자 지도 새로고침 뒤에도 저장 구조가 표시됐다.
- 프런트 빌드·단위 검사 50건과 Django 도면·Luna 모의 회귀 12건을 통과했다. 기존 지도 Chrome 검수에 편집→미리보기→저장→공개 지도·추천 대조를 추가했다. 같은 합성 환경에서 직접 관람 회귀도 실행했다.
- Luna의 원문·도판 비교에 사용할 합성 사례, 원문·파일 버전 기록 방식, 채점 기준과 회신표를 작성했다. 평가 점수는 실제 비교 후 채운다. [Luna 비교 평가표](../review/docent-2026-11-15/Luna_원문과도판_비교평가표.md)
