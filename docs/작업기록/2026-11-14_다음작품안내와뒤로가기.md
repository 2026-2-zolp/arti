# 11/14 다음 작품 안내와 뒤로가기 점검

- **재현** · `cd2a1c5`에서 추천 → 지도 → 첫 작품 → 지도 보기 → 감상 복귀 → 다음 작품 안내 순으로 이동했다. 브라우저 앞으로가기를 누르면 이전 작품에서 열었던 지도가 다시 나타났다. 작품 화면에서 지도를 새 기록으로 열고 감상 복귀는 뒤로 이동했기 때문에, 다음 작품 안내가 현재 기록을 교체해도 지도 기록은 앞으로가기에 남았다.
- **수정** · 작품에서 연 지도와 현재 감상을 같은 브라우저 기록에 표시한다. 지도 안의 뒤로가기와 감상 복귀 버튼은 현재 작품으로 돌아간다. 추천에서 시작했으면 브라우저 뒤로가기는 추천으로 돌아간다. 새로고침한 지도에서 감상 복귀 동작을 복원하고, 일반 다음 작품 안내는 저장된 관람 진행 순서를 따른다. 작품 화면 왼쪽 뒤로가기는 동일 작품을 가리키는 전체 지도를 연다.
- **자체 검수** · 프론트 40건과 프로덕션 빌드 통과. PC Chrome 합성 브라우저 검사 5개 조건을 통과했다. 지도 새로고침 뒤 앱·브라우저 뒤로가기, 앞으로가기, 2·3번 안내 새로고침, 추천 재진입 후 같은 진행 순서, 회원 3점 영수증 한 건, 비회원 3점 관람, 시작 전·도중 영수증 접근 차단을 확인했다. `frontend/tests/visitCompletion.browser.cjs`로 재현할 수 있다. 실기기 검증은 보류다.
