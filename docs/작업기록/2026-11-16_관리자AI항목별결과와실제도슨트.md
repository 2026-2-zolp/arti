# 11/16 관리자 AI 항목별 결과와 실제 도슨트 검수

감정 분석 모델을 연결하지 않은 환경에서는 쉬운 요약과 관람가이드 생성이 성공해도 관리자 화면에 전체 ‘AI 분석 실패’가 떴다. 작품 상세의 결과를 쉬운 요약·관람가이드·취향 태그·감정 분석 네 항목으로 표시한다. 분석 요청이 실패한 경우의 재시도와 409의 최신 자료 다시 불러오기는 기존 경로를 사용한다. [관리자 작품 화면](../../frontend/src/pages/admin/A04Artworks.tsx) · [결과 표시와 초안 병합](../../frontend/src/lib/adminAnalysis.ts)

## 5291 PC Chrome과 실제 OpenAI

- `06b7fe1` 기반 수정 번들을 5291에 띄웠다. 별도 Compose의 Django·PostgreSQL과 실제 OpenAI `gpt-6-luna`를 사용했다. 태그·감정 분석 서비스는 비활성이었다. 합성 작품은 〈빛이 드는 방〉 `fixture-art01` 한 점이다.
- 관리자 **AI 분석 실행**에 HTTP 200이 왔다. 결과는 **쉬운 요약 · 제안 생성 완료**, **관람가이드 · 제안 생성 완료**, **취향 태그 · 기존 확정 유지**, **감정 분석 · 연결 확인 필요**였고, 전체 실패 알림은 0개였다. AI가 제안한 요약과 관찰 질문·힌트 두 쌍은 확정 전에 공개 응답에서 비어 있었다.
- 요약과 가이드를 각각 확정한 뒤 관람자 **AI 요약 보기**, **관람가이드**, **힌트 보기**에서 저장 문안을 대조했다. **1번 질문으로 대화하기 → 힌트 받기**와 요약의 **이 부분 더 알아보기**에서는 각각 실제 답변 200과 `llm` 모드를 확인했다. 콘텐츠 버전은 9, 작품·원문 버전은 `fixture-art01`·3, 요약과 가이드 개정은 각각 5였다.
- 첫 생성 힌트가 원의 어느 쪽을 보면 좋을지 모호해 관리자에서 왼쪽·아래쪽 가장자리로 다듬었다. U-10에서 수정 힌트를 확인했고, 이어서 요청한 U-11의 실제 답변 200이 콘텐츠 버전 10과 가이드 개정 6을 사용했다. 원문 버전과 요약 개정은 각각 3과 5였다. U-10의 힌트 보기는 저장 문안을 표시한다. U-11의 힌트 받기는 확정 관찰 질문과 작품 근거를 사용해 새 답변을 생성한다.
