# 유영국 전달 자료 1차 검토

2026-11-09 KST / 기준858b2bb / dev/임준억 / W06 AC18·AC19 조사. 이전 [Git자료 점검·의존분리](2026-11-08_구조안내와Git자료의존분리.md) 이후 실제 유영국 ZIP을 받아 시연 적합성과 다음 계획을 검토했다.

이전에는 유영국 자료를 받지 못해 인수 형식·개수·근거를 확정할 수 없었다. 이번에는16개 PNG와 작품별 설명16건을 읽고 이미지 구조·해시·크기를 점검한 뒤 접촉 시트로 모두 시각 검토했다. 공식 MMCA 페이지와 이미지도 비교했다. 최종적으로04·05·08·10·11의 시각 대응 근거를 확보했고09는 동명·동년 공식 게시 이미지와 달라 메타데이터 자동 연결을 보류했다. 초기 비교 후보였던1979년 산과 호수는10번과 다른 이미지이므로 연도 오류로 판정하지 않았다. 추가 조사에서10번과 대응하는1984년 산의 소장품 페이지를 찾았다.

원본 ZIP은 수정하지 않았고 해시/원래 파일명을 포함한 점검 사본은 Git 제외 private 폴더에 뒀다. 설명은 공식 원문으로 입증되지 않았고 추정·내용 대조 필요가 남아 있어 승인하지 않았다. 유영국을 관찰 중심 시연 후보로 유지하고 식별/근거→검수→안전한 적재→취향/추천→실모델 여정 순서를 제안했다. 보고서는 [자료 검토와 시연계획](../operations/2026-11-09_유영국자료검토와시연계획.md)에 있다.

검증: PNG16개 PIL 구조 확인 정상, SHA256 중복0, 전체16개 시각 검토. 공식 이미지7개를 비교했으며 그중5개가 전달 이미지와 시각 대응했다. 이미지 동일성 최종 확정·권리·실제 출품·사람 승인·추천/모델 성능은 별도다. 공식 이미지 추가 수집은 제한 환경 DNS 실패 후 허용된 네트워크 경로로 읽기 전용 재시도했다. 자체 검토는 팀/교수님/방문자/기술 관점으로 수행했고 외부 검토자·실모델 검증을 수행했다고 기록하지 않았다.

이번 변경은 조사 문서와 계획 연결뿐이다. 제품 코드·DB·승인·게이트 상태를 변경하지 않아 제품 테스트를 재실행하지 않는다. Markdown 링크와 diff를 확인한다. 기존 AI 키·확장·하네스 추후 논의와 로컬 고유자료 별도 인수 방침을 유지한다. 원격 푸시는 하지 않는다.
