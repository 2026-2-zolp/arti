# 2026-11-18 Luna 가림 답안과 Kanana 반복 검수

기준은 로컬 `dev/임준억` `1a0b4af`다. Luna는 같은 A-04 코드와 승인된 합성 입력만 사용했고, Kanana는 기존 공식 3B 가중치와 노트북 Ubuntu WSL에서 재현했다.

## Luna 원문·도판 반복과 가림 자료

L01 v1의 기존 생성 4건과 이번 신규 20건을 묶었다. L01~L03의 원문·도판 해시를 확인했다. 작업당 원문만 2회와 원문+도판 2회로 총 12쌍·24답안이다. L01을 다시 생성할 때 모델에 전달되는 작품 메타데이터도 앞선 시험과 일치했다. 도판 모드에는 A-04의 도판 전용 지시까지 포함됐다. 신규 20건의 HTTP·제안 형식이 모두 성공했고, 케이스별 확정 요약·가이드는 고정됐다. [원문과 도판 manifest](../review/docent-2026-11-15/luna-fixtures/manifest.json)

| 사례 | 원문+도판 내용 판정 |
| --- | --- |
| L01 | 기존 1회차 가이드에는 원이 경계에 닿는다는 잘못된 전제가 있었다. 2회차 가이드에서는 같은 오류가 반복되지 않았다. 두 요약은 빨간 선이 파란 면에서 흰 여백으로 이어짐을 확인했다. |
| L02 | 4개 도판 답안이 원문에 없는 빨간 선을 관찰로 잡았다. 원문만 사용한 답안은 원과 파란 면을 중심으로 설명했다. 두 도판 가이드에서 경계를 잘못 짚은 전제는 확인되지 않았다. |
| L03 | 도판 요약 두 건이 원문의 ‘왼쪽 위’와 도판의 ‘오른쪽 위’ 차이를 명시했다. 두 도판 가이드의 질문은 원 위치를 한쪽으로 전제하지 않았다. 2회차 가이드 도입은 오른쪽을 도판 관찰로 밝혔고, 원문과의 차이를 설명하는 문장은 두 가이드 모두 없었다. |

이 사건과 같은 **명시적 위치·접촉 전제 오류는 도판의 가이드 1/6건, 도판 응답 전체 1/12건**이다. 그 한 건은 품질 미통과로 남겼다. 촘촘한 도판에서의 오류율과 채택률은 독립 평가와 후속 표본으로 판단한다.

| 작업 | 조건 | 응답 수 | 지연 중앙값 | 최솟값~최댓값 | 입력 / 출력 토큰 합 |
| --- | --- | ---: | ---: | ---: | ---: |
| 쉬운 요약 | 원문 | 6 | 3.236초 | 2.372~8.194초 | 2,342 / 960 |
| 쉬운 요약 | 원문+도판 | 6 | 5.675초 | 5.127~7.986초 | 4,604 / 1,984 |
| 관람가이드 | 원문 | 6 | 3.977초 | 2.954~5.562초 | 2,252 / 1,240 |
| 관람가이드 | 원문+도판 | 6 | 6.704초 | 5.769~8.495초 | 4,514 / 2,403 |

기존 L01 4건은 Chrome 버튼에서 응답까지, 신규 20건은 같은 A-04 HTTP 요청 왕복 시간을 쟀다. 총 입력 13,712·출력 6,587, 캐시 입력과 미수집은 0이다. 신규 20건의 요청 ID별 계측과 기간 내보내기 일치까지 확인했다. 실제 청구 대조는 팀 프로젝트 내역을 확보한 뒤 진행한다.

가림 답안은 작업별 X/Y 배정을 균형 있게 섞었다. 조건표·요청 ID·토큰은 분리했고 모델의 실제 생성문에는 손대지 않았다. 답안에 등장하는 ‘도판’ 같은 표현은 평가자가 조건을 추정할 단서가 될 수 있다. 공유용 ZIP에는 답안과 합성 원문·PNG 6개만 들어 있다. 본문 검수 회신은 0/12쌍이다. [채점용 답안](../review/docent-2026-11-15/Luna_L01-L03_가림답안_2026-11-18.md)

## Kanana 토크나이저와 RoPE 경고

- 고정 가중치의 모델 타입은 `qwen3`이고 저장 설정 버전은 `4.57.6`이다. Transformers 4.57.3의 로컬 경로 분기는 이 저장 버전에 Mistral용 경고를 표시한다. 기본 로딩과 `fix_mistral_regex=False`는 L01~L03의 요약·가이드 여섯 입력에서 토큰 ID가 같았고, 전처리도 공식 `tokenizer.json`과 같았다. `True`를 강제로 주면 여섯 입력의 토큰 ID가 바뀌고 요약은 각 4개, 가이드는 각 2개 토큰이 늘었다. 실제 반복에서는 공식 전처리를 사용했다. [Transformers 토크나이저 구현](https://github.com/huggingface/transformers/blob/v4.57.3/src/transformers/tokenization_utils_base.py)
- 공식 YaRN `factor=40.0`과 길이 비율 `32768/4096=8.0`이 다르다. 설치 코드의 역주파수 계산은 명시된 40을 읽는다. 사본에서 8을 넣으면 역주파수와 attention scaling 값이 바뀌는 것을 확인했다. 원본 설정을 유지했다. 긴 문맥 품질의 검증은 별도 시험에서 다룬다. [Transformers YaRN 계산](https://github.com/huggingface/transformers/blob/v4.57.3/src/transformers/modeling_rope_utils.py)

### WSL 반복과 25초 판정

공식 설정의 루프백 HTTP 반복 첫 요청은 240초 안에 응답을 받지 못했다. HTTP 처리 지연과 추론을 구분하기 위해 같은 모델·원문·ARTI 프롬프트를 쓰고, WSL CPU 6스레드 BF16에서 한 프로세스에 모델을 올려 요약과 가이드를 번갈아 3회씩 직접 실행했다. 최대 출력 180토큰을 두고, 각 토큰이 나온 직후 경과 25초를 검사해 중단했다. 중단된 행의 지연은 **중단 시점**이다.

| 회차 | 작업 | 첫 토큰 | 추론 종료·중단 | 입력 / 출력 토큰 | 25초 내 유효 JSON |
| ---: | --- | ---: | ---: | ---: | --- |
| 1 | 요약 | 8.183초 | 23.050초 | 302 / 45 | 통과 |
| 2 | 가이드 | 6.995초 | 25.297초 | 298 / 47 | 실패 |
| 3 | 요약 | 11.479초 | 25.203초 | 302 / 22 | 실패 |
| 4 | 가이드 | 13.339초 | 25.184초 | 298 / 19 | 실패 |
| 5 | 요약 | 9.709초 | 25.102초 | 302 / 29 | 실패 |
| 6 | 가이드 | 8.908초 | 25.245초 | 298 / 35 | 실패 |

요약 1/3건과 가이드 0/3건, 총 1/6건이 25초 안에 형식을 완성했다. 통과한 요약은 파란 바탕·노란 원·흰 여백·빨간 선을 유지했으며 원이 왼쪽 위라는 위치는 생략했다. 현재 WSL BF16 경로는 A-04 투입 기준을 충족하지 못했다. 같은 입력으로 CPU에 맞는 경량 실행 경로의 지연을 먼저 재고, 통과하면 루프백 HTTP와 실제 A-04에서 25초 내 JSON 및 확정본 유지를 재현한다. 기준 설정은 [ARTI 연결 코드](../../backend-django/arti/llm.py)에 있다. 진단과 반복 계측은 `data/private/arti-kanana-1118/kanana-diagnostics.json`과 `kanana-repeat.json`에 보관했다.

## Gemma를 비교할 조건

이번 표본에서는 도판이 L02의 새 관찰과 L03의 불일치 표시를 도왔고, L01 오류는 두 번째에 반복되지 않았다. 이번 릴리스의 필수 모델 도입은 보류하는 판단이다. 독립 검수에서 같은 유형의 오류가 다시 확인되거나 실제 작품을 외부에 보낼 수 없어 로컬 도판 분석이 필요한 경우에는 **Gemma 4 E2B의 공식 Q4_0 GGUF**를 첫 비교 후보로 둔다. Google은 멀티모달 입력과 CPU 실행용 GGUF 경로를 안내한다. 이 노트북에서 품질·지연은 아직 실측 전이다. [Gemma 4 모델 카드](https://ai.google.dev/gemma/docs/core/model_card_4) · [공식 E2B Q4_0](https://huggingface.co/google/gemma-4-E2B-it-qat-q4_0-gguf)

후보로 검수할 때는 L01~L03의 같은 원문·도판과 가림 형식을 사용한다. 틀린 색·위치·접촉을 전제하는 질문·힌트 0건, L03의 불일치 처리, 기존 공개본 보존, A-04용 JSON 및 25초 전체 응답을 같이 확인해야 한다. 현재 드래프트 제공자 경계는 텍스트 모델 선택을 지원하고 도판은 Luna에만 허용한다. Gemma 도판 기능을 채택한다면 별도 허용 경로와 전송 검수부터 추가한다. [현재 도판 허용 조건](../../backend-django/arti/llm.py)
