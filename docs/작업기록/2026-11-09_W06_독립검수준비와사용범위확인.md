# W06 독립 검수 준비와 사용 범위 확인

2026-11-09 / 출발10955a9 / dev/임준억. [격리 전체 여정 검증](2026-11-09_격리전체여정검증.md) 후 실제 유영국 적용의 선행 자료를 준비했다. 사용자 요청에 따라 검증단 관점으로 준비 범위와 사람 판단을 분리했다.

## 확인 입력과 변경 전후

사용자가 ‘광권님이 웹에서 캡처, 교내 졸업프로젝트 기간에만 사용’이라고 회신했다. [사용 맥락](../execution-plan/2026-11-07/records/W06/independent-review-2026-11-09/usage-context.json)에 기록했다. 소장품 식별 근거와 전달 이미지의 원취득 URL·개별 조건은 다른 항목으로 유지했다. MMCA 공식 FAQ/저작권정책을 조회했고, 재단 홈페이지 웹 조회는502로 새 조건을 확인하지 못했다. 자료 취득 방식/사용 목적 확인을 개별 이용 허락으로 바꾸지 않았다.

기존 검수 packet은 AI 후보 태그와 설명을 함께 포함해 첫 라벨에 영향을 줄 수 있었다. 원본/동결 packet을 보존하고 docs/review/yoo-2026-11-09에 독립 판단용 HTML과 파일식별 manifest/안내를 추가했다. 첫 단계는 이미지와 중립 정의만 보여 주며 순서를 섞는다. 제목/설명/모델 점수/기존 팀 답은 노출하지 않는다. 2차에는 별도 source-followup과 기존 콘텐츠 검수표로 식별·판본/원문·요약·가이드/사용조건·배치를 검토한다.

이미지는 SHA-256으로 원 인수16점과 대조하고 로컬 File API로 읽는다. 네트워크 전송/DB 적재/자동 저장은 없다. 태그는 yes/no/unsure/미응답을 구분하고 감정은 선택적 개인 의견이다. JSON에는 별칭·파일해시·정의버전·제시순서가 남는다. 초안은 다운로드 가능하나 자동 재불러오기는 아직 없어 페이지를 유지하고 닫기 전 저장하도록 안내했다. 실제 이미지나 권리 미확인 자료를 Git에 추가하지 않았다.

scripts/yoo_labels.py와 tests/test_yoo_labels.py를 추가해 원 인수자료/manifest·응답 대응, 변조/중복·가짜 완료/승인·모르겠음/미응답/감정 미참여를 검사한다. TEST 응답은 기본 거절이며 --allow-test는 도구 시험용이다. 검증기는 형식만 확인하고 contentApproved/teamReviewAccepted는 false로 유지한다. 실제 집계/DB 승인 기능은 만들지 않았다.

## 검증 루프

브라우저에서 잘못된 이미지 해시 거절→원본16점 준비→TEST 첫1점8개모르겠음→draft JSON 내려받기를 확인했다. 이미지/정답 데이터를 외부 제출하지 않았다. 실제 브라우저 파일을 CLI로 검증해 시험 응답/완료1/유효판단0/불확실8/미응답120을 확인했다. 이 값은 팀원 라벨이 아니며 팀원 응답은0건이다.

기술/시니어 관점에서 자기 해시만 바꾸는 manifest 변조도 원 인수자료와 대조해 거절하도록 보강했다. 데이터/운영은 미완료·TEST·자동승인 방지, 콘텐츠/방문자는 의견 강요·사전 모델 노출 방지와 라벨 부담, 팀/교수/평가위원은 독립 판단과 실제 승인 구분·작은 표본/기존 탐색 노출을 자체 검토했다. 실제 사람 승인이 아니다. 전용 서버에서 UI를 확인한 뒤 종료하고 다운로드 TEST 예시는 분리 보존한다.

검증 결과는 [준비 기록](../execution-plan/2026-11-07/records/W06/independent-review-2026-11-09/README.md)과 validation.json에 남긴다. 일반 arti-dev는16점 source_check/이미지공개0/배치0, 요약·가이드 suggested16점으로 그대로다. 제품 프론트/API 변경이 없어 과거20/93회귀를 이번에 재실행한 것으로 쓰지 않는다.
