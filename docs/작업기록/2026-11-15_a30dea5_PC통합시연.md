# 11/15 최신 main PC 통합 시연 검수

- **환경** · `main` `a30dea5`의 프로덕션 프론트, Windows Chrome 157의 1280×800 화면, 새 PostgreSQL과 합성 전시 `fixture-ex01`을 사용했다. Django 마이그레이션 8개 적용과 `/api/ready`의 PostgreSQL 준비 응답을 확인했다. 브라우저는 검수 주소로만 요청했고, Django는 외부 모델 키 없이 기동해 기존 루프백 모의 제공자로 도슨트를 실행했다. [실행과 시연 순서](../operations/2026-11-11_main_시연복구체크리스트.md#최신-main-pc-통합-시연--a30dea5)
- **취향과 추천** · 조사풀 10점·5쌍을 읽고 회원·비회원 모두 위쪽 카드의 선택 버튼으로 다섯 번 골랐다. 미리 확인 응답의 V2·조사풀 버전·동점 근거 버전을 대조했고, 추천 요청에 V2가 전달됐다. 30분의 추천 목록, 처음 지도 마커, 다음 작품 안내의 카드·현재 마커·강조 경로, 감상 화면과 영수증이 모두 `fixture-art01 → fixture-art03 → fixture-art05` 순서였다.
- **작품 확대** · U-05 첫 비교 이미지와 U-10 첫 작품 전체 화면을 Enter로 열었다. Tab·Shift+Tab은 창의 닫기 버튼에 머물렀다. 두 창에서 마우스 휠로 확대하고 원래 배율로 돌아왔다. U-05는 Enter로 닫은 뒤 1/5가 유지됐고, U-10은 Esc로 닫은 뒤 같은 작품과 관람 ID가 유지됐다. 창을 닫을 때마다 포커스가 각 원래 버튼으로 돌아왔다.
- **모의 도슨트** · 두 관람 모두 첫 작품의 관람가이드 1번에서 힌트 요청 502 뒤 다시 시도로 200을 받았다. 질문·관람 ID·진입 맥락이 같은 요청을 보냈다. 기본 합성 전시의 일반 관찰 질문(`generic_tip`)은 현재 작품의 원문 버전 1·리비전 1을 참조했다. 제공자가 넣은 다른 작품 참조는 응답에 포함되지 않았고, HTML 모양 문자열은 말풍선에 텍스트로 표시됐다. 뒤로가면 같은 작품으로 돌아왔다.

- **회귀와 판정** · 프로덕션 빌드, 프론트 단위 시험 43건, 관람 Chrome 회귀 14건이 통과했다. 통합 관람 중 브라우저에서 지정한 502 외 HTTP 오류나 처리되지 않은 화면 오류는 관찰되지 않았다. 제품 코드 수정이 필요한 문제는 재현되지 않아 시연 순서와 이 기록을 갱신했다.
- **검수 범위** · 모의 제공자로 관람 연결과 복구를 확인했다. 실제 모델 호출, 실기기 제스처·키보드와 OS 공유는 계속 보류했다.
