## 이번 커밋 정리 방식

W01~W04는 이미 수행한 작업을 2026-11-08에 회고 정리해 단계별로 커밋했다. 실제 검증 당시 로그는 보존하며 커밋 날짜/작성자를 과거로 바꾸지 않는다. 원격 `dev/임준억`의 f0c55aa에서 동섭 통합본 ae0e58e를 병합했고 그 병합의 파일 tree가 원본과 같음을 확인했다.

작업기록에는 자신이 포함된 커밋의 SHA를 적어 자기 참조로 계속 바꾸지 않는다. 해당 기록의 최초 추가 커밋은 `git log --follow -- docs/작업기록/<파일>`로 확인한다. 다음 작업기록은 앞 단계의 실제 SHA를 연결한다.
