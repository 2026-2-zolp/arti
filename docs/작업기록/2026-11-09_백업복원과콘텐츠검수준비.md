2026-11-09 KST / dev/임준억 / 품질 보완 커밋38dd3a6 이후, 조사 기준6e2ea40 및 [품질 평가 후속](2026-11-09_GPT품질평가와프롬프트보완.md). 사용자는 품질 확인 후 계획된 보존/검수 준비를 이어가고 일반 개발 API에 provider 설정을 반영하도록 요청했다. 평소 개발 프로젝트가 없어 사용자 응답에 따라 arti-dev를 새로 만들었다.

## 왜·어디·전후

기존 migration/재시작 검증에는 DB+미디어 백업세트를 새 환경으로 복원하는 증거가 없었다. arti-backup-src/dst의 신규 시험 볼륨에 합성 자료만 사용해 dump+media archive+manifest를 만들고 새 빈 대상으로 복원했다. 관계·검수 상태·공개 제한·미디어 누락과 재시작 지속성을 확인했다. 원본 이전/복원본/원본 이후/재시작 후의 논리 DB와 미디어3개 해시가 같았다. 실제 데이터/덤프는 private에 보존하고 [Git 증거](../execution-plan/2026-11-07/records/backup-restore/2026-11-09/README.md)에는 집계·해시·키 없는 실행문을 담았다.

migration 누락·잘못된 fixture ID·볼륨 간 rename EXDEV·복원 root 소유권 문제를 절차에서 보완했다. 복원 미디어는 서비스 UID10001로 소유권을 돌렸다. 시험 컨테이너/네트워크는 down(no -v)하고 모든 볼륨을 보존했다. 원래 arti-w04/arti-w05·팀원 로컬 원본에는 쓰지 않았다. 운영/AWS 복구·로컬 고유자료 인수 완료가 아니다.

식별표의 핵심3점001/004/010에 대해 [콘텐츠 검수 준비](../operations/2026-11-09_유영국핵심3점_콘텐츠검수준비.md)를 새로 작성했다. 이전에는 후보 선정만 있었고 이후에는 근거 후보·직접 관찰·가능한 해석·쉬운 설명·질문/접는 힌트·도슨트 맥락 시험·사람 검수표가 있다. 팀 편집 초안이며 공식 해설이나 승인 콘텐츠가 아니다. 원본 인수 registry·자료·DB는 수정하지 않았다.

## 일반 개발 환경과 검증

`docker compose --env-file .env.compose -p arti-dev --profile ui up -d --build --wait api frontend`로 새 DB/미디어 환경을 기동했다. API4018·UI5178, PostgreSQL ready, provider=openai_compatible·요청모델gpt-6-luna·키존재만 확인했다. 키값/암호는 출력하지 않았다. 전시0·작품0·계정0으로 자동 fixture/기본계정이 없다. 프론트5178의 /api/ready 프록시가 PostgreSQL 정상 응답, 브라우저에는 '진행 중인 전시가 없어요'가 표시된다. 빈 DB이므로 일반 앱에서 실제 유영국 전체 여정을 검증한 것은 아니다. arti-dev는 사용 가능하도록 켜둔다. 실제키/env는 Git 제외, 추가 유료호출 없음.

방문자/콘텐츠 검토는 초안 준비 범위 적정·필수 수정 없음, 비공개 적재 전 백업 선행 링크를 보완했다. 기술/SENIOR·팀/교수/평가위원 관점으로 최종 검토한다. W06 in_progress/W07 planned·AC18~22 not_run/G5를 유지한다. 다음은3점 사람 검수·권리/식별 보강·명시적 범용 인수 형식이며 그 뒤 비공개 적재·배치/태그 검수·전체 여정으로 간다. 로컬 커밋만, 원격푸시 없음.

최종 TECH/SENIOR 지적에 따라 관계/snapshot/검수 상태의 ORM 대조와 공개/보호/누락 API 검사를 분리해 문서를 정정했다. 관람 영수증 API 완주는 미실행이다. 명령 템플릿·6도메인 행 논리 해시 범위도 추가했다. TEAM/PROF/EVALUATOR 검토는 부분 완료 판정에 필수 결함 없음으로 확인했다. 계획 무결성 오류0·가드레일25/25·보호 아카이브38개 보존을 확인했다.
