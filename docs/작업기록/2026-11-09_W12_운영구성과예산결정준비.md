# W12 운영 구성·예산 결정 준비

2026-11-09 / dev/임준억 / 출발d43f812. [격리 모델 장애·복구](2026-11-09_격리모델장애복구여정.md) 다음 과업. 사용자는 기존 검증 방식으로 기준 충족까지 진행하고 종료 후 보고·후속 과업을 확인하도록 요청했다. 기존 로컬 커밋/원격 미푸시 경계를 유지했다.

## 배경·변경 전후

기존06-operations.md는 통합본 시점의 SQLite/180·300초/미구성 CI 표현이 남아 있었고 실제 배포 구성·가격·운영자/상한은 미결이었다. 이를 당시 출발점으로 구분하고 현재 [W12 결정안](../operations/W12_운영구성과예산결정안.md)에 실제 Django/PG·미디어 경로·모델/LLM·브라우저/gunicorn 시간 제한과 최신 실측을 연결했다. 크레딧 없음이라는 사용자 회신을 반영해 비용 우선 후보는 Lightsail4GB 자체PG(C), 대안은 EC2 자체PG(A)/EC2+RDS(B)와 교내 로컬 보조 시연이다. 세 AWS 안은 운영형 정적 서빙/내부 모델·DB/미디어 보존·비공개S3 백업을 사용하며(EBS 직접 관리는 EC2 안에 해당), 실제 선택은 미정이다. S3를 이미 지원하는 앱 저장소처럼 설명하지 않았다.

AWS 공식 서울 가격과 Lightsail 공식 번들을 조회해 Linux shared t3.small/medium/large·EBS gp3·RDS PostgreSQL Single-AZ 실제 InstanceUsage/gp3·S3 Standard·유지IPv4·선택 DNS zone 단가를 고정했다. [가격/검토 근거](../execution-plan/2026-11-07/records/W12/2026-11-09/README.md)에 출처·발행/확인일·SKU/필터/해시·재현 계산을 남겼다.720시간 핵심 소계 A44.81/B65.43달러,176시간 비교 A16.53/B23.55달러다. C는 번들24달러+백업5GB의 월24.13달러 소계이며 일반 VM의 stop은 무료가 아니다. 로컬안은 보유 장비 기준 새 호스팅 청구만 없고 AWS 인수를 대체하지 않는다. 외부 LLM/해당 CPU credit/전송/스냅샷 등과 세금/환전은 별도다. 무료 크레딧·총 청구액·hard cap으로 제시하지 않는다.

## 검증단 검토·보완

초기 가격 endpoint404·EC2 JSON80MiB 상한 초과는 공식CSV 스트리밍으로 대체했다. RDS의 사용 인스턴스와 unused 예약 행·S3의 productFamily 없는 행을 구분했고 원본의5GB 최소 메타데이터를 RDS PostgreSQL의 실제 gp3 최소20GiB로 오인하지 않았다. 정지 시간에 IP/스토리지 비용을 같이 줄이는 계산, 복원 새 인스턴스/보존 키/DB+미디어 불일치를 놓치지 않게 보완했다. 선택/배포 확정 오기·제외항목 누락·가짜 무료·5GiB·유지IP 부분과금·예약SKU 혼동·Lightsail IP 이중과금/stop 무료 오인9개 변이를 거절하는 계산/결정안 검사를 통과했다.

시니어/기술은 libpq SSL 지원과 Compose CA/변수 전달 미검증을 구분하고 런타임/마이그레이션 권한·로컬 Path 파일의 보존/권한·모델 패키징 미구현을 확인했다. 운영/데이터는 SG/SSM/비밀·원본 보존·새 대상 복원·중단/잔여 과금·실제 담당/상한 미확인을 확인했다. 팀/교수/평가위원/관람객/콘텐츠는 주제 범위·저장 점수 추천·실모델/합성/운영 승인·미검수 자료 공개 경계를 대조했다. 동일 작성자의 역할별 자체 검토로 실제 외부 승인을 대신하지 않는다.

추가 발견은 전체 요청 시간 예산이다. summary25+guide25+공유 모델30초의 네트워크 예산 합계는80초 수준이며 브라우저 분석/gunicorn은90초다. 큐 대기·DB·프록시를 포함한 엄격한 총 deadline은 구현/검증되지 않았다. 이전 장애 브라우저는 확정 텍스트를 건너뛰었으므로 이 전체 경로 성공으로 해석하지 않는다. 성능 실패를 새로 재현한 것은 아니며 코드 대조에서 나온 후속 검증 항목이다.
