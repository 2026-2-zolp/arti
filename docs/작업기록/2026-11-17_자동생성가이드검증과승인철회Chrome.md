# 11/17 자동생성 가이드 형식과 승인 철회 검수

- `main`과 로컬·원격 `dev/임준억`을 `3ff9aab`에 맞춘 뒤 작업했다. 합성 작품과 모의 제공자로 검수했다.
- 자동생성 가이드는 질문 1~3개를 받고 공백 문자만 있는 질문을 거절한다. 힌트 슬롯은 질문당 하나씩 필요하며 빈 슬롯은 허용한다. 가이드 단독 재생성의 형식 오류는 `502 PROVIDER_ERROR`로 반환한다. 여러 항목을 동시에 분석하는 요청에서는 가이드 항목에 `PROVIDER_ERROR`가 기록되고 정상 생성된 다른 항목의 저장은 기존대로 처리한다. [제공자 검증](../../backend-django/arti/providers.py) · [분석 API](../../backend-django/arti/editing.py)
- 질문 0개·4개·공백과 힌트 부족·초과를 모의 응답으로 시험했다. 다섯 건 모두 502였고 관리자 초안, 공개본, 버전이 그대로였다. 정상 질문 3개로 재시도하면 관리자 제안만 저장됐다. 기존 코드에서는 질문 0개로 200을 반환해 같은 회귀가 실패하는 것을 확인했다. [Django 회귀](../../backend-django/arti/tests/test_integration.py)
- 관리자 Chrome에서 힌트 개수 불일치로 응답이 502였고 화면에서 재시도한 뒤에도 확정 전까지 이전 가이드·관람자 미리보기·도슨트 참조가 유지됐다. 새 질문·힌트는 관리자 확정 후 공개됐다. [관리자 Chrome](../../frontend/tests/adminAnalysis.browser.mjs)
- 새 제안과 기존 공개본이 함께 있는 상태에서 검수 상태를 `출처 확인`(`source_check`)으로 변경했다. 미리보기에서 공개 내용이 내려갔고 작품 상세·기존 가이드 문맥으로 보낸 도슨트 요청은 404였다. 작품을 재승인하자 확정 요약은 표시됐고 철회한 가이드는 복구되지 않아 기본 감상 팁이 표시됐다.
- 합성 PostgreSQL에서 Django 196건과 마이그레이션 변경 여부 확인을 통과했다. 프론트 47건과 프로덕션 빌드, 모의 관리자 Chrome이 통과했다. Chrome은 기존 `admin-analysis` CI 작업을 사용한다. [CI 실행 정의](../../.github/workflows/ci.yml)

## 제안 폐기 Chrome 준비

- 기존 확정 가이드 공개 → 같은 필드 재생성 → 관리자 제안과 이전 공개본이 함께 있는 지점까지 Chrome에서 실행했다. 가이드 제안만 폐기하는 관리자 화면 동작과 API는 후속 개발 대상이다.
- 제안 폐기 후에는 관리자 제안만 제거되고 이전 확정 질문·힌트, 공개 버전과 열린 도슨트 문맥이 유지되어야 한다. 공개 이력이 없는 제안만 폐기하면 해당 항목은 기본 감상 팁으로 남는다. 다른 확정 필드도 그대로여야 한다.
- 다른 탭에서 최신 제안을 수정하거나 확정한 후 이전 버전으로 폐기하는 경우 409와 부분 저장 0건을 확인한다. 최신 상태를 불러오면 현재 제안이 있을 때만 다시 폐기할 수 있어야 한다. 같은 확인을 반대 순서인 폐기 뒤 오래된 확정에도 적용한다.
