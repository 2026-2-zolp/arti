# 직접 관람·관리자 운영과 도면 재검수

직접 관람은 팀 검토용 합성 전시의 옵션이다. `4578688`을 기준으로 전시 첫 화면의 설명을 감상과 해설에 맞췄다. 다음 작품 안내에서 기존 썸네일·타이틀·하단 버튼을 재사용하고 지도는 펼쳐서 확인한다. 도면이나 작품 목록 조회가 일시 실패해도 작품 상세를 직접 열 수 있다. 직접 관람 일반 도면에는 감상 순서와 작품 위치를 숫자로 표시하고 실내 이동을 나타내는 선은 그리지 않는다.

## 도면 세 가지 비교

| 도면 | 관리자와 직접 관람 확인 | 기존 추천 화면에서 발견한 점 |
| --- | --- | --- |
| 전시실 하나, 작품 세 점, 도면 이미지 없음 | 관리자의 전시실 사각형과 세 마커, 360px Chrome에서 필요할 때 펼치는 지도와 다음 작품 버튼 | 단순한 방 배치는 기존 좌표와 SVG로 설명할 수 있다. |
| 전시실 하나, 중앙 기둥, 세로 도면 360×640 | 관리자 보호 이미지와 세 마커, 원래 도면 비율, 직접 관람 마커와 목록 | 기존 추천의 작품 간 직선을 SVG에서 확인했다. 중앙 기둥 사각형을 통과했다. |
| 전시실 두 개, 아래쪽 연결부, 가로 도면 640×360 | 상이한 두 전시실에 작품을 배치하고 관리자·관람자에서 위치와 비율을 확인했다. | 기존 추천의 작품 간 직선이 열린 연결부 위의 벽을 통과했다. |

Django 추천은 공개·좌표 등록 작품에서 취향 태그 강도와 태그별 후보를 적용해 3·5·7점을 목표로 고른다. 입구부터 퍼센트 좌표의 유클리드 거리로 가까운 작품을 차례로 정한다. U-09는 받은 순서의 점을 잇고 다음 구간을 강조한다. 이 계산에는 도면 종횡비와 실제 통로 길이가 반영되지 않는다. 기존 갤럭시 검증용 도면 한 곳에만 문과 복도를 지나도록 지정한 예외가 있다. [추천 계산](../../backend-django/arti/recommendations.py) · [추천 화면](../../frontend/src/pages/user/U09Route.tsx)

지도는 네이티브 화면의 번호·전시실 색·작품 목록·다음 작품 카드를 유지하고, 도면 이미지는 관리자 참고 레이어로 사용할 수 있다. 후속으로 전시실 경계·벽/기둥·출입문·통로 연결점과 작품 앞 접근 위치를 도면 버전에 함께 등록하면, 등록한 연결선을 따라가는 경로를 계산할 수 있다. 등록 상태를 확인하지 못했거나 두 지점이 연결되지 않으면 번호와 전시실 정보만 보여준다. 기존 추천 적합도와 관람 순서는 우선 유지한 채 **그 사이에 걸을 수 있는 구간**부터 바꾼다. 우회 비용을 추천 순서에도 사용할지는 이동 거리와 큐레이션 순서를 따로 검수한 뒤 판단한다. [OGC IndoorGML](https://www.ogc.org/standards/indoorgml/) · [국립중앙박물관 순서·전시실 표기](https://www.museum.go.kr/MUSEUM/contents/M0201020000.do)

## 관리자와 실제 작품 검수

- Django 관리자에 최근 운영 이벤트 목록, 오류 필터, 한국 시각 기준 오늘의 도슨트 요청·관리자 분석·AI 요청 오류 집계를 추가했다. 테스트에서 비로그인 조회 401, 관리자 작품 저장·도슨트 503 이벤트, 요청 ID 조회를 확인했다. 저장 항목은 시각·작업 종류·상태 코드·요청 ID다. 작품 설명과 질문·계정·인증 값은 저장하지 않는다.
- 별도 합성 DB에 빈센트 반 고흐 **〈사이프러스가 있는 밀밭〉(1889)**의 The Met 공개 자료를 등록했다. 출처 사실은 작가·연도·캔버스에 유채·소장 번호 1993.132다. 도판의 아래쪽 밀밭과 오른쪽 어두운 나무는 관찰이며, 붓 자국이 바람처럼 느껴진다는 설명은 해석 예시다. [소장품 원문](https://www.metmuseum.org/art/collection/search/436535) · [The Met Open Access](https://www.metmuseum.org/hubs/open-access)
- 관리자 API에서 JPEG 등록과 출처 문안 저장, 승인 전 작품·도판 404, 승인 후 같은 도판 바이트 반환, 모의 요약·질문의 확정 전 비노출과 확정 후 공개를 확인했다. 도판 SHA-256은 `af0e3486621c210b54932d055294051b5601aa3362af4b84ab97e2831f8163bc`다. W06 유영국 도판은 기존 회신 절차에 남겨뒀다.
- 비용과 토큰 집계의 후속 데이터 범위 및 모델 비교 기준은 [도슨트 모델과 관리자 운영 검토](../operations/2026-11-17_도슨트모델과관리자운영검토.md)를, 실제 카카오 연동과 메일 복구는 [첫 연동 가이드](../operations/카카오로그인_첫연동가이드.md)를 따른다.

## 재현

[직접 관람 Chrome 재현](2026-11-17_합성전시순서바로보기.md#재현)과 같은 격리 PostgreSQL에서 `migrate`로 `0009_operation_event`를 적용한다. 합성 관리자를 만든 뒤 새 프런트 빌드로 아래 명령을 실행한다. 지도 세 검수는 합성 전시만 수정하고 종료할 때 원래 fixture를 다시 적재한다. 운영 로그의 503 검수에는 비활성 모델 설정을 사용한다.

```powershell
node frontend/tests/runVisitBoundaries.browser.mjs exhibition-order
node frontend/tests/runVisitBoundaries.browser.mjs map-variants
node frontend/tests/runVisitBoundaries.browser.mjs operations
```

직접 관람·지도 3종·운영 로그와 로그인 지원 Chrome, 기존 관람 Chrome, 프런트 단위 검사 47건과 빌드, Django PostgreSQL 전체 검사 199건을 통과했다. `makemigrations --check --dry-run`에서 미반영 변경은 없었다. 실제 API 제공자 호출과 실기기 검수는 보류했다.
