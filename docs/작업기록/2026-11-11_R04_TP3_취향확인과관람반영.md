# R04 TP3 취향 확인과 관람 반영

- 작품 선택·태그 편집·preview·최종 확인을 분리했다. 취향이 같으면 현재 관람을 이어가며, 다른 취향은 성공한 확인에만 반영한다.
- 계정 저장 충돌과 지연 응답에서 이전 관람을 보존한다. 동일 요청 재전송과 204 이후 계정 조회 재시도를 분리했다.
- 첫 시간 선택이 관람 ID를 교체하던 경로를 찾아 고쳤다. 관람 ID와 서명된 근거를 영수증에 연결하고, pending 본문을 새로고침 뒤 복원한다.
- React 검토에서 확인 대화상자의 취소·초점 동작을 재사용하고, 초안 변경 시 화면 범위가 끝난 응답을 차단하는지 확인했다.

기술 관점에서는 계정·관람 변경과 mutation 재시도를 확인했다. 방문자 관점에서는 같은 취향 복귀, 빈 집합 제한, 균등 가중치와 이번 관람만 적용을 점검했다. 운영·데이터 관점에서는 저장 버전과 서명·영수증 본문이 일치하는지 확인했다. 팀·평가 관점에서는 세로·가로 작품 전체 표시, 원문·요약 문단, 닉네임 100자와 전역 조사 호출을 확인했다. 별도 UI 변경 선별은 최신 종합본 인수에 남겨 두었다.

프론트 33건과 빌드, 격리 Chrome의 합성 API 여정을 통과했다. 시험에서 응답 연결을 끊는 방식은 Chrome이 PUT을 자동 재전송해 자극이 달라졌다. 저장 후 중간 서버가 504를 반환하는 경우로 바꿔 브라우저의 명시적 재시도를 검증했다. [TP3 검증 기록](../execution-plan/2026-11-07/records/taste-tie-implementation-results-2026-11-11/TP3/README.md)
