# 스페인 다음 작품 안내와 Luna 안전 응답

## 스페인 관람 화면

- `1adb20c` 기준으로 추천·전시 순서의 U-09에서 다음 작품명과 승인된 도판을 먼저 표시한다. 전체 지도와 순서는 접어 둔다.
- 스페인은 A-05에서 예시 배치를 해제한 최신 도면에 이동 가능한 경로가 있을 때만 직전 작품 또는 입구에서 다음 작품까지 선을 그린다. 예시 배치와 도면이 부족한 관람에서는 순서를, 벽이나 미확인 통로 때문에 경로가 끊긴 구간에서는 현장 안내를 표시한다.
- 로컬 배치표에는 기존 30점의 첫 표기 연도를 기준으로 오래된 작품부터 배치했다. 캡션 대기 16·20번을 제외한 28점은 1549년 작품에서 시작해 1931년 작품으로 끝난다. 그리드 좌표는 로컬 배치 검수용이다. 실제 전시실·작품 위치는 A-05에서 현장 자료와 대조한다. [예술의전당 시대순 감상 안내](https://www.sac.or.kr/site/main/academy/academy_app_view?searchCourseCd=C102104202609015)

## 캡션 보강 상태

- 16번 `A188`과 20번 `A309`는 전달받은 전시 캡션의 작가·연대·재료·치수를 검수 초안에 기록했다. 16번은 성인의 정체가 추정이라는 표기를 유지하고, 다른 유채 습작은 작가의 작업 방식에 관한 참고로 사용한다. 20번에는 로페스가 1815년에 수석 궁정화가가 되었다는 기관 자료를 배경으로 덧붙인다. [캡션 출처](https://blog.naver.com/zhalscjf/224425025738) · [메도스 미술관](https://meadowsmuseumdallas.org/wp-content/uploads/2019/01/2018_Spring_ATM.pdf) · [라코루냐 미술관](https://museobelasartescoruna.xunta.gal/es/coleccion/autores/lopez-vicente)
- 두 작품은 캡션 대기와 기존 비공개 상태를 유지한다. 광권님과 임준억이 기관의 원본·출품 목록과 도판 사용 범위를 대조할 수 있다. 1832년 방코 데 에스파냐 초상은 별도 작품으로 기록한다. [방코 데 에스파냐 `P_143`](https://coleccion.bde.es/wca/en/secciones/coleccion/obras/fernando-vii-p_143.html)

## 도슨트 응답과 검수 기준

- 공식 OpenAI의 `gpt-6-luna`는 정상 답변에 안전 분기를 반환한다. 등록 소장처 조회가 가능한 질문만 먼저 분기판정을 거치며, 허용된 경우에만 기존 함수와 승인 근거를 사용한다. Moderation은 검수 실험에 사용한다.
- 위험·확인 필요 분기는 서버 고정 문구를 UI에 잠시 표시한다. DB 대화 원문과 브라우저 대화 기록, 다음 요청 맥락, 관람 관심 신호, 출처·음성 권한·후속 질문을 만들지 않는다. 사용자 입력은 판정 후 비우며, 타임아웃 또는 아직 전송하지 않은 새 초안은 유지한다.
- 504 안내는 좁은 화면에서도 답변·재시도·입력창이 함께 보이도록 짧게 썼다. 기존 질문을 다시 보내도 작성 중인 다른 초안과 권한 범위를 유지해야 한다.
- Chrome에서 스페인 예시 도면 숨김, 검증된 구간 선 1개, 단절된 경로의 선 0개, 관람 계속을 확인했다. 안전 안내 후 세션 대화 기록과 재생 버튼이 없었고, 504 뒤 동일 질문·근거로 재시도하면서 새 초안이 남았다. 기존 지도·다른 계정의 영수증 저장 거부 회귀도 통과했다.
- 실제 Luna 어댑터의 합성 질문 8건이 통과했다. 등록 소장처를 언급한 위험 요청의 도구 호출은 0회였고, 정상 소장번호 질문은 도구를 1회 호출하고 정확한 등록번호를 반환했다. 모의 제공자와 합성 계정에서 위험 질문의 도구·원문 저장·음성 발급 차단을 검증했다.
- 프런트엔드 77개 자동 테스트와 타입·빌드를 통과했다. Django 전체 297개 중 분할 실행에서 관리자 HTTP 시간 예산 테스트 1개가 실패했다. 이 사례를 포함해 관리자 시간 예산·도슨트 안전·도구·운영 지표 23개를 부하를 분리한 PostgreSQL에서 다시 실행해 통과했다.
- 배포 전 최신 후보의 원격 CI와 앱 공개 검수를 거친다. 서울 EC2 운영 Compose의 Marin 설정 전파와 DB·미디어 복귀점을 확인한 뒤, 스페인 공개 범위에 맞는 A-04 승인 문안과 음원 해시를 대조한다.
