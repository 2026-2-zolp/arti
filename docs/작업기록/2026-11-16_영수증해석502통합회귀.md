# 영수증 AI 해석 502와 계정 전환 검수

## 합성 검수 결과

- **환경** · `dev/임준억` `eb5d1b9` 기준으로 PC Chrome 360×812, 정적 Vite 프리뷰, Django, 격리 PostgreSQL 17, 루프백 OpenAI 호환 모의 제공자를 연결했다. 완료된 합성 관람 상태에서 영수증 화면을 열고 버튼 조작과 Django API 응답을 확인했다.
- **회원** · 첫 해석 200 → 다시 해석 502 → 다시 시도 200. 실패할 때 기존 해석과 회원 영수증 응답 전체가 유지됐다. 재시도 뒤에는 해석만 교체됐고 새로고침 후에도 같은 영수증 ID로 한 건만 남았다. 새로고침의 저장 재전송은 같은 관람 ID를 사용했고 해석 API를 재호출하지 않았다.
- **비회원** · 같은 200 → 502 → 200 경로에서 기존 해석 보존과 갱신을 확인했다. 새로고침 뒤에도 새 해석을 탭에서 다시 보여 줬으며 관람 저장 POST는 0건이었다.
- **다른 계정 로그인** · 기존 회원의 실제 Django 응답을 첫 탭에서 잠시 보류했다. 둘째 탭에서 로그아웃하고 다른 합성 계정으로 로그인한 뒤 응답을 전달해도 이전 해석은 화면과 탭 저장소에 나타나지 않았다. 다른 계정 관람 목록은 0건, 이전 영수증 직접 조회는 403이었다.
- **제공자 경계** · 장애는 모의 제공자 HTTP 500으로 주입했고 Django가 502와 `PROVIDER_ERROR`를 반환했다. 응답에 모의 제공자의 오류 본문은 표시되지 않았다. 첫 해석과 실패·재시도에서 브라우저 요청 본문과 제공자 요청 바이트가 각각 동일했다. [이전 UI·PNG 검수](2026-11-14_영수증해석보존과관리자조회.md)
- **기존 회귀** · 별도의 Django PostgreSQL 시험 DB에서 영수증 작업과 제공자 전송 검사 20건을 통과했다.

## PowerShell 재현

Chrome, 잠금 의존성이 설치된 Django Python 3.12 가상 환경과 프론트를 준비한다. 아래 명령은 저장소 루트에서 실행한다. 포트 5551·5552·5553은 각각 이 검수용 PostgreSQL·Django·Vite다.

```powershell
docker run --rm -d --name arti-receipt-interpret-5551 -p 127.0.0.1:5551:5432 -e POSTGRES_DB=arti_receipt_interpret -e POSTGRES_USER=arti -e POSTGRES_PASSWORD=browser-only-receipt-db postgres:17-alpine
for ($receiptBootAttempt = 0; $receiptBootAttempt -lt 20; $receiptBootAttempt++) {
    docker exec arti-receipt-interpret-5551 pg_isready -h 127.0.0.1 -U arti -d arti_receipt_interpret
    if ($LASTEXITCODE -eq 0) { break }
    Start-Sleep -Milliseconds 500
}
if ($LASTEXITCODE -ne 0) { throw '검수용 PostgreSQL이 준비되지 않았어요.' }

$env:DJANGO_SECRET_KEY = 'synthetic-receipt-interpret-django-key-only'
$env:ARTI_ENV = 'test'
$env:ALLOW_TEST_FIXTURES = 'true'
$env:ARTI_LLM_PROVIDER = 'disabled'
$env:ARTI_MODEL_SERVICE_URL = ''
$env:OPENAI_API_KEY = ''
$env:PGHOST = '127.0.0.1'
$env:PGPORT = '5551'
$env:PGDATABASE = 'arti_receipt_interpret'
$env:PGUSER = 'arti'
$env:PGPASSWORD = 'browser-only-receipt-db'
$env:MEDIA_ROOT = Join-Path $PWD 'data/private/receipt-interpret-5551'
& backend-django/.venv/Scripts/python.exe backend-django/manage.py migrate --noinput
if ($LASTEXITCODE -ne 0) { throw '검수 DB 마이그레이션에 실패했어요.' }
& backend-django/.venv/Scripts/python.exe backend-django/manage.py load_test_fixture
if ($LASTEXITCODE -ne 0) { throw '합성 전시를 불러오지 못했어요.' }
& backend-django/.venv/Scripts/python.exe backend-django/manage.py shell -c "from arti.tests.receipt_interpret_browser_server import serve; serve()"
```

```powershell
$env:VITE_API_TARGET = 'django'
$env:VITE_API_BASE = '/api'

npm.cmd --prefix frontend run build
```
