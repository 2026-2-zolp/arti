# A-05 두 전시실 프리셋과 Luna 도판 v1

- `c51fac7`에 이어 A-05 **이동 구조 등록 → 복도로 연결된 두 전시실 불러오기**를 추가했다. 편집기에 전시실 2개, 벽 5개, 문 2개, 복도 1개, 연결점 6개를 채운다. 기존 형상이나 입력 중인 모서리가 있으면 교체 전에 확인한다. 입구와 작품 위치를 기준으로 미리 보고 **이동 구조 저장**을 누르면 현재 도면 버전에 반영된다.
- 합성 Chrome에서 교체 확인을 취소했을 때 그려 둔 기둥이 남았다. 프리셋을 불러오자 두 문과 복도를 통과했다. **이동 구조 종류 → 문 → 마지막 입력 취소**로 오른쪽 문을 빼면 미리보기 이동선이 사라졌다. 프리셋을 다시 불러오면 양쪽 문이 복구된다.
- 초기 편집과 프리셋 적용·문 제거 중 저장 요청은 0건이었다. 관람자 탭을 새로고침해도 기존 지도와 V2 3·5·7점 추천이 같았다. 문 하나를 제거한 채 첫 저장을 하자 관람자 지도는 해당 연결선 없이 안내를 표시했고 V2는 기존 순서를 유지했다.
- 양쪽 문을 편집기에 다시 불러왔을 때 관리자 미리보기는 연결됐지만 관람자 지도와 추천은 닫힌 상태로 저장한 결과를 보여 줬다. 두 번째 저장 뒤 해당 구간의 이동선이 복구됐고, 새 V2 추천 3·5·7점 모두 작품 ID·점수·태그·추천 이유를 유지한 채 순서가 달라졌다.
- 프런트 빌드·단위 검사 50건, 합성 PostgreSQL의 PC Chrome 지도·직접 관람 회귀를 통과했다. 직접 관람의 비회원 저장 요청 0건과 회원의 응답 유실 재시도 후 영수증 한 건도 확인했다.
- Luna 비교용 PNG 도판 L01·L02·L03과 UTF-8 원문 파일을 각각 v1로 고정했다. 도판 세 점은 다른 SHA-256이며 L01과 L03은 동일 원문으로 위치 불일치만 비교한다. 6개 파일의 SHA-256을 다시 계산하고, 도판은 육안과 Django 이미지 입력 함수에서 640×480 원본 바이트를 확인했다. 비교 점수는 실제 호출 재개 후 채운다.
