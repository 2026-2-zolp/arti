# 2026-11-11 · W06 핵심 3점 독립 검수 인수 준비

[TP4 작업기록](일지/2026-11-11_취향동점처리와관람반영.md#tp4-격리-통합-검증)에서 격리 기술 검증을 마쳤다. [기존 W06 검수 준비](일지/2026-11-09_유영국자료인수.md#시연-준비와-독립-검수)의 16점 도구는 전체 응답을 받도록 되어 있어 핵심 3점만 먼저 제출하면 초안이었다. 핵심 3점의 독립 의견을 우선 수집하고 이어서 콘텐츠와 취득 근거를 확인할 수 있도록 인수 단계를 구체화했다.

| 변경 전 | 변경 후 | 변경 위치 |
| --- | --- | --- |
| 16점 라벨링과 3점 콘텐츠 초안이 분산됨 | 기존 도구·태그 정의를 재사용해 원본 해시가 맞는 3점의 비공개 ZIP 생성. 도구는 묶음 크기에 맞춰 진행 상태 표시 | `scripts/build_yoo_core3_review.py`, 기존 `labeling.html` |

| 작품 식별·출처·콘텐츠·사용 근거의 판단이 여러 문서에 나뉨 | 단계별 전달물, 001·004·010 대응표, 항목별 인수 조건과 회신 양식 작성 | [핵심 3점 검수](../review/yoo-core3-2026-11-11/README.md) |

## 검증단 검토 결과

- 운영자·팀 인수 관점에서 기존 인수표와 국립현대미술관 개별 소장품의 제목·연도·관리번호를 3점 모두 대조했다. 수집 경위와 팀의 사용 범위는 기존 사용 범위 기록과 일치한다. 동일 작품 확인, 개별 캡처 URL·사용 근거·종료일, 콘텐츠 확정은 대기다.
- 검수자·평가위원 관점에서 ZIP에 라벨 도구·안내·중립 이름 이미지 3점만 들어가는지 확인했다. 작품 출처·해설·모델 점수·기존 응답은 ZIP에 넣지 않았다. 사전 노출과 모르겠음·미응답 처리, 기존 탐색 표본의 평가 한계를 기록했다.
- 기술 관점에서 ZIP 무결성·해시 3개·임베디드 manifest·JS 구문 검사를 통과했다. 3점·16점 각각의 합성 완료·초안 검증을 통과했고, TEST·다른 묶음·해시 불일치·작품 순서 중복·잘못된 완료 10건을 거부했다. 합성 응답은 검수 집계에 포함하지 않았다.
- 결과 묶음은 Git 제외 경로에 만들었다. 사람 검수, 서비스 데이터, 배포 상태의 변경은 없었다.

다음은 팀에 1차 묶음을 전달해 독립 응답을 고정하고, 2차에서 캡처 동일성·출처·사용 근거와 해설·가이드 회신을 받는 단계다. 세 작품의 적용 판단은 항목별 근거를 확인한 뒤 기록한다.
