## 맥락과 범위

직전 로컬 커밋 `c8fa850`의 [운영 구성·예산 결정 준비](2026-11-09_W12_운영구성과예산결정준비.md)는4GB 보수적 후보와 비용표를 정리했으나 소형 호스트의 실제 용량은 측정하지 않았다. 사용자가 제시한 부트캠프 소형 EC2/약10달러 맥락을 재검토하고, 1/2GB 후보의 웹·Django·PostgreSQL과 전체 분석 시간을 실제 코드로 검증했다. 팀원 작품 검수·AWS 계정 결정 없이 할 수 있는 W12/W07 선행·W05 유지보수이며 실제 W08 배포는 아니다.

## 검증 루프와 결과

1. 처음 용량 시험은 HTTP/저장/재시작을 통과했으나 메모리 측정이 누락됐다. Docker가 cgroup v1인데 v2 경로만 읽은 원인이었다. 이 결과를 용량 통과로 취급하지 않고 원시 JSON을 불합격/대체로 보존했다. v1/v2 분기·수집 실패 시 인수 실패·60초 지속 부하를 추가했다.
2. 수정 후 두 후보 모두 조회/추천·저장·지속 부하 p95<2초, 할당 실패/OOM0, 행 중복0·재시작 후 DB/이미지 보존을 통과했다. 50동시 혼합1,000요청의 p95는1GB 848.06ms/2GB 962.47ms다. API/DB/웹 피크는1GB 124.79/78.21/13.58MiB,2GB 142.29/79.38/13.82MiB다. 현재 표본에서 RAM 증가의 속도 이득은 확인되지 않았다.
3. 실제 static JS/CSS와 상세 재진입·API404를 확인했다.1GB JS100요청/10동시 p95 107.59ms다. 빌드는 목표 작은 서버 밖에서 수행하는 방식이다.
4. 시간 예산 도구의 import 범위·모의 서버 모듈 경로 오류를 보완하고 기동 확인을 추가했다. 실제 Nginx→Gunicorn→합성 LLM·모델 경로에서21+21+남은18초로 **60.133초504**, 이전 전체 스냅샷 동일을 확인했다. 분석 중 조회100건은200/p95 168.60ms였다. 복구200은0.394초·버전+1이었다.
5. 연결 중단 후에는 서버 처리가 완료돼 버전이 한 번 증가할 수 있다. 이전 버전 재전송은409·제공자 추가 호출0으로 확인했다. 서버 취소·미저장을 보장한다는 잘못된 설명을 문서에서 배제했다.
6. 실제 PG17 Django100개·Linux 모델24개·프론트23개/typecheck/build가 통과했다. 계획 정합 오류0·보호 원본38개 유지·가드레일32개·결과 증거/비용 계산도 통과했다. 원격 CI 성공으로 표현하지 않는다.

## 자체 검증단 관점

- 시니어 개발: 개별 timeout 합계 대신 공유 예산·늦은 값 저장 차단·버전/lock 회귀를 확인했다. DNS/지속 소량 전송·DB 잠금·worker 대기까지 강제 취소하는 SLA는 아니다. F27은 미종결이다.
- 운영/데이터: 개별 상한과 VM 전체 RAM을 구분하고 OS 여유·백업/배포 순간 부하·외부 모델 전제를 명시했다. 실패 증거·시험 볼륨을 보존하고 유영국/일반 DB는 사용하지 않았다.
- 방문자: 분석 한 건이 진행돼도 조회100건이 통과했지만 두 sync worker의 AI 동시 점유까지 보장하지 않는다. 연결이 끊긴 뒤의 저장 여부는 최신 조회로 확인해야 한다.
- 팀/교수/외부 평가위원: “부트캠프 소형 EC2라 가능”을 근거로 단정하지 않고 SQLite/외부 API 차이를 비교했다.1GB 최소 시험 가능성과2GB 운영 권장, 로컬 증거와 실제 AWS·사람 승인을 분리했다. 실제 팀원/교수 검토를 받았다는 뜻이 아니다.

## 결정과 후속

**1GB는 제한된 시연의 최소 시험 후보,2GB는 운영 여유를 둔 권장 후보**다. 최소 후보에는 모델 동거·서버 이미지 빌드가 포함되지 않는다. EC2 상시1GB 기본 소계는약$14.91이며, 간헐176시간은약$7.84다. Lightsail1GB 월 번들+가정 백업은약$7.13이다. 유료 GPT·추가 과금/세금·외부 모델 호스트 비용을 포함한10달러 보장이 아니다. 기존4GB가 필수라는 결론은 수정한다.

AWS Core는 Data Analytics와 다른 AWS 공식 도구로 확인했다. IAM·비용·관측·배포 설계에 적합하므로 준비 단계 도입은 권장하지만 설치/계정 연결은 하지 않았다. 인프라를 ECS/Bedrock/RDS로 확장하는 근거로 쓰지 않는다.

다음 한 작업은 **운영형 설정·프록시 계약과 DB TLS/배포 준비의 로컬 검증**이다. 이번 static은 HTTP 격리 준비다. 실제 계정/총상한·종료일 후 최소 후보에서 TLS/접근 제한·백업/복원·CPU credit·실제 지연을 확인해야 W08/GOPS를 판단한다. 팀원 콘텐츠/라벨·최신 원격 CI/PR·정식 W07 품질 평가는 남아 있다. 이번 결과로 해당 게이트를 올리지 않고 로컬 커밋만 남긴다.
