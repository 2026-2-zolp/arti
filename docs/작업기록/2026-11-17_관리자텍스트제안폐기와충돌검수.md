# 11/17 관리자 텍스트 제안 폐기와 두 탭 충돌

- 기준은 [PR #44](https://github.com/2026-2-zolp/arti/pull/44) 병합 커밋 `d0c1db1`이다. 관리자 A-04에서 저장된 쉬운 요약과 관람가이드 제안을 항목별로 폐기할 수 있다. 확인 대화상자에서 취소할 수 있고, 서버는 보낸 작품 버전과 현재 제안 상태를 확인한다.
- 공개본이 있으면 확정된 문안과 근거 개정 번호를 복구한다. 공개 이력이 없는 관람가이드 제안을 폐기하면 관람자에게 기본 감상 팁이 계속 표시된다. 폐기는 선택한 항목의 데이터만 저장하며, 관리자 화면에서 편집 중인 다른 필드는 로컬 입력으로 유지된다.
- 다른 탭에서 먼저 확정한 뒤 이전 제안을 폐기하거나, 먼저 폐기한 뒤 다른 탭에서 이전 제안을 확정하면 `409 VERSION_CONFLICT`다. 두 경우 모두 최신 관리자 응답을 비교해 추가 반영이 없음을 확인하며, 충돌 안내에서 작성 중인 입력을 유지하고 사용자가 최신 작품을 다시 불러올 수 있게 한다.
- 합성 PostgreSQL에서 Django 통합 테스트 34건을 통과했다. 기존 공개 요약 복구, 첫 가이드 제안 폐기, 관리자 권한, 다른 항목 보존, 오래된 버전과 폐기할 제안이 없는 요청을 검수했다. 새 마이그레이션은 없다. [Django 회귀](../../backend-django/arti/tests/test_integration.py)
- 관리자 PC Chrome에서 취소, 첫 제안 폐기, 확정 다음에 폐기와 폐기 다음에 확정의 두 탭 경쟁, 최신 상태 다시 조회, 이전 공개 가이드의 내용·버전과 같은 도슨트 문맥을 확인했다. 기존 분석·확정 충돌과 승인 철회도 같은 모의 시험에서 통과했다. 프론트 시험 47건과 프로덕션 빌드를 통과했다. [관리자 Chrome](../../frontend/tests/adminAnalysis.browser.mjs)
