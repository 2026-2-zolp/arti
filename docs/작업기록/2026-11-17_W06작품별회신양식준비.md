# 11/17 W06 작품별 회신 양식 준비

핵심 3점은 작품 대응 3/3, 시연 채택 0/3이다. 기존 도판·문안 기준에서 실제 접수할 양식을 만들고 접수 결과를 다시 확인했다. [W06 통합 인수표](../operations/2026-11-13_W06_팀검수통합인수표.md) · [도판 기준 manifest](../../data/intake/2026-11-09-yoo-youngkuk/core3-manifest.json)

| 작품 | 양식에 지정할 기록 ID |
| --- | --- |
| 001 바다 | `yyk-intake-20261109-001` |
| 004 산(남) | `yyk-intake-20261109-004` |
| 010 산 | `yyk-intake-20261109-010` |

1. 저장소 루트에서 `python scripts/yoo_core3_receipt.py --template yyk-intake-20261109-001`을 실행한다. 표의 기록 ID를 바꿔 세 작품의 출력 JSON을 비공개 접수 경로에 각각 저장한다.
2. 광권에게 받은 원 취득 URL·제공자·파일을 인수표에서 대조한다. 회신 JSON에는 실제 전달 도판과 검수자가 본 문안의 SHA-256을 입력한다. 문안 해시는 LF 줄바꿈으로 계산한다. 해설·쉬운 요약·질문·힌트에 각 검수자, 일자, 판정, 구절과 근거를 적는다.
3. 교내 시연·발표 자료·녹화·외부 URL마다 해당 매체 담당자가 확인한 대상·기간·표시와 근거를 기록한다. 한 매체의 확인은 그 행에 입력한다. `python scripts/yoo_core3_receipt.py <회신.json>`을 실행해 도판·문안과 검수 결과를 대조한다. [회신 필드와 매체 기준](../review/yoo-core3-2026-11-11/README.md)
4. `ready-for-review`가 나오면 해당 매체의 원 회신, 도판 대조와 실제 좌표를 담당자가 함께 확인한다. 승인된 자료는 전시·작품 상세·지도·추천·도슨트 근거에서 같은 작품과 버전을 가리키는지 검수한다. [합성 재현 기록](2026-11-17_작품확정폐기철회와관람연결.md)

빈 양식 세 건은 모두 문안 4항목과 사용 매체 4개가 대기였다. 빈 해시와 판정을 자동으로 채우지 않는 조건을 접수 회귀에 추가했다. 스크립트 검사 70건과 합성 PostgreSQL의 W06 접수·관람 연결 검사 2건이 통과했다.
