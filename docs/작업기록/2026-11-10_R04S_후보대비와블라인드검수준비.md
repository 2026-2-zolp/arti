## 변경 전 → 변경 후와 건드린 곳

- 모델 비교 보고에 흩어진 후보/대비 가설 → `docs/review/taste-survey-2026-11-10/matrix.json`과 기준표에21개 식별/출처/해시/미확정,18개 대비 가설·공통특징·교란을 정리했다. 이전 A/B/C의13쌍과 정물/인물/풍경/도시/군상 폭을 넓히는 추가5쌍을 구별했다. 후자는 새 모델/추천 점수 측정이 아니다.
- 운영자 설명과 검수자가 볼 자료의 구분 미정 → 익명코드·이미지·중립질문만 포함하는 오프라인 HTML 생성기와 틀을 추가했다. 운영자 매핑·기준표·가설/작품명/출처/모델점수는 생성된 검수자 HTML에 넣지 않았다. 원본이미지21개는 해시 확인 후 바이트 그대로 내장하며 이미지/서명 자체의 식별 가능성은 남는다.
- 강제 선택/미응답 해석의 여지 → 기본 미선택,둘다/둘다아님/어려움,표시품질·익숙함·사전 노출을 구분했다. V2는 V1의 작품/쌍순서를 반대로 하고 좌우를 전부 교환한다. 같은 사람이 두 버전을 수행해 인원을 부풀리지 않는다.
- 중간 중단/인수 규칙 미정 → 초안·완료 JSON 저장과 복원,해시/버전/순서/좌우/중복/값/완료 검증을 추가했다. 시험 응답은 기본 거절,명시 시험옵션에서만 확인하며 승인·독립성·정확도를 자동 판정하지 않는다.
- 자료 준비와 품질 인수 혼재 가능성 → CP1~CP4 준비 기준·운영자 배정/원응답 보존·기권/분모/노출층·독립 라벨과 선호 분리·채택 보류를 문서화했다. 공식 W/G/AC 상태는 그대로다.

변경 파일은 신규 검수 도구/HTML틀·기준/매핑/절차/검증·테스트와 계획/목록이다. 제품 프론트·Django·FastAPI·기존 모델 설정/라벨·조사풀·DB/미디어는 건드리지 않았다. 모델/GPT 호출·새 외부 자료 다운로드도 없다. 기존 유영국16점은 보존하며 이번21점은 별도 검수 재료다.

2. 방문자:브라우저에서57이미지 로드,기본 미선택·미완료 제출 차단,21점 확인 후18쌍 진입을 확인했다. 시험 초안/완료 JSON이 실제 다운로드됐고 Python검사를 통과했다. 파일 복원 API가 확장 권한으로 막혀 JSON붙여넣기 복원을 추가했고 실제 초안 복원과 다른버전 거절을 확인했다. 보안 설정은 변경하지 않았다. 자동 다운로드 이벤트 대기는 timeout됐으나 다운로드파일 존재·내용을 별도로 확인했다. 모바일 실기기/사람 사용성 검증은 아직이다.
