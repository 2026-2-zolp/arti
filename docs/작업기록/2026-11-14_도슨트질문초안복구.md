# 11/14 도슨트 질문 초안 복구

- `029e141`에서 도슨트 질문 전송 중 작품 자료 버전이 바뀌는 흐름을 점검했다. 기존 질문 입력은 화면 상태에만 있어 작품을 다시 열면 사라졌다.
- 미전송 질문은 계정·전시·관람·작품별로 현재 탭에 보관한다. 같은 작품으로 돌아오거나 새로고침하면 복원하며, 전송에 성공한 질문은 초안에서 지운다. 대화 기록과 관찰 질문의 근거는 기존 자료 버전별로 구분한다.
- PC Chrome 합성 API에서 첫 답변 뒤 자료 변경 오류를 발생시켰다. 작품 화면으로 복귀하고 새로고침한 뒤 질문을 다시 보냈을 때 새 자료 버전 2와 빈 이전 대화 목록을 확인했다. 성공 후 초안 삭제 및 다른 작품으로 이동할 때 입력 분리도 확인했다. 프론트 검사 43건, 프로덕션 빌드, 관람 브라우저 12개 조건 통과.
- 이후 PC에서 진행할 수 있는 검증은 영수증 저장 응답 유실 후 서버 기록과 재시도 일치 여부, 합성 자료의 복원 환경에서 관리자 조회 재현이다. 실제 도판·도슨트 답변과 카카오 실연동은 각각 팀 자료와 시험 환경을 기다린다. [잔여 계획](../execution-plan/2026-11-07/15-remaining-work-2026-11-13.md)
