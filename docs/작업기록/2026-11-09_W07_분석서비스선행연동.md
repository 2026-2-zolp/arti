# W07 선행 경계와 Django 분석 서비스 연동

2026-11-09 / 출발 f596e3d / dev/임준억. 팀원 검수 전 진행 가능한 추천 순서에 따라 선행 경계를 반영하고 분석 서비스를 연결했다. 이전 [원격 공유 기록](2026-11-09_원격공유와CI확인.md) 이후 작업이며 이번에는 로컬 커밋만 한다.

## 배경과 변경 전후

GPT 텍스트는 연결돼 있었지만 Django의 태그·감정 분석은 503이었다. W06 전체 완료를 요구하는 W07 의존성을 삭제하지 않고 execution.json에 선행 구현 범위를 추가했다. W06 사람 검수와 정식 AI 품질/G5 조건을 유지한다.

model_service.py가 기존 FastAPI /analyze에 승인 원문과 서버 보관 이미지를 전달하고 응답을 검증한다. providers.py는 텍스트와 분석 제공자를 분리하고 editing.py는 태그·감정이 같은 분석 결과를 공유하게 했다. settings.py·Compose·env 예시는 기본 비활성인 ARTI_MODEL_SERVICE_URL을 추가했다. GPT나 Kanana로 분석을 대신하지 않는다. 기존 모델 서비스를 새로 작성하거나 모델을 교체하지 않았다.

파일 경로·크기와 응답 크기, 전체 점수 범위/누락, 이미지 처리 성공, 모델명과 실제 입력 사용을 검사한다. 리다이렉트와 외부 이미지 URL 전달을 막으며 timeout/서비스 오류는 명시적으로 반환한다. 기존 승인 원문·suggested 저장·독립 확정·버전 충돌 정책을 유지한다.

## 검증 루프

Windows 샌드박스 첫 실행은 임시 파일 권한과 로컬 HTTP 접근 실패로 실패했다. 시험을 약화하지 않고 분리 Linux 컨테이너로 옮겨 기존 provider 포함 16개가 통과했다. 이후 독립 PostgreSQL 전체 90개, 실제 API 저장/실패 보존 검사 추가 후 92개를 통과했다. timeout·대용량 응답 검사를 추가해 최종 전체 93개가 36.173초에 통과했다. 최종 근거는 [검사 로그](../execution-plan/2026-11-07/records/W07-preparation/model-integration/postgres-tests.log)에 남긴다.

계획 구조 errors 0·원본 보호 38개 유지, guardrail 25개, W02 정적 계약 검사 errors 0을 확인했다. 프론트 파일은 바꾸지 않아 프론트 검사는 재실행하지 않았다.

기술/시니어·데이터/운영·방문자/콘텐츠·팀/교수/평가위원의 관점별 자체 검토에서 자동 승인·가상 모델 성능 오인·외부 이미지 접근을 점검하고 실행 안내와 제한을 보완했다. 실제 외부 검수자의 승인은 아니다.
