# 11/17 AI 운영 로그·계정 복구·지도 병렬 검수

## 관리자 AI 운영 로그

- 합성 작품 한 요청에서 쉬운 요약 성공, 관람가이드 `PROVIDER_ERROR`, 감정 분석 `AI_TIMEOUT`, 취향 태그 비활성화를 만들었다. HTTP `200`을 유지했다. 운영 로그의 **오류만 보기**에는 요청 ID, 두 실패 항목과 코드가 있고, 오늘 분석 부분 실패는 한 건 늘어난다. 설정에서 꺼 둔 항목은 집계에서 제외된다.
- 운영 이벤트가 저장하는 부분 실패는 서버에서 정한 항목명과 오류 코드다. 프롬프트·도판·모델 답변·키·제공자 상세 오류는 저장 대상에서 제외했다. 기존 응답 코드 기반 오류와 부분 실패는 대시보드에서 각각 표시한다. Django 마이그레이션 `0011`이 기존 이벤트에 빈 실패 목록을 채운다.

## 회원 비밀번호 재설정

- 로그인 도움에서 등록 주소로 링크를 요청하고, 편지함의 링크로 새 비밀번호를 설정할 수 있다. 등록·미등록 주소는 같은 빈 `204`를 받는다. 마이그레이션 `0012`는 요청과 메일 발송 상태를 저장한다. 메일은 별도 명령에서 보내고 만료된 요청을 정리한다.
- 원본 비밀번호, 사용한 링크, 같은 계정의 앞서 발행된 다른 링크와 세션을 차단했다. 동시 제출 두 건은 `204` 한 건과 `PASSWORD_RESET_INVALID` 한 건이었다. 다른 계정 세션과 같은 계정의 기존 영수증·카카오 연결이 유지됐다. 임시 메일 실패는 발송 대기 상태로 남기고 다음 발송에서 복구했다.
- PC Chrome에서 메모리 메일함으로 요청하고 링크를 열었다. 주소에서 링크 값이 지워지고, 같은 링크를 다시 열어도 재사용이 차단됐다. 새 비밀번호로 기존 회원 ID에 재로그인했다. [환경 변수·발송 명령·재현 절차](../operations/비밀번호재설정_로컬검수와배포준비.md)

## A-05와 카나나

- 경로가 끊기면 A·B 각각에 가까운 문·통로·연결점을 하나씩 제시한다. 후보 버튼을 누르면 관리자 지도에서 위치가 강조된다. 갈림길 Chrome에서 후보 강조, 저장 전후 우회, 관람자 지도에 관리자 표시가 나타나지 않는지, 다른 탭 저장 충돌 `409`를 확인했다.
- Kanana-2 3B 모의 주소에 고정 원문 `L01`~`L03`을 보내 요약·가이드 6건, 형식 오류 `502`, `429`, 타임아웃 `504`와 재요청을 확인했다. 모의 요청은 관리자 초안 주소로만 갔다. WSL은 사용 가능 메모리 약 10.3GiB였고 기본 Python에서 `torch`·`transformers`·`vllm`은 확인되지 않았다. [카나나 모의·실행 준비](../operations/2026-11-17_도슨트모델과관리자운영검토.md#kanana-2-초안-연결-재현)
