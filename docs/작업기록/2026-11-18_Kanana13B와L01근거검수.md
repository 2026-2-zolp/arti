# 2026-11-18 Kanana 1.3B와 L01 근거 검수

## 검수 환경과 통과 기준

- Ubuntu WSL CPU에서 카카오 공식 `kanana-2-1.3b-instruct` 개정 `bf4786aa2a1908adce942d53976270132732f720`를 사용했다. `model.safetensors`는 2,582,997,160바이트이며 SHA-256은 `49aa6cd8686563c59321d83810731956c61ec8d5c8538a249d38007986cdc942`이다. 가중치 해시와 공식 코드·토크나이저 등 6개 파일의 Git Blob 해시를 대조했다. [모델 카드와 고정 리비전](https://huggingface.co/kakaocorp/kanana-2-1.3b-instruct/tree/bf4786aa2a1908adce942d53976270132732f720)
- 1.3B는 슬라이딩 윈도우와 전체 어텐션에 서로 다른 RoPE를 사용한다. 해당 모델을 지원하는 변환기가 설치된 llama.cpp에 확인되지 않아 공식 Transformers 구현을 사용했다. 처음 로드한 4.57.3에서는 `check_model_inputs` 호출 규약 차이로 추론 진입이 실패했다. 검수 프로세스에서 데코레이터 호출 방식만 맞춰 재시험했다. [공식 구현](https://huggingface.co/kakaocorp/kanana-2-1.3b-instruct/blob/bf4786aa2a1908adce942d53976270132732f720/modeling_kanana2_tiny.py)
- 모델은 PyTorch `2.8.0+cpu`와 SDPA로 실행했다. YaRN에 지정된 factor `40`과 컨텍스트 길이 비율 `8` 차이에 대한 경고가 나왔고, 공식 설정대로 명시값 `40`을 유지했다.
- 이전과 동일한 합성 L01 원문 SHA-256 `bc94c61d4895e5c63f7f795fa1761cf8471770c87923db1e6ba25b3394f24ff1`와 현재 ARTI 요약·가이드 프롬프트를 사용한다. WSL 루프백의 동일한 Chat Completions 요청으로 요약·가이드를 번갈아 3회씩 실행한다. 완료 판정은 25초 이내 HTTP 200·정상 종료·Django 형식 검사 통과다. [L01 원문](../review/docent-2026-11-15/luna-fixtures/L01-source-v1.txt) · [ARTI 요청 계약](../../backend-django/arti/llm.py)
- 근거 검수에서는 파란 바탕, 왼쪽 위 작은 노란 원, 오른쪽 넓은 흰 여백, 아래쪽의 가는 가로 빨간 선을 대조한다. 요약·도입문의 사실과 질문·힌트의 전제를 모두 확인한다. 새로운 작가 의도나 작품 사실을 단정하거나 위치·색·방향을 틀리게 전제하면 해당 응답을 근거 오류로 판정한다.

## 응답 시간과 JSON

고정 프롬프트로 제약 디코딩 없이 생성한 원문을 그대로 검사했다. 프롬프트 토큰 수는 요약 302개, 가이드 298개였다. 25초 경계에서는 토큰 생성이 끝나는 지점에서 중단하므로 측정값이 약간 초과할 수 있다.

| 실행 경로 | 요약 1·2·3 | 가이드 1·2·3 | 25초 내 유효 JSON |
| --- | --- | --- | ---: |
| BF16 CPU 6스레드, SDPA | 25.901초 중단 / 18.496초 일반 텍스트 / 25.201초 중단 | 25.612초 중단 / 25.279초 중단 / 25.337초 중단 | 0/6 |
| CPU 4스레드, x86 동적 INT8 선형 계층, SDPA | 26.412초 중단 / 25.608초 중단 / 26.533초 중단 | 25.072초 중단 / 26.676초 중단 / 25.453초 중단 | 0/6 |

- BF16에서 완성된 일반 텍스트 요약은 파란 바탕·노란 원·흰 여백·빨간 가로선을 유지했다. 세 가이드는 25초에 잘렸다. 근거를 더 보기 위해 별도로 80초까지 실행한 가이드도 80.025초에 첫 힌트 도중 끊겼다. 도입문의 색과 방향에 원문과 충돌하는 사실은 없었다. 질문은 빨간 선을 왜 그렸는지 물어 원문만으로 답하기 어려운 작가 의도까지 요구했다. 완성된 가이드가 없어 근거 오류 0건 기준은 확인할 수 없었다.
- INT8 양자화 준비에는 63.872초가 걸렸다. 이후 요약·가이드 첫 토큰은 나왔지만 6건 모두 말줄임표를 반복했다. 근거를 판정할 내용과 유효 JSON이 없었다.
- 두 경로 모두 6/6회 기준에 미달했다. Kanana를 연결한 A-04의 기존 확정본 유지 검수는 후속으로 남긴다. 원시 계측과 실행기는 `data/private/arti-kanana-13b-1118/`에 보관했다. `measure-13b-bf16.json`과 `measure-13b-int8.json`이 25초 판정 기록이고, `guide-diagnostic.json`은 근거 확인용이다.

## 병렬 회귀

- **운영 로그·비용** · 현재 브랜치에서 새로 빌드한 PC Chrome으로 관리자 접근, 작업·모델별 사용량과 캐시 누락, 요청 ID, 오류 필터, 요청 본문 미노출을 확인했다. OpenAI Usage 정규화 3개도 통과했다.
- **A-05 지도·관람** · 직접 관람의 비공개 작품 건너뛰기, 앱·브라우저 뒤로가기와 새로고침, 비회원 영수증 저장 요청 0건, 응답 유실 후 같은 회원 영수증 ID 1건, 기존 V2 5쌍 선택을 합성 PC Chrome에서 검수했다.
- **비밀번호 재설정·카카오** · 합성 Chrome에서 재설정 링크 1회 소비·이전 세션 폐기·동일 회원 로그인 복귀를 통과했다. 모의 카카오를 포함한 Django 운영·계정 회귀 27개도 통과했다.
