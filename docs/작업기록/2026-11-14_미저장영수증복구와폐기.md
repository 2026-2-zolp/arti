# 11/14 미저장 영수증 복구와 폐기

- 최신 `main` `d8cd38c`에서 팀 회신 없이 검증할 수 있는 미저장 영수증을 점검했다. 합성 회원으로 저장 실패 후 마이페이지에서 기록을 버리고 브라우저 뒤로가기를 누르자 기존 영수증 주소가 다시 열리는 것을 재현했다. 복구 목록의 항목만 지워지고 영수증 캐시와 완료된 관람은 남아 있었다.
- 버리기를 확인하면 해당 기록과 영수증·해석 캐시를 지운다. 버린 기록의 방문 ID가 현재 관람과 같을 때에만 관람을 초기화한다. 이전 방문의 미저장 기록을 버릴 때에는 진행 중인 관람을 이어갈 수 있다.
