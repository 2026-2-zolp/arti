# A-05 원본 도면 맞춤과 Luna 합성 등록

- 기준은 로컬 `7f631a3`이다. 원본 이미지가 있는 A-05에서 두 전시실 프리셋을 불러온 뒤 **원본 도면에 맞추기**를 누르고 맞은편 모서리 두 곳을 선택한다. 선택한 영역에 맞춰 전시실·벽·기둥·문·복도와 연결점을 함께 옮기고, 가로와 세로 크기를 각각 조정한다. 입구와 작품의 이미 저장된 위치는 선택한 영역의 경로를 검수하는 데 사용한다.
- **제안 연결점 추가**는 문이 관람 가능 공간과 복도에 모두 맞닿을 때, 문 양쪽과 이어지는 복도 중앙의 통행 가능한 점을 편집기에 추가한다. 벽이 막은 문을 잇는 점과 기존 점에 겹치는 후보는 제외한다.
- 640×360 합성 원본 도면에 프리셋을 맞추고 기존 연결점 6개를 제거하자 실 사이 경로가 끊겼다. 제안 연결점 6개를 더하면 두 문과 복도를 지나는 미리보기가 복구됐다. 저장 전 전시 API가 같았고, 저장 후 같은 도면 버전과 관람자 이동선을 읽었다. 기존 문 개폐와 V2 3·5·7점 구성 유지·재정렬도 Chrome에서 확인했다.
- Luna v1의 L01·L02·L03을 별도 합성 A-04에 등록했다. 업로드 뒤 출처 확인 상태에서 해시를 대조하고 승인했다. 관리자 API와 Chrome 작품 편집 화면에서 원문·도판의 SHA-256이 모두 일치했다. 작품 3점과 도판은 비회원 API에서 404였다. [Luna 평가표와 발급 작품 ID](../review/docent-2026-11-15/Luna_원문과도판_비교평가표.md)
- 프런트 프로덕션 빌드·단위 검사 52건, 지도·직접 관람 Chrome, A-04 원문·PNG Chrome을 통과했다. 모델 호출과 실기기 검증은 보류했다.
