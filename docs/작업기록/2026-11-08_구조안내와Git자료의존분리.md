# 구조 안내와 Git 자료의 legacy 의존 분리

2026-11-08 KST / 기준858b629 / dev/임준억. 이전 [개발 실행 일관화](2026-11-08_Django개발실행일관화.md) 후 사용자 요청으로 현재 구조와 Git 자료 점검을 진행했다.

이전에는 기본 실행은 Django로 바뀌었어도 구조표/주석/자료 안내에 Express가 현재 서버로 남아 있었고, 캡처 exporter도 backend 안의 해설 파일을 직접 읽었다. 루트 역할표·data/scripts 안내·프론트 주석을 현재 Django 계약과 맞추고, 해설 입력을 data/reference/git-captures의 원본 추적 가능한 사본으로 분리했다. 기존 backend/ai-service는 수정하지 않았다.

참조 사본은 ae0의 Git blob을 바이트 그대로 추출했다. provenance로 commit/blob/SHA256/크기를 연결하고 이미지·메타데이터·라벨의125개 자산을 점검한다. scripts/git_materials.py에서 읽기전용 검사와 exporter의 공통 경로/ID/내용 검증을 제공한다. exporter는 backend 없는 사본에서도 작동하며 기존 출력/원본 영역에 덮어쓰지 않는다.

실제 캡처40점·WikiArt 이미지파일79개·감정예시11건을 구분해 확인했다. 경로차이40건과 checkedAt=null을 기록했다. 내용 사실/출품/권리·사람검수나 로컬DB 부재를 추론하지 않았다. 기존 importer의 draft/source_check 정책은 유지하며 승인·좌표를 추가하지 않았다.

검증은 Windows/Linux의 새 자료7검사, 프론트17검사, actionlint, 이전 exporter와의40payload/이미지 동일성 비교로 진행했다. 임시폴더 권한과 모호성 fixture의 잘못된 사전조건을 고친 경위를 상세 기록했다. 검증단의 오래된 문서 현재형 지적도 보완했다. [실행 근거·판정](../execution-plan/2026-11-07/records/git-materials/README.md).

분리한 범위는 현재 자료 복원 도구의 legacy 디렉터리 의존이다. 과거 W03 재현과 원래 시드·모델 자료는 보존하고 Express 실행 선택도 유지한다. W06의 기존자료 점검을 진행한 것이며 유영국 실제자료·평가 기준·전체게이트는 미완료다. 로컬커밋만 만들고 원격push는하지않는다.
