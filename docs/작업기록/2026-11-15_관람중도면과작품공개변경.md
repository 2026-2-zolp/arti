# 11/15 관람 중 도면·작품 공개 변경

- **기준** · `main` `0caa1c2`. 합성 전시와 PC Chrome으로 관리자 도면 교체, 다음 작품 비공개 전환, 관람자의 지도·감상·영수증을 검수했다.
- **재현** · 추천 도중 다음 작품이 공개 목록에서 빠지면 지도에서 재시도해도 같은 화면에 머물렀다. 지도에서 본 작품이 감상 화면 진입 전에 비공개가 된 경우에도 같은 문제가 있었다.
- **수정** · 지도에서 현재 작품이 공개 목록에 없거나 감상 API가 404를 돌려주면 재시도와 건너뛰기를 제공한다. 503 등 조회 장애에는 기존 재시도 경로를 사용한다. 건너뛰면 진행 위치만 바뀌고 관람 ID, 이미 감상한 작품과 반응·체류 시간은 유지된다. 이동 구간은 마지막으로 감상한 작품을 기준으로 그리며, 도면 교체로 좌표가 지워진 경우 위치 부족 안내를 표시한다.
- **실제 API 검수** · 관리자 화면에서 합성 전시의 도면을 교체하고 다음 작품 B를 검수 대기로 전환했다. 회원 V2 관람에서 새 도면과 위치 부족 안내가 보였고, 뒤로가기와 재시도 뒤 B를 건너뛰어 C·A를 순서대로 저장했다. C의 반응 이유가 남았고, 영수증을 새로고침해 다시 저장 요청이 나가도 같은 회원의 서버 관람기록은 한 건이었다.
- **회귀** · 브라우저에서 비공개 전환이 지도 조회 전과 작품 진입 사이에 일어나는 두 경로를 추가했다. 두 경우 모두 앞 작품 체류 4초와 뒤 작품 2초를 유지했고, 건너뛴 작품은 영수증에서 제외했다.
- **범위** · 이번 변경은 다음 작품을 건너뛰는 복구다. 이미 감상한 작품이 저장 전에 비공개로 바뀌는 경우에는 서버의 공개 작품 저장 검사가 적용된다. 이 경우의 저장 정책은 작품 공개와 과거 기록 보호 기준을 확인한 뒤 다룬다.
