## 기존 ZIP에서 확인한 범위

성현님이 전달한 `frontend (1).zip`은 당시 `ce5e487`과 정적으로 대조했다. 줄바꿈 정규화 후 52개 파일이 같고 23개가 달랐다. ZIP의 UI 변경은 제품 반영과 브라우저 검증이 대기다.

| 현재 브랜치 기준을 유지하는 항목 | 조사 API를 전시별 호환 경로로 바꾸는 변경, 작품을 자르는 `cover`, 같은 시간으로 복귀하는 분기 제거, 해설 문단 스타일 제거, 닉네임 12자 제한, 기존 회귀 시험 누락은 현재 적용 범위에서 제외했다. |

[동섭님 통합 브랜치](https://github.com/2026-2-zolp/arti/tree/dev/김동섭-1106-merge) · [성현님 중간본 대조 기록](2026-11-11_R04_프론트인수와동점처리계약.md)

## 팀원이 실행해서 확인하는 방법

[PC·휴대폰 검증 가이드](../operations/프론트인수_PC와휴대폰검증.md)를 먼저 따른다. PC Chrome 모바일 모드로 모든 팀원이 화면을 빠르게 확인하고, 수정본의 키보드·터치·시스템 뒤로가기·음성·PNG 저장은 실제 휴대폰에서 확인한다. 서로 다른 장소에 있다면 각자의 PC와 폰을 같은 Wi-Fi에 연결해 가이드의 로컬 환경을 사용한다.

| 순서 | 현상과 관련 코드 | 적용 기준 |

외부 공개 준비에서는 가입 체크박스에서 원문을 읽을 수 있게 한다. ARTI 노션과 저장소를 확인한 범위에서는 연결할 원문을 찾지 못했다. 팀이 실제 수집 항목·목적·보관·삭제 기준을 정리해 문서를 준비한다. 비밀번호 재설정은 서버가 현재 501을 반환하므로 화면 문구와 실제 제공 범위를 맞춘다.

## 실제 후보 이미지로 본 작품 비교 배치

기존 검수 후보 P01·P14·P15를 사용해 이미지 원본 비율을 유지한 상하 압축형과 좌우 2열 시안을 만들었다. Chrome 모바일 에뮬레이션 320×667·360×740·412×820에서 3쌍 모두 양쪽 카드가 화면 안에 들어왔다. 실제 후보를 읽은 로컬 비교이며 후보 선정과 사용 범위는 기존 검수 절차를 따른다.

| 확인 지점 | 상하 압축형 | 좌우형 |
| --- | --- | --- |
| 360×740의 두 번째 카드 하단 | 화면 상단에서 639~658px | 489~508px |
| 360px의 P01·P14 첫 이미지 표시 폭 | 249px·232px | 각각 141px |
| 320×667의 두 번째 카드 하단 | 620~639px | 489~527px |

**권고는 상하 압축형을 먼저 구현하는 것**이다. 이번 비교에서는 두 작품을 동시에 보면서 가로 구도의 세부를 더 크게 볼 수 있었다. 실제 제품 헤더·진행 표시·긴 작품명·하단 안전 영역을 넣어도 두 카드가 함께 보이는지 재확인한다. 프론트 검수에서 위아래 시선 이동이나 세로 작품 가독성이 더 문제라면 좌우형을 다시 비교한다.

다음 쌍은 미리 불러오고, 탭 후 선택 상태가 보이는 짧은 전환을 준다. 이미지가 늦어지면 비교 영역의 크기를 유지하고 로딩을 표시한다. 같은 탭으로 두 단계가 넘어가지 않게 하고, 움직임 줄이기 설정에서는 전환을 줄인다.

## 검증단 관점과 갤럭시 재검증

- **방문자·평가위원**은 갤럭시 S24+ / One UI 8.5 / Android 16 / Chrome 세로 화면에서 두 작품을 한눈에 비교하고 선택 결과를 인지할 수 있는지 확인한다. 가로·세로 후보, 긴 제목, 느린 이미지에서 같은 기준을 쓴다.
- **기술·시니어**는 취향 확정 전후와 저장 취향 재사용에서 선택·버전·충돌 보호를 확인한다. 근거를 다시 불러와도 상하 이동이 없고, 영수증 앱·시스템 뒤로가기가 되돌아가는 화면을 각각 확인한다.
- **콘텐츠·운영**은 갤럭시 PNG에서 ‘따뜻한 색감’ 한 줄, 긴 태그와 여러 칩 배치, 좋아요·싫어요 이유 표시를 확인한다. 같은 합성 전시 결과는 UI 기준으로 쓰고 작품 태그와 도슨트 품질은 검수 자료를 넣어 후속 시험한다.
- 회신은 기종·브라우저, 재현 순서, 기대/실제 결과와 해당 스크린샷 또는 PNG를 남긴다.

다음은 담당자 조율 → 1차 결함 수정 → 두 작품 압축 배치의 갤럭시 확인이다. 이후 다음 작품 안내, 감상 확대·관람가이드, 영수증 정보 구조, 작품별 도슨트 질문·음성 비교를 별도 작업으로 이어간다.
