## 실제 후보 이미지로 본 작품 비교 배치

기존 검수 후보 P01·P14·P15를 사용해 이미지 원본 비율을 유지한 상하 압축형과 좌우 2열 시안을 만들었다. Chrome 모바일 에뮬레이션 320×667·360×740·412×820에서 3쌍 모두 양쪽 카드가 화면 안에 들어왔다. 실제 후보를 읽은 로컬 비교이며 후보 선정과 사용 범위는 기존 검수 절차를 따른다.

| 확인 지점 | 상하 압축형 | 좌우형 |
| --- | --- | --- |
| 360×740의 두 번째 카드 하단 | 화면 상단에서 639~658px | 489~508px |
| 360px의 P01·P14 첫 이미지 표시 폭 | 249px·232px | 각각 141px |
| 320×667의 두 번째 카드 하단 | 620~639px | 489~527px |

**권고는 상하 압축형을 먼저 구현하는 것**이다. 이번 비교에서는 두 작품을 동시에 보면서 가로 구도의 세부를 더 크게 볼 수 있었다. 실제 제품 헤더·진행 표시·긴 작품명·하단 안전 영역을 넣어도 두 카드가 함께 보이는지 재확인한다. 프론트 검수에서 위아래 시선 이동이나 세로 작품 가독성이 더 문제라면 좌우형을 다시 비교한다.

다음 쌍은 미리 불러오고, 탭 후 선택 상태가 보이는 짧은 전환을 준다. 이미지가 늦어지면 비교 영역의 크기를 유지하고 로딩을 표시한다. 같은 탭으로 두 단계가 넘어가지 않게 하고, 움직임 줄이기 설정에서는 전환을 줄인다.

## 검증단 관점과 갤럭시 재검증

- **방문자·평가위원**은 갤럭시 S24+ / One UI 8.5 / Android 16 / Chrome 세로 화면에서 두 작품을 한눈에 비교하고 선택 결과를 인지할 수 있는지 확인한다. 가로·세로 후보, 긴 제목, 느린 이미지에서 같은 기준을 쓴다.
- **기술·시니어**는 취향 확정 전후와 저장 취향 재사용에서 선택·버전·충돌 보호를 확인한다. 근거를 다시 불러와도 상하 이동이 없고, 영수증 앱·시스템 뒤로가기가 되돌아가는 화면을 각각 확인한다.
