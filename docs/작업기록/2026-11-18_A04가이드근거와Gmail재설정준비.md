# 2026-11-18 A-04 가이드 근거와 Gmail 재설정 준비

## A-04 가이드 생성 후 근거 대조

- 기존 가이드 검사는 도입·질문·힌트의 형식과 개수를 확인했다. 형식을 충족한 잘못된 위치나 근거 바깥의 작가 의도도 제안으로 저장될 수 있었다.
- `ARTI_DRAFT_GUIDE_REVIEW=true`인 환경에서는 가이드가 형식 검사를 통과한 후 A-04 초안 제공자에게 생성 문안과 승인 원문을 보내, 도입·질문·힌트의 주장과 전제를 대조한다. 관리자가 도판을 선택했다면 같은 도판을 검수에도 사용한다. 관람자가 본 인상이나 가능한 해석을 묻는 열린 질문은 허용한다.
- 검수 결과가 거절이면 `502 GUIDE_UNSUPPORTED`와 재시도 안내를 표시한다. 응답이 없거나 판정 형식이 틀려도 가이드 제안을 저장하지 않는다. 요약·가이드를 함께 요청해 요약만 성공했다면 성공한 요약만 제안으로 저장한다. 근거 검수 토큰은 운영 로그의 별도 작업으로 집계한다.
- 설정 기본값은 `false`다. 이번에는 합성 검수 환경에 켰다. 가이드 요청마다 같은 제공자에 검수 호출이 한 번 추가되며 기존 전체 처리 예산을 공유한다. 사람의 공개 확정 단계는 기존대로 거친다. 모의 검수는 제공자가 돌려준 판정을 애플리케이션이 반영하는지 확인했다. 팀 가림 평가로 사람의 판정을 확정한 뒤 실제 Luna 검수 결과와 대조하면 오탐과 놓친 오류를 셀 수 있다.

## 합성 검수 결과

- Django 신규 회귀 3개에서 왼쪽 위에 있는 원을 오른쪽 위라고 가정한 질문, 자료 없이 작가 의도를 단정한 힌트, 선을 왜 그렸는지 묻는 질문을 거절했다. 잘못된 검수 응답도 저장을 막았다. 정상안은 제안으로 저장됐고 공개 질문·힌트·가이드 버전은 유지됐다. 기존 관리자·도슨트·제공자·운영 회귀 61개도 통과했다.
- 관리자 PC Chrome 6개를 통과했다. 미리보기에서 형식 오류와 근거 오류를 각각 재현했다. 근거 오류 안내가 표시됐고 관리자 저장본과 관람자 공개본을 그대로 확인했다. 재시도한 정상안은 미리보기에 제안으로 보였고, 기존 안내와 도슨트 근거는 관리자가 확정하기 전까지 유지됐다. V2 추천·지도와 비회원 도슨트까지 연결해 확인했다.
- A-05 지도 Chrome 9개에서 문·복도·기둥, 저장 전후 지도, V2 추천 3·5·7점, 뒤로가기 후 회원 영수증 1건을 확인했다. 운영·모의 카카오·합성 메일 회귀 27개, OpenAI Usage 정규화 3개, 프런트 단위 검수 56개·타입 검사·빌드도 통과했다.

## Gmail 앱 비밀번호와 자동 발송

- 2단계 인증 계정에서 앱 비밀번호 발급이 가능하면 기존 Django SMTP와 Compose `reset-mail` 워커를 사용할 수 있다. 시험 발송용 Gmail 주소를 SMTP 사용자·발신 주소에 넣고, TLS `587`을 사용한다. 앱 비밀번호는 발송 서버의 Git 제외 환경 파일에 입력한다. [Google 앱 비밀번호](https://support.google.com/accounts/answer/185833?hl=ko) · [Google SMTP 설정](https://knowledge.workspace.google.com/admin/gmail/send-email-from-a-printer-scanner-or-app)
- 예시 주소와 합성 인증값으로 `check_live_config mail` 및 Compose `reset-mail` 구성 검사를 통과했다. 모의 SMTP 연결로 `STARTTLS → 인증 → 발송 → 종료` 순서를 확인했다. 실제 Gmail 인증·메일 발송은 이후 시험에 포함한다. 사용자는 발송 계정 2단계 인증과 앱 비밀번호 발급, 고정 HTTPS 주소를 준비한다. [Gmail 설정과 자동 발송 순서](../operations/비밀번호재설정_로컬검수와배포준비.md#gmail로-시작하는-경우)
