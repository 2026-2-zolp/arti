가이드에 적은 PowerShell과 Compose 설정을 검사한 뒤 새 프로젝트에서 Django·정적 웹 빌드, 마이그레이션 `0014`, 합성 관리자·전시 준비, Nginx를 통한 `/api/ready` 200과 관리자·공개 전시 진입까지 재현했다. 새 시험 컨테이너만 종료했고 기존 환경은 건드리지 않았다. 설정·운영 로그·재설정 Django 14건과 Luna 도판 Django 3건을 통과했다.

실제 모델 응답, 외부 SMTP 수신·반송, 운영 카카오 앱 콜백, 팀 도면과 실기기는 후속 확인으로 남겼다. 시험용 SMTP·재설정 주소와 카카오 앱 설정은 현재 로컬 Compose에 비어 있었다. 새 명령과 문서는 로컬 후속이다. PR #50은 상태만 조회했다.
