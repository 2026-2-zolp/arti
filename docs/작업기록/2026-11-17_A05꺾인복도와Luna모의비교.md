# A-05 꺾인 복도와 Luna 모의 비교

- 로컬 `c1ee31c`를 기준으로, 문 주변 외에도 복도가 맞닿는 곳과 기둥 바깥에서 쓸 수 있는 연결점을 A-05에 제안한다. 관람 가능 공간과 구조물 검사로 좌표를 거르며, 실제 경로는 기존 U-09와 같은 구간 검사로 계산한다.
- 길이 끊기면 **A·B**로 출발 쪽과 도착 쪽에서 각각 닿을 수 있는 가장 가까운 위치를 표시한다. 출발이나 도착이 관람 가능 공간 밖이거나 구조물에 걸리면 해당 점만 표시한다. 표시는 관리자 미리보기에서 문·통로·좌표를 확인하는 위치다.
- 합성 ㄱ자 복도에서 제안 연결점을 추가하자 폭이 좁은 문 두 곳을 통과해 기둥을 돌아갔다. 도착 쪽 문을 제거하면 이동선이 사라지고 문 양쪽에 A·B가 표시됐다. 도착점을 관람 가능 공간 밖의 작품으로 바꾸면 B만 표시됐다. 저장 전에는 관람자 전시 응답이 같았고, 저장 후 관람자 지도에서 경로를 확인했다.
- Luna v1은 별도 테스트 DB에서 L01·L02·L03 각각의 쉬운 요약과 관람가이드를 원문만·원문+도판으로 검수했다. 루프백 HTTP 요청 12건에서 원문이 같고, 도판 조건의 PNG가 해당 사례의 해시와 일치했다. 관리자 제안 저장 뒤에도 관람자 API에서 기존 확정본과 원문·콘텐츠·요약·가이드 리비전이 유지됐다. [Luna 평가표](../review/docent-2026-11-15/Luna_원문과도판_비교평가표.md)
- 프런트 빌드·단위 검사 53건, 지도·직접 관람 PC Chrome, Django Luna 모의 검사 3건을 실행했다. 직접 관람의 비회원 저장 요청 0건도 확인했다.
