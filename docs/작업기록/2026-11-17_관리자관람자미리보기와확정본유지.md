# 관리자 관람자 미리보기와 확정 문안 유지

- 기준은 PR #42 병합본 `75af721`이다. 수정 전 합성 작품의 확정 요약을 명시적으로 재생성하자 제안 저장과 동시에 공개 API의 요약·키워드가 비고 콘텐츠 버전이 바뀌었다.
- A-04 **관람자 미리보기**는 **현재 공개본**과 **편집 중인 내용**을 함께 보여준다. 현재 공개본은 관람 화면과 같은 공개 작품 API에서 조회한다. 편집 중인 원문·요약·가이드·질문과 힌트는 저장 전에도 미리 볼 수 있다.
- **쉬운 요약 다시 생성**과 **관람가이드 다시 생성**은 선택한 항목만 실행한다. 모의 제공자가 보낸 새 문안은 제안으로 저장한다. 공개 중인 문안의 스냅샷은 동일 원문 버전에 묶이고 새 제안의 확정 전까지 관람·도슨트에서 쓰인다. 공개 응답의 내용이 그대로인 분석은 도슨트 콘텐츠 버전을 올리지 않는다. 도슨트는 공개 응답에 실린 요약·가이드 개정 번호를 참조한다.
- 요약과 가이드를 각자 확정할 수 있다. 해당 항목을 확정하면 새 공개본으로 교체하고 보존한 이전 판본을 제거한다. 원문·출처 변경이나 작품 승인 해제 뒤에는 이전 공개본도 이어받지 않는다. 모델 요청은 작품 저장 잠금 밖에서 실행하고, 결과 쓰기 직전에 기존 버전 검사를 거친다.
- 마이그레이션 `0008_artwork_retained_text`는 보존 문안 필드를 빈 상태로 추가한다. 이전 버전 합성 DB 복제본에 적용한 뒤 작품 14건의 기존 요약·가이드 도입, 상태와 버전 집계가 일치했다.

## 검수 재현

별도 합성 PostgreSQL에서 `ARTI_ENV=test`, `ALLOW_TEST_FIXTURES=true`, `ARTI_LLM_PROVIDER=disabled`로 실행한다. 실제 모델 키와 내부 모델 주소는 비운다.

```powershell
& $env:ARTI_TEST_PYTHON backend-django/manage.py makemigrations --check --dry-run
& $env:ARTI_TEST_PYTHON backend-django/manage.py test arti.tests --noinput
```

- PC Chrome에서 미저장 요약은 편집 중인 내용에 표시됐고 현재 공개본은 그대로였다. 요약 재생성 대기·완료와 가이드 502→재시도 200 동안 공개 텍스트·개정 번호를 유지했다. 기존 가이드로 도슨트 요청 200을 받은 뒤, 요약과 가이드를 각각 확정했을 때 해당 공개 내용만 교체됐다.
- Django PostgreSQL 테스트 195개, 프론트 테스트 47개, 프로덕션 빌드, 관리자 분석·동시 편집 Chrome, 관람가이드·쉬운 요약 도슨트 Chrome이 통과했다. 집중 검수에서 저장 실패·예산 초과 시 전체 롤백과 다른 연결에서의 부분 저장 비노출도 확인했다.
