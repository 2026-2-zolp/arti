# W06 팀 검수 통합 전달 묶음

[핵심 3점 검수 준비](2026-11-11_W06_핵심3점독립검수인수준비.md) 이후 사용자가 한 ZIP과 상세 안내를 요청했다. 기존에는 3점 ZIP, 후보 HTML 두 개, 콘텐츠 안내를 각각 전달해야 했다. 이번에는 한 ZIP 안에서 01 태그 → 02 후보 비교 → 03 콘텐츠 확인 순서로 진행하고 결과 파일을 준억님 개인톡으로 보낼 수 있게 구성했다.

- `docs/review/yoo-core3-2026-11-11/먼저 확인할 것.md`에 목적·임시 별칭/버전 배정·압축 해제·화면 조작·초안 저장/복원·결과 제출·오류 대응을 작성했다. 별칭/버전은 전달 편의를 위한 제안으로 동섭 R01/V1, 성현 R02/V2, 광권 R03/V1을 넣었다.
- `scripts/build_team_review_pack.py`는 기존 이미지 해시와 후보 생성기를 재사용하고, 새 비공개 폴더에 9파일짜리 ZIP을 만든다. 콘텐츠 문서는 현재 core3 manifest에서 생성해 v2 질문과 맞췄다. 원본 캡처·출처 확인과 항목별 수정/보류를 적을 회신양식을 함께 넣었다.
- 결과는 `data/private/team-review-20261111/ARTI_팀검수_20261111.zip`이다. 작품 설명도 같은 ZIP에 들어가므로 순서 준수는 안내에 의존한다. 사전 열람 여부를 회신에 기록하도록 했다.
- 기존 후보 검증은 21점·18쌍과 양 버전 통과다. 새 ZIP은 파일 9개·압축 무결성·파일 해시 전체·상대 Markdown 링크·HTML 3개 JS 구문·핵심 3점 해시·후보 HTML 내장 이미지 42개 해시를 확인했다. 이번에는 실제 브라우저 조작을 새로 수행하지 않았다.
