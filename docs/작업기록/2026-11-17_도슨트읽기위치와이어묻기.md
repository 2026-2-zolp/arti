# 11/17 도슨트 읽기 위치와 같은 작품 이어 묻기

- PR #48 병합본 `62946f5` 위에서 U-11을 수정했다. 대화 끝을 보는 중에는 새 상태와 응답을 따라간다. 위로 스크롤해 이전 답변을 읽는 중에는 질문 전송과 새 응답이 도착해도 읽던 위치를 유지한다. ‘최신 대화 보기’를 누르면 새 응답으로 이동하고 대화에 포커스가 간다. [PR #48](https://github.com/2026-2-zolp/arti/pull/48)
- 360×420 PC Chrome과 합성 PostgreSQL, 루프백 모의 제공자에서 같은 작품에 질문·답변 네 쌍을 만든 다음 이전 답변까지 스크롤했다. 다섯 번째 질문의 모의 응답을 지연시켜 전송·응답 전후의 스크롤 위치를 비교했다. 이전 빌드에서 회귀 검사가 실패했으며, 수정본은 위치 오차 2px 이하, 최신 대화로 이동, 질문 중복 표시 0건을 확인했다.
- 다섯 번째 요청은 같은 관람 ID·작품 ID·원문 진입 문맥과 직전 네 쌍을 사용했고, 응답의 근거 ID·버전도 같았다. 자료 갱신, 다른 작품 이동, 같은 작품과 다른 작품의 두 탭 격리, 502·429·504 재시도와 영수증 복귀, 프론트 단위 검사 47건과 프로덕션 빌드를 확인했다. 검수한 읽기 위치 범위는 열려 있는 U-11 화면이다. [Chrome 회귀](../../frontend/tests/docentRetry.browser.cjs)
- 기존 모의 기동 환경에서 `ARTI_DOCENT_RACE_TESTS=1`로 `node frontend/tests/docentRetry.browser.cjs`를 실행한다. 실제 모델 호출과 실기기 검수는 대기 상태다. [모의 기동 절차](2026-11-15_AI도슨트브라우저복구.md#재현)
