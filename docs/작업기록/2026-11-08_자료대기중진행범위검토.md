# 자료 대기 중 진행 범위 검토

사용자가 유영국 작품 도착 전에 가능한 다른 작업을 조사·구체화하도록 요청했다. 기준530291a에서 계획 선행조건과 현재 프론트/Compose/API/자료 importer를 읽었다. 제품 코드·외부 설정은 변경하지 않았다.

개발 실행의 실제 불일치를 발견했다. Compose는 Django를 명시하지만 standalone Vite의 기본 프록시는4000이며 관리자 경로도 별도 환경변수에 의존한다. 따라서 새 기본 개발 실행 일관화가 첫 추천이다. 이어 기존 Git자료 읽기전용 인수 점검, 시험 DB/미디어 분리 복원 검증을 자료/키와 독립인 단위로 설계했다. 40점 전용 importer를 자료 수령 전 무리하게 범용화하지 않는 경계도 정했다.

[자료 대기 중 실행계획](../operations/자료대기중_실행계획.md)에 각 단위의 실제 근거·수정 범위·필요 입력·완료 기준·제외 범위를 기록했다. 기존 W와 게이트는 유지하며 GPT키·확장·하네스 보류 결정도 유지한다. PR 생성·AWS 구성·다음 제품 구현은 아직 시작하지 않았다.

검증은 계획·문서 링크·인수 이력·보호 아카이브 및 diff 검사로 한정한다. 코드/DB를 수정하지 않았으므로 제품 시험을 재실행하거나 새로 통과했다고 쓰지 않는다. 로컬 문서 커밋으로 남기며 원격 push는 수행하지 않는다.
