## 실제 회신을 받으면

1. **광권** · 세 작품의 원 취득처·제공자·파일 버전·해시를 확인한다. **준억과 각 매체 담당**은 사용 대상·기간·표시를 근거와 연결한다.
2. **작성자 외 검수자** · 질문·힌트의 관찰 위치와 해설·요약의 사실·관찰·해석 구분을 현행 도판·문안 버전에서 다시 판정한다.
3. **준억과 시연 운영자** · 승인한 매체와 도면 버전의 전시 ID·입구·구역·좌표를 선택한 뒤 시험 환경에서 추천 → 지도 → 해설 → 질문에 쓰인 작품 ID와 자료 버전을 대조한다. 실제 자료 공개, 실제 모델 호출과 실기기 검증은 보류 상태다.
