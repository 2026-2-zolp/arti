# 11/17 갈림길·동시 저장과 작품 공개본 비교

## A-05 지도 검수

- 두 전시실을 위·아래 통로로 이은 합성 도면을 추가했다. 위쪽 문을 빼면 관리자 미리보기는 아래 통로로 이동하고, 저장 전 관람자는 위 통로를 계속 본다. 저장 뒤에는 관람자 지도도 아래 통로를 쓴다. 이동선이 중앙 벽을 만나지 않는지도 확인한다.
- 같은 도면을 연 다른 관리자 탭이 오래된 버전으로 저장하면 `409 VERSION_CONFLICT`를 받는다. 최신 도면을 불러오는 확인 창을 취소하면 편집 중인 내용이 남고, 확인하면 먼저 저장된 도면과 우회로를 표시한다. 충돌 이후 공개 도면은 그대로다.
- 문을 막기 전과 후에 V2 3·5·7점의 작품·점수·추천 이유가 같았다. 관리자 저장 응답과 관람자 응답의 도면 버전과 이동 구조도 일치했다.

## A-04 작품 검수

- **관람자 미리보기** 양쪽에 출처·참고자료 URL과 저장된 근거 버전을 표시한다. 출처·참고자료 URL·작품 해설·쉬운 요약·관람가이드 중 공개본과 달라진 곳을 위에 표시한다. 입력 중인 출처에도 근거 버전은 마지막 저장 값을 보여 준다.
- 승인 저장의 누락 안내가 비어 있는 항목을 알려 준다. 기존 Chrome 회귀에서 출처가 빈 상태의 승인 시도, 공개 요약을 유지한 채 새 제안 생성, 가이드 502 뒤 재시도, 제안 폐기 및 승인 철회를 확인했다.

## 팀 PC와 운영 확인

- 팀 PC 검수는 공유된 `a316d86`을 기준으로 안내한다. 직접 관람과 V2, 비회원 저장 요청, 회원 영수증, 모의 도슨트, 복원 뒤 권한 기준과 회신 항목을 적었다. [PR #50 팀 PC 검수](../operations/2026-11-17_PR50_팀PC검수.md)
- 합성 DB에서 요약 생성 성공과 가이드 `PROVIDER_ERROR`를 한 요청에 넣었다. 응답은 `200`이고 관리자 분석은 1건 늘었으나 AI 오류는 0건 증가했다. 운영 로그는 해당 요청을 `200`으로 표시하며 오류 필터에서 제외한다. 다음에는 끈 기능과 실행 중 실패를 구분하고, 실패 항목명·코드만 기록해 오류 필터와 집계에 반영할지 검수한다.
- W06와 도슨트 평가의 접수 검사 9건·8건을 재실행했다. 팀 회신과 도판 사용 범위의 판정은 해당 인수표의 담당과 근거를 따른다. [W06 작품별 회신](2026-11-17_W06작품별회신양식준비.md) · [도슨트 평가표](../review/docent-2026-11-15/README.md)
