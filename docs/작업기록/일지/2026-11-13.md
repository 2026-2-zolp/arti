## ① 조사 근거 갱신 시 화면 밀림

**시작 배경** — 갤럭시에서 조사 근거 갱신을 누르면 기존 풀을 비우는 동안 상단 로딩과 재조회 버튼이 나타나 취향 카드가 아래로 밀렸다.

**작업과 변경 파일**

- `frontend/src/lib/useAsync.ts` · 조사 풀을 갱신할 때 직전 응답을 유지할 수 있게 했다.
- `frontend/src/pages/user/U05Taste.tsx` · 태그 카드의 갱신 버튼 위치에서 진행 상태를 표시하고, 실패 시 같은 자리에서 다시 확인할 수 있게 했다. 버전 변경으로 실제 재확인이 필요하면 기존 선택을 보존하고 안내한다.
- `frontend/src/components/TasteReview.tsx` · 취향 확인 영역을 유지하면서 근거 재확인 중에는 새 적용을 막는다. 이미 응답을 받은 계정 저장은 확인 흐름을 유지한다.

**검증 결과** — 격리 Django·PostgreSQL에 연결한 360px Chrome에서 지연 중 카드 Y좌표 유지, 버튼 1개, 503 및 풀 버전 변경 중 태그 유지, 재시도 후 관람 시간 진입을 확인했다.

## ⑤ 저장 취향 바로 쓰기

**시작 배경** — 저장 취향 목록을 본 뒤 다시 미리보기에서 같은 태그를 확인해야 관람에 적용할 수 있었다.

**작업과 변경 파일**

- `frontend/src/pages/user/U06SavedTaste.tsx` · ‘이 취향으로 관람 시작’을 기본 동작으로 두고, ‘태그 수정하기’와 ‘작품 다시 고르기’를 분리했다. 여기서 수정한 태그는 이번 관람에 적용한다.
- `frontend/src/components/TasteReview.tsx` · 적용 시 현재 계정과 저장 버전을 재확인하고, V2는 서버에서 해당 관람의 근거를 받은 뒤 진행한다. 오류가 나면 기존 관람을 유지한 상태에서 최신 계정 취향을 다시 읽을 수 있다.

**검증 결과** — V1과 V2 각각에서 503, 다른 탭에 해당하는 서버 취향 변경, 최신 취향 다시 읽기, 직접 태그 변경 취소 및 관람 적용, 30분 추천 3점, 계정 저장값 유지가 통과했다. 두 작업을 합친 프론트 테스트 34건, 빌드, diff 공백 검사도 통과했다. 새 화면은 갤럭시 재확인 대기다.

## 갤럭시 후속 관찰과 다음 검토

| 화면 | 다음 검토 |
| --- | --- |
| U-05 작품 비교 | 첫 쌍에서는 좌상단이 진입 화면으로 돌아가고, 이후에는 이전 쌍으로 가는 동작을 검토한다. 단계별 접근성 이름을 바꾸고 조사 나가기 경로를 제공한다. 제목이 이미 선택을 안내하므로 보조 문구는 전시와 별도 조사라는 정보만 남긴다. 합성 전시는 1px 이미지라 실제 작품 가독성은 가로·세로·혼합 작품으로 비교한다. 상하 압축형을 기준으로 좌우형과 대조하고 확대는 세부 확인에 사용한다. |
| U-05 취향 확인 | 편집 뒤 확인 단계에서는 서버가 반환한 선택 태그와 진행·편집 복귀를 보여준다. 회원의 계정 저장과 이번 관람 적용 선택은 유지한다. 직접 추가한 태그는 칩에 짧게 표시하고, 비중 안내는 필요할 때 펼쳐 볼 수 있게 한다. 전환 효과는 모션 감소 설정을 존중한다. |
| U-10 관람가이드 | 대체 질문은 ‘기본 감상 팁’처럼 짧게 표시한다. 질문별로 본문과 분리한 ‘이 질문으로 대화하기’를 두고, 하단 자유 대화는 ‘작품에 대해 질문하기’로 구분하는 방향을 검토한다. |
| U-10 작품 반응 | 선택 후 반응과 이유를 한 줄에 보여주고 ‘수정’에서 반응 변경·취소·이유 편집으로 이어지는 안을 비교한다. 긴 이유와 짧은 화면에서도 위치를 유지한다. |
| U-11 도슨트 | 가이드에서 들어온 경우 긴 설명과 일반 환영 문구를 걷고, 선택한 질문을 대화 첫 화면에서 보여준다. 관찰 질문은 ‘어떤 색이 먼저 보였나요?’처럼 사용자의 관찰을 먼저 받으며, 해설·힌트 요청은 사용자가 선택할 수 있게 한다. |
| U-12 영수증 | 시험 환경은 AI 제공자를 꺼두었고 정상 비회원 요청에서도 `503 AI_UNAVAILABLE`을 재현했다. 해석 가능 환경에서 별도 품질 검증이 필요하다. 디자인은 전시명·날짜를 머리말로, 관람 수치와 작품 목록을 품목처럼 배치하고, 취향 키워드를 하단에 묶는 안부터 검토한다. 화면·저장 PNG에서 같은 위계와 칩 한 줄 표시를 확인한다. |
