## 검증 결과

격리 Django·PostgreSQL의 합성 전시 한 작품에 검수 초안의 텍스트를 넣고, 360px Chrome에서 실제 제품 요청 경로로 OpenAI `gpt-6-luna`를 네 번 호출했다. 시험 작품의 가이드 공개 상태는 시험 DB에서만 구성했다. 원본 이미지, 실제 계정, 팀원 회신 원문은 요청에 포함하지 않았다. 네 응답은 모두 HTTP 200과 `llm` 모드로 반환됐으며, 가이드 버전·질문 번호·출처 참조와 이전 대화 0·2·4·6개 전달을 확인했다.

| 사례 | 통과 근거 |
| --- | --- |
| 관찰 이어가기 | 관람자가 말한 붉은 자국을 받아 시작과 끝, 자국 사이 간격을 보도록 안내했다. |
| 쉬운 재설명 | 표면 질감을 매끈하게 펴진 부분과 붓자국이 남은 부분의 차이로 두 문장에 풀었다. |
| 심화 | 밝은 면의 이어짐과 붉은 자국의 끊김을 화면 리듬에 연결하고, 가능한 해석으로 표현했다. |
| 근거 부족 | 특정 해변 이름과 색에 담긴 실제 의도는 확인할 수 없다고 답하고, 작품에서 볼 수 있는 특징으로 돌아왔다. |

- **방문자 관점** · 진입 직후 고른 질문이 보이며, 자유 질문으로 들어가면 해당 카드가 나오지 않는다. 화면 복귀와 대화 복원, 503 실패 시 입력 보존은 같은 응답을 재생해 다시 확인했다.
- **기술·시니어 관점** · 기존 서버의 승인 자료, 버전, 질문 번호, 대화 이력 계약을 유지했다. 프론트 테스트 34건과 프로덕션 빌드를 통과했다.
- **자료·팀·평가위원 관점** · 시험 DB의 13작품·관람 0·반응 0을 확인했다. 네 답변의 사례 검토를 마쳤으며, 실제 공개 채택과 정식 품질 판정은 작품 검수·출처·사용 근거 확인 뒤에 한다.
