# A-05 여러 번 꺾인 복도와 저장 경계

- 로컬 `fd6bf11`을 기준으로 전시실 두 곳을 복도 네 구간과 문 두 곳으로 이은 합성 도면을 검수했다. 좁은 공통 변으로 맞닿는 첫 굽이를 포함해 세 곳을 꺾어야 도착한다. 기존 연결점 제안으로 이 구간의 이동선이 만들어졌다.
- 모서리 한 점만 닿는 두 구역에도 직선이 생기는 현상을 재현했다. 프런트 미리보기·관람자 지도와 Django 추천 계산은 구역이 겹치거나 길이가 있는 변을 공유할 때 이어 준다. 모서리 한 점이나 실제 틈은 끊고, 모서리에 수동 연결점을 찍은 경우도 통로로 처리하지 않는다.
- 관리자 화면에서 마지막 굽이의 연결점을 지우자 이동선이 사라지고 A·B가 나왔다. 해당 위치에 연결점을 다시 찍자 이동선이 돌아오고 A·B가 사라졌다. 마지막 문을 지우고 새로 그렸을 때도 두 표시가 새로고침 없이 바뀌었다.
- 별도 관람자 Chrome 탭에서 각 저장 전후를 확인했다. 연결점을 추가한 뒤 첫 저장 전에는 기존에 끊긴 경로가 보였고, 저장 뒤 이어졌다. 문을 빼고 저장하기 전에는 연결된 경로가 유지됐다. 문을 뺀 상태를 저장하자 이동선이 사라졌고, 문을 복구하고 다시 저장하자 이어졌다. 관람자 지도에는 관리자 확인 위치 A·B가 표시되지 않았다.
