비회원 완주 후 DB는0건, 회원은3점·좋아요/색감이 좋아요·체류15초를 저장했다. reload와 같은 관람 재전송 후에도 관람1건/반응1건이었다. 별도9조합 API 검사에서3/5/7점 수량·범위·선택 좌표 방문 순서를 확인했다. 일반 arti-dev16점의 상태 해시도 동일했다. fixture 로그인 ID 불일치401은 시험계정만 수정했다. canonical 프로필 재전송409는 원제출과 다르므로 정상 충돌이며, 원제출 프로필로200을 확인했다.
