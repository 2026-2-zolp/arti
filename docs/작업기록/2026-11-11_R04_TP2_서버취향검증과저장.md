# R04 TP2 서버 취향 검증과 저장

TP1b 커밋 `11edcff`의 검증된 점수 출처를 읽기 전용 preview, 추천, 회원 저장과 관람 기록에 연결했다. 기본 기능 설정을 끈 상태로 두고 전용 PostgreSQL에서 검증했다.

- 같은 빈도에서만 승인 모델 점수 합계를 사용한다. 점수·출처가 빠진 그룹과 같은 합계는 TAGS 순서를 쓴다. 선택하지 않은 작품의 변경도 조사 근거 버전에 반영한다.
- 회원 저장은 버전과 mutation ID를 함께 확인한다. 같은 요청의 재시도는 204를 반환하며 같은 버전의 동시 저장은 한 건만 반영한다. 기존 프로필은 nullable 필드만 추가해 보존한다.
- 서명한 관람 근거에 actor, visit ID, 서버 snapshot을 묶는다. 풀 교체 이후 첫 영수증과 만료 이후 이미 저장된 동일 요청을 각각 검증했다.
- 초기 위조 입력 시험에서 400 대신 500이 발생했다. 필드별 검증 오류로 수정했다. 풀 잠금 대기 중 새 행이 활성화된 경우 409로 재조회하게 했다. 관리자 확정 순서와 합성 fixture의 풀 잠금 순서를 맞췄다.

기술·시니어 관점에서 PostgreSQL의 실제 차단을 관찰하고 풀·점수 변경 경합과 역순 관리자 확정을 검증했다. 방문자 관점에서는 preview·확정·만료 응답을 점검했고, 운영·데이터 관점에서는 preview의 행·미디어 불변과 모델 호출 0건, 기존 데이터 이관을 확인했다. 팀·교수·외부 평가위원 관점에서는 추천 수와 가중치 보존을 동점 정책 및 실제 품질 인수와 구분했다. 이 평가는 역할별 자체 검토다.
