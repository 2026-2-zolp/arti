# R04 TP4 격리 통합 검증

- 별도 PostgreSQL과 실제 Django로 취향 선택, 추천, 지도, 감상·관람가이드, 도슨트, 영수증을 연결했다. 같은 영수증 재시도에서 해당 관람 행과 반응 행이 중복되지 않았다.
- 같은 데이터에서 v1 3/5/7점 응답 전체가 기존 구현과 일치했다. v2는 빈도 가중치를 유지하며 검증된 동점 근거로 태그 순서를 계산했다.
- 고정 CLIP 캐시로 비공개 합성 이미지 한 장을 오프라인 추론했다. 입력·모델·processor·보정·점수의 근거를 DB 저장값과 대조했다. 다섯 조사 항목의 v2 비교에는 같은 이미지 바이트에 대한 이 분석 결과를 격리 DB에서 재사용했다.
- 재시작 전후 비교에서 체류 시간 동점으로 영수증의 대표 작품이 달라지는 문제를 찾았다. 관람 순서를 동점 기준으로 고정해 최초 저장·재시도·재조회가 일치하도록 보완했다.
- 격리 서버에서 v2를 끈 뒤 기존 취향·정확한 mutation 재시도·영수증과 미저장 근거의 첫 저장을 확인했다. 재활성 후에도 같은 DB와 필드, 계정·관람 기록을 사용했다.

기술 관점에서는 API 응답과 JSON 저장 결과, 출처 해시를 대조했다. 방문자 관점에서는 감상에서 질문으로 이어지는 맥락과 영수증 재시도를 확인했다. 운영·데이터 관점에서는 일반 DB·미디어·원본 16점의 전후 해시와 격리 복구를 확인했다. 팀·교수·외부 평가위원 관점에서는 도슨트의 로컬 제공자 시험, 캐시 모델의 실추론, 실제 작품의 독립 검수를 구분했다.
