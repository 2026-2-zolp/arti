# A-05 도면 버전과 Luna 도판 모의 검수

## 도면 저장과 추천

- A-05의 **이동 구조 등록**에서 관람 가능 공간·벽·기둥·문·통로·연결점을 입력한다. 사각형은 마주 보는 모서리 두 곳을 선택한다. 원본 이미지가 있으면 겹쳐 보며 좌표를 맞출 수 있다. 저장된 구조는 현재 도면 버전에 적용된다. 다른 탭이 먼저 수정하면 409로 돌려보낸다. 도면 이미지 교체·제거는 버전을 올리고 기존 구조와 작품 위치를 지운다.
- 기존 V2가 작품과 점수·추천 이유를 먼저 정한다. 입구와 작품 위치 사이에 등록된 연결점으로 보행 가능한 구간을 계산하고, 선택된 최대 7점의 열린 경로를 비교해 순서만 바꾼다. 거리 단위는 도면 비율을 반영한 상대값이다. 도면에서 확인할 수 있는 경로가 끊기면 작품 목록과 기존 순서를 제공하고 U-09의 끊긴 구간에는 선을 그리지 않는다. [OGC IndoorGML 공간과 연결 모델](https://docs.ogc.org/is/22-045r5/22-045r5.html) · [Google OR-Tools 거리 행렬 예제](https://developers.google.com/optimization/routing/tsp)
- 합성 PostgreSQL에서 3·5·7점 각각 작품 ID·점수·추천 태그·이유가 같고 순서가 바뀌는지 확인했다. 문을 닫으면 세 길이 모두 기존 순서로 돌아왔다. 기둥 모서리에 닿는 선분, 이동 공간이 중간에 끊긴 선분, 잘못된 좌표, 도면 교체 후 오래된 저장 요청도 검수했다.
- PC Chrome에서는 A-05에서 기둥과 연결점을 그려 저장하고 새로고침 뒤 다시 확인했다. U-09에서는 한 방의 세로 기둥 배치, 두 방의 가로 문·복도 배치, 등록 구조가 없는 기본 도면과 연결 불가 시 안내 문구를 확인했다. 지도 변경 이전에 감상한 작품은 기존 관람 기록으로 유지한다.

### 네이티브 지도 편집을 쉽게 만드는 순서

1. **우선 적용 후보**는 전시실 프리셋과 경로 미리보기다. 빈 전시실·가운데 기둥·복도로 이어진 두 전시실 프리셋에서 시작하고, 벽 끝·문·복도 모서리에 붙는 기능을 둔다. 입구와 대표 작품을 찍으면 이동선과 연결 실패 구간이 바로 보이게 한다. 관리자가 도면과 현장에서 출입 조건을 확인한 뒤 공개하는 단계는 후속으로 둔다. 현재 편집기는 지도 클릭으로 입력하며, 저장하면 즉시 해당 도면 버전에 반영된다. 정밀 편집에는 좌표 직접 입력도 도움이 된다.
2. **벡터 자료**가 반복해서 들어오면 SVG·IFC 등에서 구조를 가져와 초안으로 채우는 편이 효율적이다. 캡처 이미지의 자동 검출은 관리자에게 수정 가능한 후보 영역을 제안하는 용도로 검토한다. 출입문·통행 가능 여부는 운영자가 확인한다. [OGC IndoorGML 2.0](https://www.ogc.org/standards/indoorgml/)
3. 남은 시험은 ㄱ자·좁은 통로, 출입 통제 변경, 층간 이동, 실측 축척, 계단 없는 경로다. 가능한 구간부터 확인하고, 작품을 가장 가까운 순서로 한 점씩 고르는 방식과 전체 보행 거리 후보를 비교한다. 짧은 경로라도 전시 의도나 일방통행을 지키지 못하는 경우에는 큐레이터가 정한 순서·통행 제약이 우선이다.

## 팀원 PC 직접 관람

현재 합성 전시에서만 미리 볼 수 있다. 이번 커밋을 가진 PC에서 아래 순서로 실행하거나 준억의 로컬 화면을 회의에서 공유한다. 개발용 컨테이너와 자료는 별도 프로젝트 이름으로 둔다.

1. Docker Desktop을 켠 후 저장소 루트의 새 PowerShell에서 아래를 실행한다. 다른 환경의 운영 설정을 불러오지 않는다. `5418` 또는 `5478`을 이미 쓰고 있으면 같은 환경 파일에서 포트만 바꾼다.

   ```powershell
   if (-not (Test-Path -LiteralPath .env.direct-review.local)) {
   @"
   DJANGO_SECRET_KEY=$([guid]::NewGuid().ToString('N'))
   ARTI_DB_PASSWORD=$([guid]::NewGuid().ToString('N'))
   ARTI_ENV=development
   ALLOW_TEST_FIXTURES=true
   ARTI_EXHIBITION_ORDER_DEMO_ENABLED=true
   ARTI_TASTE_PROFILE_V2_ENABLED=true
   ARTI_LLM_PROVIDER=disabled
   ARTI_DRAFT_PROVIDER=default
   ARTI_LUNA_DRAFT_VISION=false
   ARTI_MODEL_SERVICE_URL=
   ARTI_API_PORT=5418
   ARTI_UI_PORT=5478
   "@ | Set-Content -LiteralPath .env.direct-review.local -Encoding ascii
   }
   docker compose --env-file .env.direct-review.local -p arti-direct-review --profile ui up -d --build
   docker compose --env-file .env.direct-review.local -p arti-direct-review exec -T api python manage.py load_test_fixture
   ```

2. [PC 합성 전시 열기](http://127.0.0.1:5478/exhibitions/fixture-ex01) → **전시 순서로 바로 보기** → 합성 작품 03 첫 화면 → **다음 작품 안내** → 뒤로가기·새로고침 → 마지막 작품·영수증 순서로 본다. 비회원은 그대로 진행한다. 회원 저장을 보고 싶으면 같은 합성 환경에서 이메일로 시험 계정을 만들어 로그인한 뒤 시작한다.
3. **내 취향으로 추천**도 한 번 열어 두 버튼을 비교한다. 회신은 `선택한 버튼 / 첫 작품까지 걸린 클릭 / 막힌 화면과 문구 / 다음 작품과 영수증까지 확인 여부`로 받는다. 자동 재현에는 [직접 관람 회귀 절차](2026-11-17_합성전시순서바로보기.md)를 사용한다.

## 관리자 Luna 선택 검수

- `ARTI_LUNA_DRAFT_VISION`과 작업별 Luna 연결을 동시에 켤 경우 A-04에 별도 도판 체크박스가 나온다. 체크를 끄면 저장된 텍스트만 보낸다. 선택하면 승인된 작품의 업로드 PNG·JPEG·WEBP를 2MiB 상한으로 읽어 Chat Completions의 이미지 파트에 넣는다. 502 후 다시 시도는 요청 당시의 항목과 도판 선택을 유지한다.
- 로컬 HTTP 모의 서버에서 `gpt-6-luna` 모델 필드, 해제 시 텍스트, 선택 시 원본 도판 바이트, 가이드 형식 오류 502와 확정본 보존을 검사했다. 태그·감정 요청, 방문자 도슨트, 비-Luna 설정 및 잘못된 도판도 검사했다. 관리자 Chrome에서는 체크 기본값, 해제·선택·502 후 동일 옵션 재시도, 새 제안과 공개본 분리를 확인했다. 다음 품질 시험에서는 같은 작품의 원문만 사용한 경우와 원문에 도판을 더한 경우를 비교하고 없는 색·형태 언급, 사실과 관찰 혼용, 질문과 힌트 짝, 수정 없이 채택 가능한지를 기록한다.
- 실제 도판을 보낼 때는 사용·외부 전송 범위 확인이 필요하다. 이번에는 합성 자료와 모의 공급자로 요청 계약·오류 복구를 검수했다. 실제 모델 호출과 실기기는 보류했다. [모델·키 설정과 Kanana 로컬 준비](../operations/2026-11-17_도슨트모델과관리자운영검토.md)
- Django PostgreSQL 206건, 프런트 단위 50건과 프로덕션 빌드, 도면·직접 관람·운영 로그·관리자 Chrome 회귀, 마이그레이션 일치 검사를 통과했다.

## 전시 QR과 카카오 로그인

- 전시별 QR은 A-03에 **관람 링크 복사·QR 다운로드**를 제공하는 방향을 권한다. 공개 전시의 고정 HTTPS 전시 주소를 넣고, 운영자는 전시명과 주소를 미리 확인한다. 포스터에는 QR과 짧은 주소를 함께 둔다. 인쇄 뒤 전시가 종료되면 같은 URL에서 종료 안내를 표시하고, 운영 전시 목록으로 이동할 수 있게 한다. QR에는 계정이나 세션 정보를 넣지 않는다. [국립현대미술관 QR 리플렛](https://www.mmca.go.kr/pr/newsDetail.do?bdCId=202304190008785) · [서울시립미술관 도슨팅 앱](https://sema.seoul.go.kr/kr/sema/app_download)
- QR은 전시 진입의 수고를, 직접 관람은 취향·시간 입력을, 카카오는 회원 재로그인의 반복 입력을 각각 줄인다. QR 진입 직후에는 비회원으로 작품을 볼 수 있게 두고, 저장이나 이전 기록이 필요한 자리에서 로그인 선택을 제시한다. 준억·팀 앱 소유자와 Codex의 콘솔·설정·검수 분담은 [카카오 첫 연동 가이드](../operations/카카오로그인_첫연동가이드.md)에 정리했다.
