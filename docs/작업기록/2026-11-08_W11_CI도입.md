# W11 CI 도입 기록

이전 [W05/G4 기록](2026-11-08_W05_핵심통합구현과인수대기.md)의 CI 검토를 사용자 요청으로 구현했다. 출발25c027d, dev/임준억. 원격 push는 하지 않는다.

팀원별 AI 코딩 결과 통합에서 타입/계약/DB 회귀가 재발하지 않도록 .github/workflows/ci.yml에 프론트·실제PostgreSQL·fake모델·계획계약4job을 추가했다. 프론트 package/lock에 tsx/npm test를 넣어 Express 개발 의존성 없이 검사하게 했다. 권한은read, 키disabled, 실모델·AWS배포는 제외한다.

이전 수동 검사에서 이제 PR·개발브랜치push마다 같은 검사를 실행할 준비가 됐다. Linux에서 명령을 재현해 프론트13·타입/빌드, 모델17, 계획/guardrail/계약, Django63(연결준비회귀 포함)을 통과했다. actionlint의 runner context 오류를 고쳐 재통과했다. [상세와 원시로그](../execution-plan/2026-11-07/records/W11/README.md).

W11은 구현·로컬검증 후 in_progress다. 실제 Actions run이 없어 AC07/GCI는 not_run이며, 첫 원격 실행/PR검사 확인 후 종결한다. 사용자 확인 전 push/branch rule/CD변경은 하지 않는다. AI 준비는 별도 작업기록과 커밋으로 이어진다.

후속 사용자 승인 후 원격 push4job 모두성공을 확인했다. 초기 미푸시/미실행 경위와 구분하며 [최종검토·원격결과](2026-11-08_최종검토와원격CI검증.md)를 따른다. PR 이벤트 미검증으로 W11/GCI 최종인수는 남아 있다.
