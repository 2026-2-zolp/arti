# 프로젝트 범위와 결정 상태

> 기준: [10/12 실제 정기회의 결과](https://app.notion.com/p/3fb34713f1678122bbf9f2c856b50ce8) · [10/17 진행 현황 취합](https://app.notion.com/p/3fc34713f167814bb884e2bf31a8bdb9). 기존 [10/12 구현 착수안](https://app.notion.com/p/3f734713f16781dda4fef887384ac17d)은 **회의 준비용 권장안**으로 별도 구분합니다.

## 확정된 방향
- **우선 개발할 전시:** 서울시립미술관 **〈유영국: 산은 내 안에 있다〉**. 신인상주의 **〈Radical Harmony〉**는 후속 후보입니다.
- **사용자:** 미술 감상 초보자. 모바일 웹 중심, 전시 입구 QR/URL 진입.
- **역할 분담:** 프론트엔드(김동섭·지성현)는 화면설계·목업을 실제 화면으로 구현, 백엔드·AI·데이터(임준억·김광권)는 별도 협의 후 API 연동.
- **구현 전략:** 26쪽 전체 화면설계를 한 번에 개발하지 않고 **최소 사용자 흐름 하나부터** 구현·통합.
- **지도:** 실제 GPS가 아니라 전시 입구/직전 작품을 기준으로 하는 진행 상태 기반 2D 안내.
- **AI 개발 도구:** 개인별 도구 선택을 허용하되, 담당한 코드를 이해·검수하고 변경 범위를 확인한 뒤 공유.

## 우선 개발할 사용자 흐름
전시 QR/URL → 취향 선택 → 관람 시간 → 작품 추천·이유 → 2D 지도·순서 → 작품 해설·관찰 질문 → 다음 작품.

| 구분 | 초기 구현 권장 범위 | 상태 |
| --- | --- | --- |
| **P0** | 출처를 확인한 작품 일부, 비회원 진입, 취향·시간 입력, 추천·이유, 2D 지도 마커·순서, 기본 해설의 연결 | **구현 우선순위 제안** · 실제 연동 미검증 |
| **P1** | Guided Looking 1문답 / 근거 기반 Q&A / 간단한 관람 결과 중 1개 | **여건에 따른 확장** |
| **후속** | 로그인·관리자 기능 고도화, TTS, 기록, 공간 그래프 기반 동선 최적화 | **이번 중간발표 필수 아님** |
| **제외** | 실시간 실내 GPS, 3D 내비게이션, 다중 미술관 전체 운영, 대규모 모델 자체 학습 | **초기 범위 밖** |

**작품 수:** 10/12 실제 회의에서 **초기 정밀 검증용 약 5~6점**이 언급됐고, 구현 착수안에는 **3~5점 규모의 최소 샘플**이 제안됐습니다. **최종 작품 수와 수집·검수 완료 기준은 미확정**이므로 고정 요구사항으로 해석하지 않습니다.

## 아직 확인·합의할 것
- 유영국 전시의 실제 출품 작품 목록·출처·이미지 사용권·작품별 배치 또는 가상 좌표 사용 여부
- 백엔드 프레임워크·DB·배포 환경 및 광권님 기존 구현 코드·실행 가능 여부
- 최소 전시/작품 ID와 추천 API 요청·응답 필드, 비회원 visitId 발급·보존 정책
- 실제 프론트 앱 코드·화면 실행 결과와 백엔드 응답의 연결 수준
