# 프로젝트 범위와 현재 결정 상태

기준: [10/12 정기회의·구현 착수안](https://app.notion.com/p/3f734713f16781dda4fef887384ac17d), [개발 1단계](https://app.notion.com/p/3fa34713f167804ebb23c251498f3c5a). 이 문서는 요약이며 **최종 의사결정의 기준은 Notion 회의 결정사항**입니다.

## 핵심 사용자 경험
전시 입구 QR/URL → 취향 선택 → 관람 시간 → 작품 추천·이유 → 2D 지도·순서 → 작품 감상·관찰 질문 → 다음 작품.

## 우선순위
| 구분 | 첫 구현 |
|---|---|
| P0 | 검증 가능한 전시 1개, 작품 3~5점, 출처/검수 기록, 비회원 흐름, 추천 결과, 2D 위치 마커, 기본 해설 |
| P1 | Guided Looking 1문답 / 근거 기반 작품 Q&A / 간단 아트 영수증 중 최소 기능 |
| 후속 | 회원·관리자 고도화, TTS, 관람 기록, 실제 공간 그래프 |
| 제외 | 실시간 실내 GPS, 3D 내비게이션, 모든 미술관 운영, 대규모 AI 모델 자체 학습 |

**주의:** 사용자의 '현재 위치'는 마지막 관람 작품 등 진행 상태에 따른 가상 기준점입니다. 실측 위치가 아닙니다.

## 전시 데이터
- 사조 중심: National Gallery **Radical Harmony** (신인상주의)
- 작가 중심: 서울시립미술관 **유영국: 산은 내 안에 있다**
- 실제 첫 개발용 작품, 이미지 권리, 실제 전시 소속, 좌표 확보 여부는 원자료로 확인해야 합니다.

## 확정되지 않은 요소
- 최종 백엔드 기술(Django/DRF 등은 제안 단계)
- DB, 호스팅/배포 방식, 추천/임베딩·RAG 방식
- API의 정확한 경로·응답 필드·회원 인증 및 방문 ID 발급 정책
- 실제 작품 배치 자료(없으면 **가상 좌표임을 명시**)

팀 합의 전에 위 항목을 고정된 계약·설정으로 간주하지 않습니다.
