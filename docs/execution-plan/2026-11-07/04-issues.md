## 변경의 핵심

- F03: guide필드 반영은 이미 보완됐다. 새 full frontend에서 저장회귀를 확인한다.
- F18: 캡처40장/WikiArt79장은 Git에 있다. 이전 이미지부재 판단을 정정하고 재현/유영국 구별력으로 과업을 바꾼다.
- F34: 확정요약 재생성은 별도 미해결 결함이다. F03과 혼동하지 않는다.
- F35: 출처URL만 바꿀 때 확정 유지(실행), seed재실행의 guide재검수 누락(코드)을 구분한다.
- F36: 시드라는 방식 자체가 결함은 아니다. 검수전AI초안/시연좌표를 실제자료 승인·운영공개로 승계하는 것이 문제다.
- F37: 로컬DB가 반드시 필요하지 않지만 고유값/파일/확정상태가 있으면 보존 후 인수한다.

## 종결과 릴리스

현재 F21만 releaseRequired=false다. 고급 알고리즘 미구현·설계변경 설명은 AC31에서 필수다. 다른 이슈는 연결 AC·해결 증거 후 종결한다. accepted_deferred는 해결이 아니며 필수릴리스 집계에서 숨길 수 없다.

스택을 바꿔 기존 코드가 없어졌다는 사실만으로 결함을 닫지 않는다. 새 대상 API/React에서 같은 입력을 검사한다. UI별 상태와 raw API 접근은 별개로 확인한다.
