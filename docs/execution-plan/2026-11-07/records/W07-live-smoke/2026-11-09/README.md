추적 근거: [요청/확정·assertion 추적](request-and-check-trace.json), [실행한 일회성 소스의 텍스트 사본](executed-smoke.py.txt). 자동실행 시험/하네스가 아닌 당시 실행 증거이며 키·런타임 인증토큰값은 포함하지 않는다. contentVersion 등 일부값은 저장응답과 실행소스에서 도출했음을 구분했고, 원시 공개GET응답/네트워크패킷을 저장한 것처럼 표현하지 않는다. model필드도 요청설정 모델이며 upstream resolved모델/usage를 따로 수집하지 않았다.

## 순서 판단과 범위

사용자가 키/모델 입력 후 실제연결과 해설·가이드·도슨트 연계를 요청했다. 현재 W06의 실제자료 검수·백업/복원·유영국 적재/배치와 사전평가 기준이 미완료여서 이번에는 **합성1점의 실제 연결 smoke만** 수행했다. 새로운 평가하네스·모델라우팅/추론수준 분리·실제 전시 승인으로 확대하지 않는다. W07의 정식 완료 선행조건을 생략하지 않는다.

설정에 키와gpt-6-luna는 있었지만 provider=disabled였다. 시험프로세스만 openai_compatible으로 켜서 먼저 검증했고, 성공 후 사용자 provider 질문에 답하며 로컬 `.env.compose`의 해당 한 줄도 openai_compatible으로 수정했다. 나머지 줄·키·모델은 보존했다. 실행 중인 일반 개발 앱을 재생성하거나 다른 프로젝트 DB를 변경하지 않았다.

## 실제 실행과 결과

독립Compose프로젝트 `arti-gpt-smoke`의 PostgreSQL17·현재 API이미지에서 Django test runner가 별도시험DB를 만들었다. 직접 작성한 합성 텍스트만 사용하고 실제유영국 이미지/설명·개인정보는 외부로 전송하지 않았다. 승인값은 합성시험행에만 적용했다. HTTP 가상서버/모델응답 mock을 사용하지 않고 기존 providers→llm→공식API의 실제응답을 받았다.

| 순서 | 실제 API 동작 | 결과 | 소요시간 |
| --- | --- | --- | --- |
| 1 | 작품 쉬운해설 /explanation | 200,mode=llm,원문 sourceRefs | 4.445초 |
| 2 | 관리자 /analyze의 summary+guide | 200,두 산출물 provider 생성·suggested | 합계5.669초 |

API요청은생성4건,외부추론은요약/가이드별도라 코드경로기준5회다. 자동재시도없음. 응답사용량/청구액은수집하지않아 실제비용은측정하지않았다. 평균/P95·동시성·현장지연으로일반화하지않는다. 오류는발생하지않았다.

가이드는도형/선의배치를보도록질문했고, 첫도슨트는사용자가말한앞으로나오는느낌을받아삼각형과노란선간격을살펴보도록이어갔다. 후속답변은앞선빨간삼각형관찰을명시적으로연결하고 선의효과를작가의의도로단정하지않았다. 시험문장은‘실제작품아님/작가의도정보없음’이라고명시했고 생성해설/요약도이경계를유지했다. 이는합성표본1개에서의관측이지 유영국의미술사사실성·환각률·교육효과 검증이아니다.

태그/감정은시험행의기존합성confirmed값을kept했으므로 이번에CLIP/mDeBERTa를실연결한것이아니다. 모델이미지인식도시험하지않았다. sourceRefs는서버가승인/진입범위에서구성한참조이며 모델이독립적으로출처를검증했다는뜻이아니다.

## 운영과 한계

기존25초 timeout/최대2000출력토큰/JSON검증/기존확정산출물보호와자동fallback없음은변경하지않았다. API호환성문제가없어제품코드를수정하지않았다. OpenAI Docs로공식모델/Chat Completions형식을확인했으며 실제키·인증헤더·upstream body는출력하지않았다. 유료시험은CI에추가하지않고수동실행1회로끝냈다.

실제브라우저U10→U11·뒤로가기/스크롤,실제전시자료·도면/추천·모바일,모델비교·강제실패·하네스/사전평가계획은미실행이다. 기존가상응답회귀/브라우저과거근거와이번실호출결과를합쳐이번에전부실행한것처럼표현하지않는다. W06/07·AC18~22·G5 상태는그대로유지한다.

다음순서는 W06의합성자료백업/복원검증과핵심3점콘텐츠검수준비다. 실제자료를사용한정식GPT평가는작품근거/평가사례·기준을고정한뒤진행하고 그때확장·하네스도함께논의한다. 로컬설정반영은기존개발Compose프로젝트이름으로API컨테이너를재생성해야한다. 키는공유하지않는다.

## 검증단 검토

기술/SENIOR 관점은 합성자료·생성4요청/추론5회·sourceRefs revision·태그감정kept·미통과범위를 확인했고 추적성 보완을 요구했다. 기존 실행소스·정확한 history와 entryContext/확정요청·공개전후 assertion을 보존해 보완했다. 공개GET원시응답은 당시 저장하지 않았으며 실행assertion 근거로 한정한다. 추가유료호출은 하지 않았다.

콘텐츠/방문자 관점은 관찰을 이어받는 첫/후속대화와 작가의도 단정 유보가 적정하다고 보았다. 다만 요약의 ‘재료와 작가의 의도는 알려져 있지 않습니다’는 ‘제공된 자료에는 해당 정보가 없습니다’로 한정하는 편이 정확하다고 지적했다. 실제 생성결과는 수정하지 않고 향후 고정 평가사례로 남겼다. 단일 smoke를 근거로 프롬프트를 대규모 변경하거나 전체품질통과로 처리하지 않는다. AI역할 검토이며 실제 교수/사용자 검수를 뜻하지 않는다.

기술/SENIOR 재검토에서 추적성보완완료·필수잔여없음을확인했다. 첫ask만visitId를보냈고후속은현재호환입력처럼생략했으므로 actor/visit격리의실검증으로확대하지않는다. 시험DB는runner가정리했고 전용Compose컨테이너/네트워크도down으로종료했다. 볼륨은삭제하지않았다. 실행소스텍스트는당시CRLF원문바이트와해시를보존한다. 계획검사는오류0·보호아카이브38파일보존이며앱/원격CI재실행이아니다.
