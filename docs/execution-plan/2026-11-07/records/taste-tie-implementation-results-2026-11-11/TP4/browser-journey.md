# 실제 API를 사용하는 격리 브라우저 여정

Chrome 156.0.8078.81의 별도 프로필에서 빌드한 화면을 열었다. 브라우저의 API 요청은 루프백 프록시를 통해 Django와 전용 PostgreSQL에 전달했다. 브라우저에는 격리 DB에서 가입한 합성 계정의 세션을 사용했다.

1. 전역 조사 10점에서 다섯 쌍을 선택했다. v2 미리보기와 회원 저장 후 관람 시간 화면으로 이동했다.
2. 30분을 선택해 세 작품을 추천받고 지도에 들어갔다. 도면 이미지 요청은 200을 반환했고 관람 ID는 미리보기에서 서명한 값과 같았다. 별도 API 대조에서는 60분과 여유 관람의 다섯·일곱 작품도 확인했다.
3. 첫 작품에서 관람가이드를 열고 질문 화면으로 이동했다. 테스트 제공자가 받은 질문의 진입 맥락과 원문을 검사했고 Django 응답의 출처가 해당 작품의 관람가이드임을 확인했다.
4. 감상 화면으로 돌아와 좋아요와 이유를 저장했다. 세 작품을 차례로 완료한 뒤 영수증을 처음 저장했다. 같은 화면을 새로고침하자 같은 관람 ID·서명·원문 요청이 다시 전송됐다.
5. 최초 201과 재시도 200의 응답 본문이 같았다. 회원의 해당 관람과 반응은 각각 한 건이었다. 재시작 뒤에도 최초 영수증과 반응, 마지막 계정 저장 mutation을 확인했다.

초기 시험의 필드별 대조에서 체류 시간 동점인 ‘가장 오래 본 작품’이 달라졌다. 양쪽 계산을 관람 순서 기준으로 고치고 이 여정을 다시 실행했다. 외부 GPT 대신 루프백 제공자에 한 번 요청했으며 실제 모델 출처는 별도 오프라인 분석 한 번으로 검증했다.
