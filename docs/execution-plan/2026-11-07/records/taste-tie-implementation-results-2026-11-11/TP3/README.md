# TP3 취향 미리 확인과 관람 적용

기준 커밋 `ba3b6dc`의 TP2 API를 작품 선택 화면과 저장 취향 화면에 연결했다. 선택 초안은 탭의 계정·전시·관람 범위로 나눈다. 태그 선택을 바꾸면 이전 확인 화면을 해제해 늦은 응답이 새 초안에 적용되지 않도록 했다.

| 단계 | 동작 |
| --- | --- |
| 작품과 태그 선택 | 원래 작품의 태그를 다시 포함하거나 제외할 수 있다. 작품에 없는 태그를 추가하면 균등 가중치를 안내한다. 빈 집합은 확인할 수 없다. |
| 미리 확인 | 활성화된 v2에서는 서버의 정규화 프로필·표시 순서·후보 관람 ID용 서명을 받는다. 조사 근거가 바뀌면 선택 ID를 보존하고 사용자가 최신 근거를 확인한다. |
| 사용자 확인 | 동일한 의미로 복귀하면 현재 관람과 반응을 이어간다. 진행 중인 관람을 교체할 때는 별도 확인을 받는다. |
| 계정 저장 | preview 시점의 저장 버전과 mutation ID를 쓴다. 저장 응답이 유실되면 같은 원 요청을 재전송한다. 204를 받은 뒤 계정 조회만 실패하면 조회만 다시 한다. |
| 관람 반영 | 최종 서명과 취향을 확인한 뒤 후보 관람 ID로 한 번 전환한다. 이번 관람만 적용하면 계정 PUT을 보내지 않는다. 첫 관람 시간 선택은 서명된 ID를 유지한다. |
| 영수증 | 동일 관람의 pending 요청과 서명을 새로고침 뒤 그대로 전송한다. 활성 관람 복원에는 기록한 소유자를 확인한다. |

서버의 v2 지원과 활성 상태가 확인되면 새 조사에서 v2를 사용한다. 기존 v1 조사도 같은 확인 흐름에서 동작하며 v2 mutation 재시도 보장은 v2 계약에 적용된다. 진행 중인 v2 관람에서 시간을 바꿀 때는 새 ID용 근거를 받은 뒤 전환한다.

P3-01~P3-06의 적용 범위는 [검증 결과](validation.json)에 기록했다. 빌드와 프론트 테스트 33건을 통과했고 Chrome에서 합성 API 응답을 지연시키거나 409·504·조회 실패를 반환해 실제 화면을 검증했다. 기존 동섭님 추적 브랜치의 마지막 커밋은 `ae0e58e`였다. 별도 최신 종합본의 UI 변경 선별은 인수 확인 후 진행한다.

다음 TP4는 격리 PostgreSQL과 실제 API로 10점 선택 → 추천 → 지도 → 감상·도슨트 → 영수증을 검증한다. 기존 캐시 모델의 출처 대조와 비활성화·재개도 포함한다.
