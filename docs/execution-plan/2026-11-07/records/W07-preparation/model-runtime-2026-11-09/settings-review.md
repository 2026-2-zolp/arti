# CLIP·mDeBERTa 설정 적정성 추가 검토

현재 설정을 유영국 전시에 최적이라고 단정할 근거는 없다. 기존 값을 폐기하거나 이번 3점에 맞춰 튜닝하지 않고 기준선으로 보존한다.

| 항목 | 현재 구현과 근거 | 후속 판단 |
| --- | --- | --- |
| 모델 | CLIP ViT-B/32, mDeBERTa-v3-base MNLI/XNLI | 과거 감정 비교 보고서는 11개 예시에서 보정된 현재 설정을 선택했다. 유영국 및 실제 이미지 혼합 전체의 최적성 근거는 아니다. 당장 대형 모델 교체보다 현재 연결·입력·평가를 먼저 확인한다. |
| 태그 보정 | 빛 .95, 강렬 .9, 따뜻 .9, 나머지 .5. 출력이 .5 기준이 되도록 점수를 재매핑 | 기존 40점 팀 라벨·작품별 교차검증 근거가 있다. 유영국 추상화 분포로 그대로 일반화할 수 없으며 추천 점수/태그 범위에 직접 영향을 준다. |
| 감정 보정 | 11개 예시에서 구한 텍스트 prior를 빼고 이동·정규화 | 모델 신뢰도나 객관적 감정 확률이 아니다. 이미지 기반 감정과 스케일을 맞춘 결과도 사용자 심리/작가 의도를 뜻하지 않는다. |
| 이미지 비중 | 감정 결합에서 .6, 텍스트 .4 | 태그 결합 비중이 아니다. 태그는 이미지가 있으면 이미지로만 분석한다. 감정에 대해 .0/.6/1.0의 제한 비교를 제안하되 팀 라벨 전에 우승값을 고르지 않는다. |
| 태그 프롬프트 | 긍정/부정 문장, 이미지/텍스트 임베딩 비교 및 sigmoid | 기존 문장 설계 근거는 있지만 색면 추상화에 최적인지는 미확인. 모든 그림을 같은 태그로 만드는지, 추상/풍경·빛/밝은 색 혼동을 확인한다. |
| 전처리 | 원본 파일 디코드 후 RGB, 모델 기본 processor 사용 | 캡처의 액자·벽·여백 영향이 있을 수 있다. 원본과 작품 영역 crop 비교는 파생본을 구분하고 해시를 보존해야 한다. 원본을 몰래 교체하지 않는다. |
| CPU 실행 | 이번 시험은 4개 연산 스레드로 제한 | 시스템 부하에 따른 로딩/지연 측정 조건이며 최적 스레드 수를 찾은 결과가 아니다. 필요한 경우 2/4 제한 비교를 별도 수행한다. |

근거 파일: ai-service/app/config.py, analyzer.py, tags.py, emotions.py, calibration.json, tag_calibration.json, evaluation/results/report.md, team_tags_report.md와 docs/AI-감정분석-추천-정리.md. 기존 보고서 수치는 이번에 다시 측정한 값이 아니다. 기존 감정 11개 예시에는 imagePath가 없어 현재 유영국 이미지 성능 근거로 사용할 수 없다.

권장 순서: 현재 설정으로 기술 측정 → 팀원과 독립적으로 태그/감정 후보·불확실성을 기록 → 검수된 입력·라벨 고정 → 기존 보정 on/off를 우선 비교 → 감정 비중/전처리는 문제 원인이 확인된 항목만 비교. 한 번에 모델·문장·보정·crop을 모두 바꾸지 않는다. 현재 calibration 표본을 평가 정답으로 재활용해 개선을 주장하지 않는다.

16점 한 작가 표본만으로 8개 태그의 일반 정확도를 평가하지 않는다. 없는 태그는 N/A로 남기고 기존 40점은 별도 회귀 코퍼스로 사용한다. 기존 cap05와 유영국009의 도상 중복 가능성도 분할 시 표시한다. 001/004/010은 이미 탐색에 사용한 calibration 후보이므로 새 정답으로 held-out 평가를 주장하지 않는다.

팀/방문자 관점에서는 감정 정답화와 획일적 추천을 피하고, 교수/평가위원 관점에서는 라벨 불일치와 표본 한계를 보고한다. 시니어/운영 관점에서는 모델 교체보다 재현 가능한 revision·입력·실행 환경과 지연/메모리를 먼저 확보한다. 이는 동일 작성자의 자체 관점 검토이며 실제 사람 승인과 다르다.

실측 후 추가 확인: 004의 warm 보정 점수는 .434여서 .5 태그 기준 아래였고, 010은 landscape .998와 abstract .991가 동시에 높았다. 둘 다 사람 라벨 없이 오답으로 판정할 수 없다. 다만 따뜻한 색 보정과 풍경/추상 중복을 우선 검토할 구체적 사례가 확보됐다. 세 작품의 태그·감정 응답은 2회 반복에서 동일했다. 반복 안정성이 감상 해석의 타당성이나 최적성을 증명하지는 않는다.
