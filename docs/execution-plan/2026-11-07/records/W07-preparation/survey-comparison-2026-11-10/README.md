## 네 점수 처리 방식과 추천 변화

1. 현행: 선택작에서 발생한 태그 전체와 빈도 가중치,고정 순서의 동점 우선 선정.
2. 동점만 AI 보조: 태그 수·빈도 가중치는 유지하고 동점의 후보 배정 우선순위만 선택 이미지 점수 합으로 비교.
3. 대표3개+AI 보조: 빈도 우선·점수 합 보조로3개를 남기는 결합 실험.동점 해소만의 효과로 해석하지 않음.
4. 상대 대비3개: 선택 이미지 점수에서 비선택 이미지 점수를 뺀 합의 양수 상위3개를 정규화한 탐색 실험.작은 차이를 과대해석할 위험과 모델 공통 편향이 남는다.

모든 제품 API·저장 형식·임계값은 그대로 두었다. 실제 추천 함수를 메모리 자료에 적용했다.동점 단독 대조군은 동일 우선순위일 때 실제 함수와864조건의 ID/점수/일치 태그 일치를 먼저 확인한 후 순서만 바꾸었다. 상대 대비 실험의 가중치 주입은 API/인증/공개 승인 시험이 아니라 수학적 민감도 비교다. DB 커서 접근은 실패하도록 막았다.

A안의 동일 선택32개에서30분 추천 작품 **구성**이 현행과 달라진 횟수는 다음과 같다.
