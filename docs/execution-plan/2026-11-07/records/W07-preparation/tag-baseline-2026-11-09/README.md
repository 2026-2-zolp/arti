대표 태그 포함률은 가장 높은 태그의 Top-1이 아니다. raw 점수 argmax의 대표 태그 일치율은50%이며, current 모드의 calibrated argmax를 측정한 값은 아니다. 모든 태그를 양성으로 두면 대표 포함률100%가 되지만 Micro-F1은41.2%에 그친다. 따라서 포함률 하나로 모델 품질을 판단하지 않는다.

현재 보정은 기본 .5보다 Macro-F1 약9.1%p, Micro-F1 약11.7%p 높고 예측 태그 수는3.6→2.625로 줄었다. 새 기준값을 맞추거나 서비스 설정을 변경하지 않았다. 기존 문서의 서비스 기준 대표 포함률90%와 태그별 F1 경향을 재현했다. 과거 문서의 교차검증88%는 이번에 재계산하지 않았다.

## 개인별 기준과 합의 민감도

| 평가자 | 역할 | 기본 Macro-F1 | 현재 Macro-F1 |
| --- | --- | --- | --- |
| R1 | 다중 라벨 | 62.8% | 71.2% |
| R2 | 대표 태그만 | N/A | N/A |
| R3 | 다중 라벨 | 61.3% | 63.9% |
| R4 | 다중 라벨 | 58.7% | 65.0% |
| R5 | 다중 라벨 | 58.0% | 60.0% |

평가자 ID는 이 기록 내 원 응답 이름 정렬 순서의 익명 표시다. 신규 응답/개인 메모는 공개하지 않았다. 기존 수집 방식상1명은 대표 태그에만 참여해 다중 태그 음성을 추정하지 않았다. 나머지5명 각각을 기준으로도 현재 보정의 Macro-F1 개선 방향은 같지만, 점수 범위60.0~71.2%로 평가자 영향이 남는다. R3의 대표 포함률은85%→75%로 줄었다. 전체 F1 개선이 모든 사람·모든 지표의 개선이라는 뜻은 아니다.

5명의 엄격 다수결과 기존 saved expected 라벨은 이번320개 셀에서 동일했다. 따라서 개발자 동점 처리 가능성이 코드에 존재해도 이번 다중 라벨 결과가 실제로 그 처리 때문에 달라졌다고 주장하지 않는다. 대표 태그 선정 규칙과 과거 문장·기준 선택의 영향은 여전히 남는다.

5명 중 한 명씩 제외하면 남은4명의 동점15~32개 셀은 제외했다. 현재 Macro-F1은71.4~75.0%, 기본은62.3~65.9%로 모든 제외 조건에서 현재 보정이 높았다. 이 절차는 평가자 구성 민감도 확인이며 모델을 재학습/threshold 재선정한 교차검증이 아니다. 조건마다 제외 셀이 달라 점수 범위를 직접 성능 향상으로 해석하지 않는다.

4/5 이상 합의한281개 셀의 현재 Macro-F1은73.4%, 나머지39개 셀은59.0%다. 의견이 갈린 셀에서는 all-positive 대조군이70.8%로 더 높았다. 작은 표본/양성 분포와 평가 기준에 따른 지표 민감성을 드러내는 결과이며 그 대조군을 제품에 채택할 근거는 아니다. 불일치 기록은 metrics.json에 보존한다.

강렬한 색감 precision38.5%·recall100%로 과다 부여가 우선 확인 대상이다. 차가운 색감 precision50%도 확인이 필요하다. 이 결과만으로 새 보정값을 저장하지 않고, 태그 정의/의견 분포/작품별 오류를 먼저 검토한다.

판정: 현재 보정은 기존 .5 기준선보다 이 개발 자료와 평가자 집단에서 일관된 개선 신호가 있다. 즉시 폐기/대형 모델 교체보다 기준선으로 유지할 이유가 있다. 최적성·팀 외 일반화·유영국 적합성은 입증되지 않았다. 태그 평가는 이미지 CLIP만 사용한다. scorer.load가 mDeBERTa도 로드하지만 이번40점에 텍스트 감정 추론을 수행하지 않았으므로 mDeBERTa/감정 비중의 품질 개선을 주장하지 않는다.

실행: 로컬 offline CPU4스레드, 앞선 실모델 측정과 같은 가중치/환경. 두 모델 로딩 약4.61초, 이미지 태그40점 합계 약2.26초. 다운로드·Django/DB/HTTP가 없는 직접 scorer 측정이므로 앞선 API 지연과 비교하지 않는다. 파일별 SHA를 저장했다. 원본 이미지·라벨·calibration·일반 DB·승인·provider 설정은 변경하지 않았다.
