# W05 계약 구현의 구체화

W02 확정 계약을 바꾸거나 과거 팀 합의로 꾸미지 않고 아래 구현 차이를 명시한다. G4 최종 인수는 별도다.

- 회원 기록의 GET /visits/:id는 Bearer 소유자만 허용한다. 계약의 관리자 역사 열람은 **GET /admin/visits/:id**를 추가해 X-Admin-Token 전용으로 제공한다. 같은 경로에서 두 역할의 토큰을 혼용하지 않는다. member 목록/쓰기는 본인 권한 그대로다.
- If-Match/ETag의 교차 origin 사용은 API 환경변수 ARTI_ALLOWED_ORIGINS에 명시한 origin만 허용한다. 기본은 빈 목록이고 로컬 Vite proxy의 같은 origin 흐름을 사용한다. OPTIONS가 허용되어도 실제 요청의 권한은 생략되지 않는다. Compose도 이 선택 설정을 전달한다. wildcard/자동 credentials 확대는 없다.
- 실제 provider 연결은 W07이다. W05는 승인 자료/맥락/history/스키마/부분 오류/timeout 계약을 구현하며, 기본 provider는503으로 빠르게 실패한다. 테스트의 patch 응답을 서비스 성공 응답으로 남기지 않는다. 비밀번호 재설정과 전시 일괄 분석은501 및 UI 비활성 안내를 유지한다.
- 파일 교체/삭제는 새 메타데이터를 먼저 저장하고 기존 연결이 끊긴 파일은 공개 연결/권한 확인 없이 읽을 수 없다. 오래된 파일의 물리 삭제 정책은 별도 정리 대상이며 자동 영구 삭제를 추가하지 않았다. 도면 교체 시 작품 좌표를 미배정으로 돌려 재확인을 요구한다.
- Git40점 가져오기는 기존 approved/mock seed를 재실행하지 않는다. 실제 ID와 이미지 해시를 보존하고 draft/source_check/좌표 null로 적재한다. 기존 레코드는 덮어쓰지 않는다. 이는 기존 로컬 DB의 고유 자료 인수를 완료하거나 제외한 결정이 아니다.
