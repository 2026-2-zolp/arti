# 격리 환경의 추천→동선→해설·가이드→도슨트 여정

2026-11-09 KST / 기준cffc6d6. 전용 Compose arti-journey-20261109, API4029/UI5189, 별도 PostgreSQL·미디어 볼륨에서 실제 React 브라우저를 점검했다. 일반 arti-dev와 유영국 자료는 수정하지 않았다.

## 자료와 시험 범위

기존 load_test_fixture의 합성2전시/13작품(운영 전시12점 중 pending1점, 비공개 전시1점)과 합성회원1명을 사용했다. 첫 작품의 요약/가이드만 합성 확정 상태로 만들어 원문·선택 요약·검수 가이드 경로를 비교했다. 나머지는 일반 팁 경로다. [재현용 seed 정리본](fixture-seed-reproduction.py.txt)은 첫 실행 로그인ID 오타를 수정하고 시험암호를 환경변수로 분리한 문서이며 실제 실행 파일과 바이트 동일하다고 주장하지 않는다. 관리 명령으로 읽을 때 전용환경 ARTI_ENV=test와 ALLOW_TEST_FIXTURES=true가 필요하다.

이미지는 기존1픽셀 합성fixture이며 색면 설명도 시험용 원문이다. GPT에는 이미지가 아니라 해당 텍스트 자료가 전달됐다. 이미지 감상 품질·실제 작품 사실성·실제 추천 개인화 효과를 검증한 결과가 아니다. 데스크톱 IAB의 MobileShell 화면 관측이며 실기기·TTS·이미지 다운로드 검증은 별도다.

초기에는 기존 OpenAI 호환 설정으로 합성 텍스트2회만 실제 GPT 호출했다. 요약→가이드 진입 뒤 이전 사용자 발언을 이어받는 응답을 확인했다. 이후 격리 API만 provider disabled로 재생성해503경로를 확인했다. 일반 앱 provider/키는 바꾸지 않았다. [응답](guide-docent-history.txt)은 실제 출력이며 가상 응답을 대체한 기록이 아니다.

## 수정과 재검증 루프

U09는 평면도 가로40m·걸음50m/분을 임의 가정한 walkMinutes로 약1분을 표시했다. 실제 축척/통로가 없으므로 U09Route.tsx에서 좌표 기준 위치 안내로 바꾸고 통로/시간 한계를 알렸다. 사용처가 사라진 lib/recommend.ts의 dist/walkMinutes도 제거했다. 추천 대상 선정/좌표 방문 순서 알고리즘과30분→3점 계약은 변경하지 않았다. 이 안내 보완이 F21의 고급 경로 알고리즘 미구현을 해결한 것은 아니다.

초기 합성회원 login_id를 이메일과 다르게 만들어 로그인401이 났다. 제품의 이메일 로그인 계약에 맞춰 시험계정만 수정한 뒤 성공했다. 멱등 재시험의 첫 요청은 저장된 canonical 프로필을 그대로 보내409였다. 원제출 submittedTasteProfile과 다르므로 정상 충돌이다. 원래 프로필을 재구성한 다음200을 확인했다. 401/409를 숨기거나 제품결함으로 오인하지 않는다.

회원 영수증 reload 직후 저장중→API200 후 저장완료로 바뀌는 과정을 확인했다. 중간 상태를 완료 증거로 저장하지 않고 최종 DOM/이미지를 다시 저장했다. http-status는 격리 API 재생성 이후 구간의 method/path/status만 담으며 최초 GPT2회의 wire 로그가 아니다. 실제 대화는 브라우저 출력·현행 provider 경로로 확인했다. 스크롤 위치의 수치 복원·모든 예외/실기기까지 통과했다고 확장하지 않는다.

기술/시니어: 추천계약·DB·멱등·컴파일을 대조. 콘텐츠/방문자: 대화 맥락·가이드/팁 구분·입력 보존·오해 가능한 이동시간을 점검. 팀/교수/평가위원: 합성/실자료·좌표/실제통로·실모델텍스트/전체품질을 구분. 운영: 전용환경·일반상태 보존·키/토큰 비기록·시험볼륨 보존을 확인했다. 동일 작성자의 관점별 자체 검토이며 사람 검수 대체가 아니다.

판정은 격리 기술 여정 통과다. 유영국 실제자료/팀원 라벨·전시장 배치 채택·정식 W07/G5·실사용자 인수는 남는다. 다음은 독립 라벨과 출처/사용 범위 검수, 실제 전시 적용 후 같은 여정을 다시 확인하는 단계다. 시험 컨테이너는 종료하고 볼륨은 보존한다.
