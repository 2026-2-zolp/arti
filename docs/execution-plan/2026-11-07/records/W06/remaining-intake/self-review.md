# 단계별 자체 검수

동일 작업자가 기존 팀·교수/평가위원·방문자/콘텐츠·기술/SENIOR 시각을 적용했다. 독립 심사·사람 승인과 구분한다.

| 단계 | 기준 | 결과 |
| --- | --- | --- |
| S1 자료·콘텐츠 |13점 전부 관찰/해석/출처/미확정 구분, 파일/기존 근거 SHA 확인, 조건부 인수와 보류 분리 | 조건부12·보류007. 보류 자체를 해소/승인한 것으로 표시하지 않음 |
| S2 인수 보완 | 예상version·draft·시연 표시 확인, 행 잠금 후 재검사, 기존 작품/검수/미디어·도면 보존, 실패 시 version/subtitle/신규파일 복구 |83회귀 통과. 일반/공식 초안이 시연 전시로 바뀌지 않도록 시연 표시 검사 보강 후83 재통과 |
| S3 실제 추가 | 일관된 사전 보존, dry-run 무변경, 기존3점 전체 행/파일 그대로, 추가12점 비공개·제안, 007 없음, 중복/재시작 검증 |15점 비공개 상태와 기존3점 해시 유지 통과 |

팀: 기록ID/assetID/DBID·과거표의 연결을 보존했다. 연구표를 승인 데이터로 덮어쓰지 않았다.
교수/평가위원: 도상 후보4점을 개별 판본처럼 설명하지 않고 실제 출품/관람 경로·교육효과/실모델 성능을 주장하지 않는다. 인수15점≠완성된 시연.
방문자/콘텐츠: 실제 보이는 색·선·면을 열린 질문/힌트로 연결한다. 산 이름·감정·낮/밤·작가 의도를 정답으로 만들지 않는다. 도슨트가 실제 발언만 이어받는 기존 계약 유지. 이번에는 GPT/브라우저 여정을 새로 시험하지 않았다.
기술/SENIOR: 기존 전시가 있으면 기본은 계속 거절한다. 명시 append+expected-version만 허용하고 lock에서 재검사한다. 제목/장소/기간·기존 작품·도면을 변경하지 않는다. subtitle만 확장 검수용으로 바꾸고 version을 올린다. 전시 subtitle/version도 오류 시 rollback되는 회귀를 추가했다.

자체 검수에서 판본 후보의 연도를 일반 작품처럼 노출하지 않도록 DB year 비움·제목 도상 후보·description/source의 개별 판본 미확정을 확인했다. 데이터/프롬프트를 승인/모델 태그로 승격하지 않았다. 사람의 동일성·사용 범위·콘텐츠 승인과007 해결은 아직 남는다.
