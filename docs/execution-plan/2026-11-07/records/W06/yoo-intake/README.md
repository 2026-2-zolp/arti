## 판정과 미통과 범위

**이번 인수표 작성·핵심 후보 선정·확장 방향 검토의 부분 과업은 완료. W06 전체, AC18·AC19·G5 통과로 승격하지 않는다.** 실제 DB 적재·사람검수/권리·전시 출품/도면·실모델/추천 품질·초심자 사용성 검증은 하지 않았다. 게이트 기준을 낮춰 이번 문서 검사를 그 증거로 대체하지 않는다.

원본과 점검 근거는 Git에서 제외된 private 사본이다. validation의 localEvidence 결과는 이 PC에 보관된 당시 자료와의 대조이며 원격 CI나 외부 검증을 뜻하지 않는다. 제품 코드가 바뀌지 않아 제품 회귀 테스트를 재실행하지 않았다. 계획 구조/아카이브 검사와 diff 검사는 실제 수행 결과만 기록한다.

다음: 핵심3점의 설명·가이드 검수 준비,07번 원 취득URL/캡션 확인. 실제 적재 전 백업/복원·범용 인수 기능의 최소 범위 검토. 키·모델 확장·하네스는 추후 논의. 원격푸시 없음.

마지막 staged 검사에서 새 검증JSON의 CRLF가 공백 오류로 검출됐다. 검사가 실패했는데도 이어진 로컬 커밋을 보완하기 위해 새 JSON을UTF-8/LF로 정규화하고 inventory 해시도 커밋 바이트 기준으로 갱신했다. 이후 staged diff 검사와 index의 JSON 해시/내용 일치를 다시 확인했다. 원시근거/원본 ZIP의 해시는 바꾸지 않았다.
