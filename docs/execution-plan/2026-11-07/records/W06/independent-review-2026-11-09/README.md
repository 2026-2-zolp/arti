# W06 독립 라벨·출처/사용 범위 후속 준비

2026-11-09 / 기준10955a9. 격리 전체 여정 통과 이후 실제 유영국 적용의 선행 자료를 준비했다. [사용자 확인 범위](usage-context.json),[16점 후속표](source-followup.json),[수집 프로토콜](protocol.json),[도구 안내](../../../../../review/yoo-2026-11-09/README.md).

사용자는 광권님이 웹에서 캡처했고 교내 졸업프로젝트 기간에만 사용할 것이라고 확인했다. 이 취득 방식·목적은 확정 입력으로 반영했다. 개별 원취득 URL/조건·프로젝트 종료일은 미확정이다. 인터넷 공개 사용으로 확장하거나 목적 확인을 이용 허락 확인으로 바꾸지 않는다.

[MMCA 공식 저작권 정책](https://www.mmca.go.kr/civil/copyright.do)과 [FAQ](https://www.mmca.go.kr/pr/FAQ.do)를 확인했다. 기관이 제시하는 자유이용 표시는 해당 자료별로 확인해야 하며, 표시 없는 자료는 사전 협의 안내가 있다. 현재 전달 캡처 파일16점의 개별 표시/이용 조건이 확인됐다는 증거는 없어 source-followup에 분리했다. 재단 홈페이지의 웹 조회는502로 실패해 새 이용 조건을 확인했다고 기록하지 않았다. 개별 작품의 법적 이용 가능 여부를 이 문서로 판단한 것은 아니다.

기존 검수 packet은 AI 후보 태그·설명을 포함한다. 이를 덮어쓰지 않고 첫 판단용 로컬 도구를 새로 만들었다. 이미지/중립 정의만 보여 주고 모델 점수·설명·타인 답·제목은 숨긴다. SHA-256으로16점을 식별하고 무응답/모르겠음/명시판단을 구분한다. 별칭·정의버전·파일해시·제시순서가 JSON에 기록된다. 이미지/대화가 서버에 전송되지 않으며 DB 적재 기능도 없다.

실제 브라우저에서 다른 이미지의 해시 거절, 원본16점 인식, TEST 별칭/시험 체크, 첫1점에8개 모르겠음 표시 후 draft 내보내기를 확인했다. [TEST 예시](TEST-example-not-team-review.json)는 형식 시험이며 팀원 응답0건을 유지한다. 모델/감정·태그·요약/가이드 승인 상태는 바꾸지 않았다. 기록용 화면에는 실제 작품 이미지를 포함하지 않았으며 원본 이미지는 Git 제외로 유지한다.

scripts/yoo_labels.py는 원 인수 manifest와의 대응, 해시/순서/명시 답/완료 수/상태/정의 버전과 TEST 제외를 검사한다. valid는 형식 통과이며 teamReviewAccepted/contentApproved는 항상 false다. 테스트 데이터로 실제 라벨이나 승인 건수를 채우지 않는다. 후속 집계기는 아직 없고 이 도구 결과를 기존40점 CSV 집계기에 바로 섞지 않는다.

## 개발 준비 통과 기준

- 고정16점의 ID/해시가 기존 인수 자료와 일치한다.
- 첫 라벨 화면에 모델 점수/후보 설명을 노출하지 않고 다른 파일을 거절한다.
- 실제 브라우저 내보내기를 검증하며 TEST가 기본 검사에서 거절된다.
- 빈칸·모르겠음·감정 미참여를 정답/음성 라벨로 만들지 않는다.
- 원래 검수/동결 문서와 DB 비공개 상태를 보존한다.
- 출처 동일성·의견 제출·이용 조건·관리자 확정을 분리하고 검증 결과를 기록한다.

기술/시니어는 입력 대응·변조/미완료/가짜승인 차단을, 데이터/운영은 원본/비공개·전송없음·사용 범위의 분리를, 콘텐츠/방문자는 모호한 색감 정의/독립 판단/부담을, 팀/교수/평가위원은 의견 분포·표본/사전노출·실제 사람 검수 대체 금지를 자체 점검했다. 실제 사람 승인과 다르다.

실제 검수는 다음 두 단계다. 1차는 이 도구의 독립 의견, 2차는 기존 콘텐츠 검수표와 source-followup을 보며 식별·판본·원문/요약/가이드·사용 조건·배치 여부를 항목별 판단한다. 팀의 판단이 오면 원본 응답을 보존하고 새 버전의 집계/결정 기록을 만든 뒤 실제 전시 적용과 여정 재검증을 진행한다. 이 준비만으로 W06/W07/G5를 통과시키지 않는다.

최종 검증: 관련27개가5.905초에 통과했고, 기존 W06 동결/계획 보호38개·guardrail25개·W02계약 오류0을 확인했다. [검증 요약](validation.json),[검수자 빈 기록](reviewers-blank.csv),[2차 콘텐츠 검수 빈 양식](content-review-blank.csv). 실제 검수자/날짜/결정은 채우지 않았다.
