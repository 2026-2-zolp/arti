# 시연 구성·선택풀 결정

16점의 [배치 초안](layout-draft.json)과 [구성도](layout-draft.png)는 실제전시장과무관한ARTI독자구성이다. A질감/색대비6점,B선/색면5점,C겹침/반복5점이며개별작품ID/파일매핑을유지했다. 입구후보(50,92),0~100좌표는초안이다. 실제미터/벽/문/통로가없으므로도보시간/최적길찾기근거로쓰지않는다. DB floor_plan/room/position은아직적용하지않았다.

초기취향풀은001~010의10점/5쌍으로현행계약을유지한다.001-002질감/밝기,003-004거친경계/색면,005-006대각선/초록중심,007-008따뜻함/차가움·선반복,009-010붉은면/초록겹침을비교한다. 비교는선정근거가설이며정답감정을강요하지않는다.9개별소장품후보와재단007을사용해판본미확정013~016을첫선택에서피한다.011/012격자를쌍으로넣는대안은현재ID정렬10과달라지고새선정설정이필요하므로이번에는유보한다.

나머지6점도배치/검수/태그가준비되면16점추천코퍼스에포함한다. 선택풀10과최종추천대상16은역할이다르고5쌍에서선택한작품만추천하는계약이아니다. ID변경/작품숨김으로선택풀을맞추지않았다. 현행make_pool을메모리복사본에검사해의도한10점과같음을확인했다. 실제DB는전부비공개/태그/좌표없음으로live readyPool0이다.

가설태그·초안좌표의추천함수검사는warm/cool/abstract/people×3/5/7로수량/중복/전시ID범위/입력순서안정성을확인한다. warm/cool3점이달랐고people는일치0,7점warm에서는5점만일치한다. 이값을실모델품질/개인화효과나실내경로성능으로설명하지않는다. 인물없음안내·일반추가추천구분은실제여정에서검수한다. 데이터가적다는이유로다른작가그림을이전시로몰래섞지않는다.
