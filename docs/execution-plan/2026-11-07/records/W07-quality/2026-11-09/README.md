# GPT 소규모 품질 검증과 프롬프트 보완

2026-11-09 KST / 기준6e2ea40. 연결 성공을 넘어 실제 감상 안내 품질을 확인해 달라는 요청에 따른 **텍스트 표본 평가**다. 정식 W07/G5·사람 검수·학습효과 검증은 아니다.

## 방법과 결과

호출 전에 [입력·판정 기준](frozen-plan.json)을 고정하고 SHA256을 저장했다. 핵심3점 후보의 메타정보/직접 쓴 시각 메모와 합성 경계 사례12개, 각1회, 사용자 설정 gpt-6-luna를 사용했다. 이미지·개인 대화·키는 전송 자료에 포함하지 않았다. 동일 제품 provider/adapter를 직접 호출했으며 이번 표본은 브라우저 왕복 시험이 아니다. 이전 [API 연계 smoke](../../W07-live-smoke/2026-11-09/README.md)와 구분한다.

## 발견 → 변경 → 재확인

- Q02: 입력에 없던 치수 단위 cm 추가 → 제공되지 않은 단위/정밀정보 추가 금지 → [재검증](targeted-retest-results.json)에서 단위 추정 제거.
- Q03: 요약에 메타정보가 많고 길었음 → 관찰 특징 중심 두 문장/200자, 불필요한 치수·번호 생략 지시 → 짧은 두 문장 확인. 길이는 프롬프트 목표이며 서버의 새 강제 계약은 아니다.
- Q08: 앞선 사용자 관찰을 암묵적으로만 연결 → 실제 발언을 짧게 짚고 다음 관찰로 연결하도록 지시 → 노란 면이 앞으로 보였다는 발언을 명시적으로 이어받음.
- Q11: 조형 해석이 근거 문단에 섞임 → 자료 사실/조형 설명/가능한 해석 구분 → 근거와 해석 분리 확인.

제품 변경은 backend-django/arti/llm.py의 지시문에 한정한다. 모델·키·요청/응답 스키마·토큰 예산·제한시간·승인 절차는 유지했다. [변경 추적](prompt-change.json), [안전 재검증 계획](safety-retest-plan.json)과 [응답](safety-retest-results.json)을 보존한다. 변경 후 Django69회귀 통과. 실행문은 키 없는 텍스트 증거로 보관하며 자동 CI/상시 하네스에 등록하지 않았다. 런타임 설정은 실행 후 새 개발 API에서 비밀값 없이 확인한 [스냅샷](runtime-after-runs.json)이므로 과거 응답 메타데이터로 가장하지 않는다.

## 비교와 판정 한계

고정된 사실 나열과 Q04 가이드를 비교하면 후자는 색면/경계를 직접 찾아보는 질문과 힌트를 제공한다. Q02 설명은 사실 전달, Q04는 관찰 행동을 유도한다. Q10은 쉬운 한 단계 관찰, Q11은 사실과 해석을 구분한 심화 설명이다. 이는 출력 비교이며 실제 초보 관람자의 이해 향상은 측정하지 않았다.

검증단은 방문자/콘텐츠, 기술/SENIOR, 팀/교수/평가위원 관점의 AI 검토다. 실제 교수·외부 평가위원의 승인이 아니다. 현재 판정은 **사람 검수를 전제로 한 초안 작성과 제한된 대화 시험에 적합**이다. 이미지 이해·16점 전체·반복 안정성·추천/감정 실모델·전체 사용자 여정은 미검증이다. 모델 확장·고저수준 분리·정식 하네스는 추후 함께 논의한다. 실제 공개 전에 W06 근거/권리/검수와 W07 정식 품질 검증을 수행한다.
