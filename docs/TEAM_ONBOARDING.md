# 새 팀원 시작 가이드

1. 조직 `2026-2-zolp` 초대 수락 및 `arti` 저장소 접근 확인
2. [프로젝트 Notion](https://app.notion.com/p/26-2-ARTI-a3534713f16782789905811787871032)에서 프로젝트 방향·이번 주 우선순위 확인
3. [개발 범위](PROJECT_SCOPE.md)와 [협업 규칙](CONTRIBUTING.md) 확인
4. Git 저장소 내려받기:
   ```bash
   git clone https://github.com/2026-2-zolp/arti.git
   cd arti
   git checkout -b feat/my-first-task
   ```
5. GitHub Issue 또는 팀에서 정한 작업을 맡고, 별도 브랜치로 작업 시작
6. 작업한 코드·테스트·설명과 함께 Pull Request 생성

> 현재 저장소는 초기 스캐폴딩 단계입니다. 실제 프론트·백엔드 앱 실행 명령은 기술 합의 및 초기 코드 추가 후 README에 기록합니다.

## 참고
- 앱 실행 실패나 버그: GitHub Issue
- 설계/범위·팀 의사결정: Notion 회의록 및 프로젝트 방향
- 계정·접근 문제: 조직 관리자에게 직접 문의
