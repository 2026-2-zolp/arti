## 2. ARTI가 발표한 내용

<i>녹음 1:41:37\~1:51:57 / '발표 당시 설명'을 정리한 구간</i>

### 2-1. 해결하려는 문제와 피드백 반영

ARTI는 관람객이 <b>어떤 작품부터 볼지</b>, 그리고 작품 앞에서 <b>무엇을 어떻게 감상할지</b> 막막해하는 상황을 돕는 개인화 미술관 관람 지원 서비스라고 소개했다.

- 첫 구현 대상은 서울시립미술관 <b>《유영국: 산은 내 안에 있다》</b>. 가상의 전시보다 실재하는 작품·전시 맥락을 활용하는 데 의의를 두었다.
- 김광권 팀원의 <b>기존 미술관 취재 경험</b>(성남큐브미술관·전남미술관)을 사용자 관점의 기획 참고 사례로 소개했다. 이는 프로젝트 착수 후 팀 전체가 진행한 사용자 실험이라는 뜻이 아니다.
- 실제 전시를 관람하면서 사용 흐름을 점검할 가능성도 설명했지만, <b>유영국 전시에 팀 전체가 방문하기로 확정한 것은 아니다</b>. 다른 전시 방문을 통한 관람객 관점 검토도 가능하다.

### 2-2. 사용자 흐름과 화면 설계

<b>전시 입구 QR/URL → 작품 이미지 기반 취향 선택 → 관람 시간 선택 → 추천 작품·이유 → 2D 지도·감상 질문 → 아트 영수증</b>

- <b>취향 파악:</b> 미술 용어를 몰라도 선호 작품 이미지를 선택할 수 있게 설계.
- <b>추천:</b> 선택한 이미지/작품의 특징과 관람 가능한 시간을 고려한 추천.
- <b>지도:</b> 관리자가 사전에 등록한 작품 위치와 평면도 기반으로 관람 순서 안내. <b>실내 실시간 GPS 추적은 아님.</b>
- <b>감상:</b> 먼저 눈에 보이는 색·형태 등을 질문하고, 답변과 궁금증에 따라 설명을 이어가는 Guided Looking 방향.
- <b>마무리:</b> 관람한 작품과 반응을 아트 영수증 형태로 제시.
- <b>회원/비회원:</b> 비회원도 주요 기능을 이용할 수 있게 하고, 회원은 취향과 과거 관람 기록을 저장하는 방향.

### 2-3. 데이터·추천·AI·관리자 기능

<b>작품 정보 구성:</b> 기본 정보 / 시각적 관찰 요소 / 해석·상징 / 작가·시대 맥락 / 작품세계·화풍 / 연관 작품·연작의 6개 영역을 소개. 출처와 검수 상태를 별도로 다루려는 방향을 설명했다.<br /><b>추천:</b> 초기 프로토타입은 작품 특징 태그와 사용자 선택을 비교하여 추천 우선순위를 만드는 방식이라고 발표했다. 더 정교한 결과 및 실제 전시 데이터 검증은 후속 단계이다.<br /><b>AI 감상:</b> LLM API를 활용하되 작품 정보·시각적 관찰 요소·앞선 대화 맥락 중 필요한 내용을 전달하고 문맥을 유지하는 방향으로 설계한다고 설명했다. <b>사용자 수준별 질문 조절과 근거 기반 답변 품질은 후속 구체화·검증 대상이다.</b><br /><b>관리자:</b> 작품 정보, 출처·검수, 2D 평면도상 작품 위치 등을 관리하는 화면을 설계했다고 소개했다.<br /><b>개발 현황:</b> 사용자·관리자 화면 및 추천/API/DB 관련 개별 프로토타입을 바탕으로 공통 인터페이스 연동을 추진 중이라고 발표했다. <b>서비스 전체 통합 완료 또는 실제 성능 확보로 기록하지 않는다.</b>
