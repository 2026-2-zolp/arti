# ARTI 조사 기준선과 실행계획 — 2026-11-06

이 묶음은 **준억님의 구현 착수 전 인수인계 기준선**이다. 준억님은 최초 GitHub 개설 이후 실제 개발을 하지 않았다고 이번 대화에서 명확히 정정했다. 과거 개인 메모·카톡의 “해보겠다/검증 중” 표현을 구현 완료로 계산하지 않는다.

현재는 사용자 화면·API·모델 코드가 각각 있는 **통합 전 프로토타입**이다. 실제 전시 데이터, 검수된 AI 응답, 저장 일관성, 목표 스택까지 검증된 서비스는 아니다. 완료율을 임의 산정하지 않는다.

**핵심 순서:** 원본 고정 → API·상태 계약 확정 → 현 스택에서 핵심 관람 흐름 연결 → 실제 AI·공식 자료 1개 작품으로 증명 및 Django/DRF·PostgreSQL 전환 → 목표 환경에서 인증·기록·실제 전시 검증 → 시연·문서 일치 확인. 실제 AI의 키·환경을 기다리는 동안에도 Django 기반 작업은 진행한다.

현재 Express를 완성품으로 고도화한 뒤 다시 전부 옮기는 방식은 피한다. 먼저 맞출 것은 화면·필드·검수 상태·재시도·저장 계약이다. 추천 알고리즘과 Python 모델 자산은 검증 후 이식/재사용한다. 목표 전환을 무기한 미루지 않는다.

이 계획은 **조사에 근거한 제안**이며 팀이 새로 합의했다는 뜻은 아니다. 자료상 확인되는 합의, 코드에서 확인한 동작, 이번 조사에서 제안한 결정을 각 문서에서 구별한다. 서비스 소스 수정·병합·배포·실제 모델 호출은 이번 조사에서 수행하지 않았다. 로컬 조사 스냅샷에만 의존성을 설치하고 검증 도구를 추가했다.

다음 착수 작업은 [T01·T02](04-work-plan.md): 통합 작업 공간을 만들고, 미정 계약을 작은 결정표로 확정하는 것이다. 별도 계정·API 키 없이 시작할 수 있다. Notion 게시는 하지 않았으며, 팀 공유 시 이 묶음을 회의록의 통합 후속 기록에 연결하면 된다.
