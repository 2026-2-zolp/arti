**V2 재검수**

- 같은 커밋을 새 Django·PostgreSQL 합성 환경에서 `ARTI_TASTE_PROFILE_V2_ENABLED=true`로 실행했다. 조사풀 10개 고유 작품·5쌍, V2 미리 확인 응답의 풀 버전·동점 근거 버전, 추천 요청의 V2를 확인했다.
- PC Chrome 320~412px에서 비회원 3·5·7점과 회원 3점을 완주했다. 추천 순서와 전체 지도 마커, 다음 작품과 영수증의 순서가 일치했다. 회원은 이번 관람만 적용해 영수증 저장 요청 1회에 기록 1건과 반응 이유가 남았고 마이페이지에서 같은 영수증을 열었다. 비회원은 저장 요청 0건이었다. 두 방식 모두 3점 관람에서 PNG를 받았다.
- 도슨트 비활성 환경은 503 뒤 입력 유지와 원래 작품 복귀를 확인했다. 로컬 모의 제공자 환경은 502 뒤 동일 요청 재시도에서 200과 현재 작품의 출처 참조를 확인했다. 작품별 답변 품질과 현장 배치는 실제 자료 인수 후 판정한다. [V2 시연 순서](2026-11-11_main_시연복구체크리스트.md#1115-시연-순서--취향-v2) · [설계서 반영](2026-11-11_R09_발표설계서_기술검증초안.md)
- 프론트 테스트 43건, 프로덕션 빌드, PostgreSQL V2 테스트 12건이 통과했다. 이번 V2 관람 검수에서 수정이 필요한 제품 결함은 재현되지 않았다.
