# 유영국 핵심3점 콘텐츠 검수 준비

2026-11-09 / [식별·출처표](../../data/intake/2026-11-09-yoo-youngkuk/README.md) → [GPT 표본 평가](../execution-plan/2026-11-07/records/W07-quality/2026-11-09/README.md) 이후 준비한 **팀 작성 검수 전 초안 v1**이다. 생성 응답 원본과 달리 사람이 읽을 검수안으로 편집했다. 공식 해설 원문이 아니며 DB 적재·관리자 확정·출품/권리 승인을 하지 않았다. 여기의 '근거 후보'는 개별 소장품 대응 조사 결과이며 사람 확인이 남는다.

## 검수 원칙과 U10→도슨트

작품해설에는 출처가 확인된 사실과 직접 보이는 관찰을 구분해 제시하고 쉬운 요약은 선택적으로 펼친다. 공식 해설을 확보하기 전 팀 설명을 공식 원문처럼 표시하지 않는다. 관람가이드는 짧은 도입·열린 질문·접는 힌트로 구성한다. 아래 각각 한 쌍을 우선 검수하며 답의 정오를 판정하지 않는다.

'내 생각 이야기하기'는 작품ID·확정된 가이드의 버전/질문·현재 진입 맥락을 이어준다. 사용자가 답하지 않았다면 도슨트가 관찰을 지어내지 않고 한 가지 단서를 제안한다. '이 부분 더 알아보기'는 보고 있던 해설/요약 맥락을 전달한다. 사용자의 실제 발언과 최근 성공 대화를 이어받고, 복귀 시 탭/위치를 유지하는 기존 계약을 따른다. 이 문서 자체가 구현·실제3점 브라우저 검증을 뜻하지 않는다.

## 001 — 바다(1960)

- 식별: yyk-intake-20261109-001. 후보 소장품09644. [국립현대미술관 개별 자료](https://www.mmca.go.kr/collections/collectionsDetailPage.do?artistnm=%EC%9C%A0%EC%98%81%EA%B5%AD&wrkinfoSeqno=10399). 제목·연도·캔버스에 유화 물감은 후보 메타정보, 실물/출품 확정은 대기.
- 직접 관찰: 회색·흰색·파랑·검은 형태와 붉고 노란 붓질, 불규칙한 경계와 표면의 질감. 색 명칭/위치는 첨부 파일을 사람이 다시 대조한다.
- 쉬운 설명 초안: '회색·흰색·파랑·검은 형태 사이로 붉고 노란 붓질이 보입니다. 색의 경계와 표면 질감에 눈을 옮겨 보세요.'
- 가능한 해석: 거친 붓질을 움직임이나 긴장으로 느낄 수 있으나 필수 감정·작가의 의도가 아니다. 구체 해변/사건으로 연결하지 않는다.
- 가이드 도입: '제목을 떠올리기 전에 붓질의 흔적부터 찾아보세요.'
- 질문: '매끈하게 보이는 부분과 거칠게 보이는 부분 중 어디에 먼저 눈이 가나요?'
- 접는 힌트: '색의 경계 한 곳을 골라 선이 이어지는지 끊기는지 살펴보세요.'
- 도슨트 진입 시험: 이 질문에서 '모르겠어요' → 사용자가 말하지 않은 바다/감정 회상 없이 한 군데 경계 관찰 제안. 실제 관찰을 답한 후에는 그 발언을 이어받는지 확인.

## 004 — 산(남)(1968)

- 식별: yyk-intake-20261109-004. 후보 소장품09637. [국립현대미술관 개별 자료](https://www.mmca.go.kr/collections/collectionsDetailPage.do?artistnm=%EC%9C%A0%EC%98%81%EA%B5%AD&wrkinfoSeqno=10392). 크기 원문129×129에 단위를 추정해서 붙이지 않는다.
- 직접 관찰: 노랑·초록 계열 큰 삼각형 색면, 대각선, 아래쪽 붉은색·주황색 띠.
- 쉬운 설명 초안: '큰 삼각형 색면과 대각선이 화면을 나눕니다. 아래쪽의 붉고 주황색인 띠를 따라 시선을 옮겨 보세요.'
- 가능한 해석: 색면이 겹치거나 앞뒤로 느껴질 수 있다. 특정 산의 지형/고향의 상징이라는 단정은 근거가 없다.
- 가이드 도입: '색 이름보다 색면이 만나는 경계를 먼저 보세요.'
- 질문: '두 색면이 만나는 곳 중 시선이 오래 머무는 곳은 어디인가요?'
- 접는 힌트: '대각선 한 줄을 골라 양옆 색이 어떻게 다른지 비교해 보세요.'
- 도슨트 진입 시험: 사용자가 '노란 면이 앞으로 보여요'라고 말한 경우만 이를 인용하고 초록 면과 비교하도록 이어가기. 앞뒤 느낌을 정답으로 강요하지 않기.

## 010 — 산(1984)

- 식별: yyk-intake-20261109-010. 후보 소장품09628. [국립현대미술관 개별 자료](https://www.mmca.go.kr/collections/collectionsDetailPage.do?artistnm=%EC%9C%A0%EC%98%81%EA%B5%AD&wrkinfoSeqno=10383). 동일 제목의 다른 작품/연작과 식별자를 섞지 않는다.
- 직접 관찰: 파란 바탕, 겹치는 초록 산 모양, 밝은 윤곽과 아래 파란 부분.
- 쉬운 설명 초안: '파란 바탕 위로 초록 산 모양이 겹쳐 보입니다. 밝은 윤곽과 그 안쪽 색면을 번갈아 살펴보세요.'
- 가능한 해석: 겹침·색 대비를 거리나 리듬으로 느낄 수 있지만 특정 산 이름·작가 심리를 알 수 있다는 뜻은 아니다.
- 가이드 도입: '윤곽과 색면 중 먼저 보이는 쪽을 골라보세요.'
- 질문: '밝은 윤곽선을 따라 볼 때와 초록 면을 볼 때 어디가 다르게 느껴지나요?'
- 접는 힌트: '산 모양 두 개가 겹치는 곳을 한 군데만 비교해도 좋아요.'
- 도슨트 진입 시험: '어느 산이고 몇 분 걸리나요?' → 자료에 없는 산 이름/실제 보행시간을 만들지 않기. 관람 순서와 실내 보행 경로의 차이를 구분.

## 사람 검수표 — 세 작품 각각 별도로 작성

| 항목 | 확인할 것 | 현재 |
| --- | --- | --- |
| 식별·출처 | 파일 해시/도상과 개별 작품·연도·판본 후보 대조 | 사람 확인 대기 |
| 근거 | 사실/직접 관찰/가능한 해석 구분, 단위·의도 추정 없음 | 초안 대기 |
| 사용 권한 | 이미지 획득 경로·전시 시연 사용 범위 | 미확정 |
| 초보 관찰 | 열린 질문·힌트 대응, 감정/정답 강요 없음 | 초안 대기 |
| 해설·가이드 독립 승인 | 원문 출처·요약·가이드를 각각 확인, 기존 확정본 덮어쓰기 금지 | DB 미적재 |
| 추천 검수 |8태그·6감정의 근거/사람 확인, 세 작품 간 차이 | 실모델 미실행 |
| 전시·배치 | 실제 출품 근거 또는 시연 재구성 표시, 도면/입구/좌표 | 미확정 |
| 여정 | U10→U11 맥락/복귀, 빈 답·반복·근거 밖 질문 | 실제3점 시험 대기 |

기록 양식: recordId / 검수자 / 검수일 / 항목별 통과·수정·보류 / 수정 전후 / 출처 / 요약 승인 여부 / 가이드 승인 여부 / 권리 확인 여부. 이 표를 체크했다고 DB의 approved/confirmed를 자동 설정하지 않는다. 승인할 사람이 직접 자료를 확인한 후 현행 관리자 절차로 반영한다.

다음은 이3점의 사람 검수·자료 보강 → 16점 식별/콘텐츠 확장과 명시적 범용 인수 형식 → 비공개 적재 → 도면/좌표·태그 검수 → 승인된 작품으로3/5/7점 추천·U10/11·기록/영수증 검증 순서다. 16점이 모두 자동 승인되거나 실제 전시 출품작이라는 전제는 두지 않는다. 정식 하네스/모델 분기는 이후 논의한다.

비공개 적재의 선행조건인 [분리 환경 백업·복원 확인](../execution-plan/2026-11-07/records/backup-restore/2026-11-09/README.md)은 합성 자료로 마쳤다. 실제 인수 시에도 원본 DB/미디어를 한 세트로 먼저 보존한 후 새 대상에 적재한다.
