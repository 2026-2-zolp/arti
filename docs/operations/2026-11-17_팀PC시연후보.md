- 관람·답변 재현은 별도 PowerShell에서 [모의 도슨트 기동](2026-11-11_main_시연복구체크리스트.md#모의-도슨트-성공과-실패-복구) 절차를 따른다. 기본 주소는 `http://127.0.0.1:5239`다. 시작 전에 `/api/ready`가 PostgreSQL과 `X-Arti-Docent-Mock: 1`을 반환하는지 확인한다. 준비한 합성 계정과 비밀번호는 각 PC에서만 사용한다.
- 운영형 회원·관리자·복원 확인은 [운영형 원본 기동](2026-11-11_main_시연복구체크리스트.md#1-원본-기동과-준비) 또는 아래 Chrome 포함 자동 검사로 실행한다. 포트가 이미 사용 중이면 다른 루프백 포트를 지정한다.

## 2. 관람과 관리자 재현

1. **비회원 관람** · 모의 주소의 `/exhibitions/fixture-ex01`에서 관람을 시작한다. V2 비교 첫 화면에서 **크게 보기 → Esc**로 닫아 포커스 복귀를 보고, 위쪽 작품을 다섯 번 고른다. **취향 미리 확인 → 이 취향으로 계속 → 30분 → 추천 → 지도** 순으로 진행한다. 기본 합성 자료에서는 검증용 작품 `01 → 03 → 05`가 추천·지도·감상·영수증에 같은 순서로 나온다.
2. **도슨트 오류와 복구** · 첫 작품에서 **이 부분 더 알아보기**를 누른 뒤 `[합성 502 팀PC-01 재현] 그림에서 가장 밝은 부분이 보여요.`를 보낸다. 회차마다 `팀PC-01`을 바꾼다. 첫 요청은 502, 초기 질문을 유지한 **다시 시도**는 200이어야 한다. 상단 뒤로가기로 같은 작품에 복귀한다. 다음 작품 카드의 썸네일과 구간, 영수증 PNG 열림을 보고 Chrome Network에서 정확한 경로 `POST /api/visits`가 0건인지 확인한다.
3. **관리자 진입** · 관리자 전시 관리에서 전시명에 키보드 포커스를 옮겨 Enter로 작품 관리에 진입한다. 작품명에서도 Enter로 같은 작품 상세가 열린다. 목록의 체크박스는 선택만 바꾼다. 관리자 계정과 가입은 [운영형 로컬 시연 준비](2026-11-11_main_시연복구체크리스트.md#1-원본-기동과-준비)를 따른다.
4. **회원·복원** · 회원이 관람을 마치면 원래 영수증 ID로 기록 1건이 생긴다. [복원 후 권한 확인](2026-11-11_main_시연복구체크리스트.md#복원-후-영수증-접근-권한-확인)에서 본인 200·같은 ID와 기록 1건, 관리자 200, 다른 회원 403, 비회원 API 401, 공개·비공개 미디어 200/404/200을 확인한다.

```powershell
pwsh -NoProfile -File ./scripts/runOpsPreflight.ps1 -Revision b8f4c2e6ebb27e84d5e405f38bf87b4e57c062fa -HttpsPort 5623 -ChromeReceipt
```

자동 검사는 새 합성 PostgreSQL·미디어에서 실행한다. 출력의 `data/private/arti-preflight-*/result.json`에서 `revision`, `status`, `failedStage`와 필요한 상태 코드만 회신한다. 복원 세션 유지·일괄 재로그인 정책과 실제 배포 주소는 팀 운영 논의로 결정한다.
