# 11/19 취향 조사 10점·5쌍 재구성안

광권님이 전달한 `취향태그10작품 (4).zip`의 10점을 실제 이미지로 대조했다. 아래 번호는 ZIP 파일명 번호이며, 짝의 순서는 이 표를 따른다. 관찰한 시각적 단서와 태그는 팀 검수용 제안이다. 새로 붙인 태그의 CLIP 점수와 도판 이용 가능 범위는 확인 대기다.

| 순서 | 두 작품 | 확인할 차이 | 시험용 태그 제안 |
| --- | --- | --- | --- |
| 1 | 1 클림트 〈아델레 블로흐바우어의 초상 I〉 ↔ 10 키르히너 〈베를린 거리 풍경〉 | 두 그림 모두 인물이 보인다. 화면의 금빛·황토색과 짙은 파랑 대비를 본다. | 따뜻한 색감 ↔ 차가운 색감 |
| 2 | 4 르누아르 〈피아노 치는 소녀들〉 ↔ 6 드가 〈푸른 옷의 무희들〉 | 인물이 있는 장면에서 옅게 이어지는 색과 짙은 파랑의 색 덩어리 대비를 본다. | 부드러운 색감 ↔ 강렬한 색감 |
| 3 | 3 고흐 〈론강의 별이 빛나는 밤〉 ↔ 7 칸딘스키 〈여러 개의 원〉 | 둘 다 어두운 바탕에 밝은 점이 있다. 강과 거리로 읽히는 장면과 원이 만드는 구성을 비교한다. | 풍경 ↔ 추상 |

**추천 교체안** · 5번 쌍의 클레를 모네 〈양산을 든 여인 — 모네 부인과 아들〉(1875)로 바꾼다. 두 작품 모두 모네의 야외 장면이므로 사람에 시선이 가는 구도와 풍경에 시선이 가는 구도를 비교할 수 있다. `인물` ↔ `풍경`으로 8개 태그를 한 번 이상 보여주며, 전체는 10점·5쌍이다. 미국 국립미술관이 해당 도판을 퍼블릭 도메인으로 표시한다. 실제 사용본을 정할 때는 공식 다운로드본 파일명·해시·기관 표기를 기록하고, ZIP의 노적가리 도판도 정확한 판본과 출처를 대조한다. [미국 국립미술관 도판](https://www.nga.gov/artworks/61379-woman-parasol-madame-monet-and-her-son) · [시카고 미술관 노적가리 판본 자료](https://publications.artic.edu/node/135598)

- 1~4번은 사람 검수로 비교 축이 실제로 읽히는지 확인한다. 특히 드가의 `강렬한 색감`과 4번의 그늘·빛 대비는 이번에 제안한 판정이다. 5번에서 외부 작품을 쓸 경우 동일한 기준으로 태그를 확인한다.
- 팀 검수자는 축과 태그 이름을 보기 전에 각 쌍을 고르고, 고른 이유를 한 줄만 남긴다. 두 그림이 비슷해서 망설였는지와 어떤 차이를 보고 골랐는지 확인한다. 다음 사람에게 보여줄 때 위아래를 바꿔 순서 영향도 살핀다.
- 한 작품에 비교 기준에 해당하는 태그 하나를 붙이면 10개 슬롯에서 8개 태그를 쓸 수 있다. 교체안에서는 `차가운 색감`과 `풍경`이 두 번, 나머지 여섯 태그가 한 번이다. 최종 취향은 마지막 화면에서 직접 수정한다.
- 조사풀을 따로 적재할 때는 판본·도판 출처·사용 범위·팀 검수 확인을 먼저 기록한다. 전체 태그와 이미지의 승인·활성화 순서는 [조사풀 운영](취향조사풀-운영.md)을 따른다.

## 마지막 태그의 초기 선택

선택한 작품의 태그 중 최다 빈도가 하나면 그 하나, 두 태그가 동점이면 두 개가 켜진다. 최다 빈도 태그가 세 개 이상 모이면 모든 태그를 끈 상태에서 사용자가 고른다. 8개 태그는 모두 켜고 끌 수 있다. 선택한 작품에 없던 태그가 추가되면 기존의 직접 선택 방식으로 추천한다. 새로고침과 기존 취향 저장에는 사용자가 정한 값을 유지한다.

5쌍의 가능한 선택 32가지에 제안 태그를 대입한 결과다. 실제 사용자 비율은 팀 검수에서 따로 본다.

| 배치 | 초기 0개 | 초기 1개 | 초기 2개 |
| --- | ---: | ---: | ---: |
| 원본 다중 태그 | 16 | 4 | 12 |
| ZIP 10점 재배치 | 12 | 16 | 4 |
| 제5쌍 모네 교체안 | 18 | 12 | 2 |

교체안은 `인물` 태그의 선택 기회를 추가하는 대신, 마지막에 직접 골라야 하는 경우도 늘어난다. 팀 검수에서는 5쌍의 차이를 알아보기 쉬운지와 함께, 기본값이 비어 있을 때 태그 하나를 고르고 진행하기 쉬운지 확인한다.

- 로컬 프론트 빌드·테스트 60건이 통과했다. 합성 Chrome에서 8개 동점을 모의해 초기 선택 0개, `빛` 선택 후 계속 버튼과 새로고침 복구를 확인했다. 별도 합성 PostgreSQL에서 2개 동점의 초기 선택, 저장 V2 재시도, 조사풀 변경 후 태그 확인과 지도 진행도 통과했다.

## 모네 교체안의 실제 도판 로컬 검수

- 1~4번은 위 표의 순서를 그대로 쓰고, 마지막 쌍은 모네 〈양산을 든 여인〉과 〈노적가리〉로 구성했다. ZIP의 9개 파일을 태그표의 해시와 대조했다. 미국 국립미술관 도판 `1983.1.29`는 가로 645×세로 800px인 공식 제공본을 사용했다. 실제 도판과 시험 매핑은 Git 제외 `data/private/monet-taste-preview-1119/`에 보존한다.
- PC Chrome 390×812에서 두 경로를 각각 완주했다. 경로마다 5쌍의 실제 도판 10장이 로드됐다. 모두 최다 동점인 경우 초기 0개에서 `풍경`을 골랐고 V2 `picks`로 전송됐다. `차가운 색감`이 유일한 1위인 경우 초기 1개에서 `따뜻한 색감`으로 바꿨고 V2 `manual`로 전송됐다. 두 경로에서 새로고침 뒤 편집한 태그가 유지됐다.
- 독립 조사풀을 사용해 별도 합성 전시에서 30분 추천을 검수했다. `풍경`은 `fixture-art01·03·05`, `따뜻한 색감`은 `fixture-art02·04·06`이 돌아왔다. 증거는 로컬 `data/private/monet-taste-preview-1119/chrome-result.json`에 있다. 팀 도판 권리 확인과 공개 결정은 대기 상태다.
