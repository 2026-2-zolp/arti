# A-05 팀 도면 인수와 관람 동선 검수

팀 도면은 사용 허가를 확인한 한 장부터 확인한다. 별도 합성 전시에서 검수한다. 관리자가 도면과 출입 조건을 확인해 저장하면 새 경로를 관람자가 볼 수 있다.

## 받아야 할 자료

- 원본 도면 파일과 버전 또는 확인일, 어느 층인지, 시험 환경에서 써도 되는지.
- 입구와 전시실 경계, 기둥·벽·통과할 수 없는 구역, 문 위치와 평상시 개방 여부. 폐쇄나 일방통행이 있는 곳은 해당 구간과 조건을 표시한다.
- 작품 식별자·전시실·배치점. 같은 방에 여러 작품을 두고, 통로에서 여러 번 꺾이는 경우와 문 하나가 막히는 경우를 각각 한 구간씩 정한다.
- 현장에서 통행 가능한 경로를 아는 검수 담당. 원본의 픽셀 길이만 있고 실제 거리를 모르면 도면의 비례로 순서를 비교한다. 미터 단위 판단에는 기준 길이가 필요하다.

## 관리자부터 관람자까지

1. 합성 시험 전시의 A-05에서 원본 도면을 연다. 연결 기준의 층·입구 방향을 확인한다. 방 벽·기둥과 막힌 구간을 입력하고 통행 가능한 문·복도에 연결점을 둔다. 원본과 네이티브 지도를 비교해 문·작품이 벽 반대편에 놓이지 않았는지 본다.
2. **이동 구조 등록**에서 우회가 필요한 A·B, 같은 방의 다른 작품 간 A·B, 다른 방의 A·B를 고른다. 제안된 연결점은 현장 기준으로 조정한다. 이때 관람자는 기존 저장본을 본다.
3. 기존 V2에서 같은 취향과 시간으로 3·5·7점의 결과 ID와 순서를 적는다. 이동 구조를 저장한 뒤 같은 입력을 반복해, 작품 집합은 유지되고 통로에 따른 방문 순서가 바뀔 수 있는지 본다. 연결 경로가 없는 경우 이동 경로 표시를 재확인한다. 벽·기둥을 가로지르는 선이 보이면 해당 경로를 통과로 판정하지 않는다.
4. 관리자에서 실제로 막힐 문을 비활성화하거나 지운 뒤 미리보기를 재확인하고 저장한다. 관람 중인 탭에선 새로고침과 뒤로가기를 반복해 같은 관람이 이어지고, 이미 본 작품과 현재 위치가 보존되는지 확인한다. 회원 영수증은 한 건, 비회원 저장 요청은 0건을 확인한다.
5. 원본을 개정하거나 운영 시간이 다른 문, 일방통행 구간이 있으면 회신에 조건을 따로 적는다. 현재 검수는 관리자가 저장한 구조를 기준으로 하므로 실제 운영 시간과 통행 방향을 지도에 나타낼 필요가 있는지 먼저 결정한다.

작품 순서로 바로 보기는 팀 피드백용 합성 전시에서 확인한다. 합성 지도와 Chrome 회귀는 [팀 PC 검수 순서](2026-11-17_PR50_팀PC검수.md)에서 재현할 수 있다.

```text
검수자 / 전시 / 도면 버전 / 입구 / 운영 시각·문 상태
선택한 A·B / 실제 통행 가능한 구간 / 저장 전 관람 화면 / 저장 후 관람 화면
3·5·7점 작품 집합·순서 / 막힌 문 결과 / 회원 영수증 건수 / 비회원 저장 요청 건수
현장에만 있는 통행 조건 / 추가로 수정할 위치
```
