## 직접 관람과 기존 취향 추천

1. 작업 폴더의 상위 경로에서 `git clone https://github.com/2026-2-zolp/arti.git arti-pr50-review`를 실행한다. 새 폴더에서 `git switch --detach 76118565652111fb68012b000ad5ea98875731a1`를 실행하고 `git rev-parse HEAD`로 기준을 확인한다.
2. Docker Desktop과 PowerShell을 열고, PR에 연결된 기록의 **팀원 PC 직접 관람** 절차로 실행한다. 기본 주소는 자기 PC의 `http://127.0.0.1:5478/exhibitions/fixture-ex01`이다. [합성 전시 기동 순서](https://github.com/2026-2-zolp/arti/blob/7eb14be/docs/작업기록/2026-11-17_A05도면버전과Luna도판모의검수.md#팀원-pc-직접-관람)
3. **전시 순서로 바로 보기**로 첫 작품을 열고, **다음 작품 안내**에서 썸네일·제목·구간을 확인한다. 한 번 뒤로 간 뒤 다시 진행하고, 안내에서 새로고침해 같은 작품 구간이 나오는지 본다. 첫 화면에서 **내 취향으로 추천**을 다시 열어 비교 5쌍과 추천 진입도 확인한다.
4. 비회원으로 마지막 작품까지 진행한다. Chrome 개발자 도구의 Network에서 Preserve log를 켜고 `POST /api/visits` 요청이 0건인지, 영수증에서 저장한 PNG가 열리는지 확인한다. 합성 시험 계정으로 한 번 더 진행하면 같은 관람 영수증이 한 건만 저장되는지 마이페이지에서 확인할 수 있다.
