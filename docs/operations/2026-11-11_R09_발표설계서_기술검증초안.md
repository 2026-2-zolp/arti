> ARTI는 처음 전시를 보는 사람이 취향에 맞는 작품을 고르고, 작품 앞에서 관찰을 이어가도록 돕습니다. 시연에서는 전시와 별도의 취향 조사에서 작품 다섯 쌍을 비교하고, 30분 관람을 선택해 추천 작품 세 점과 지도 순서를 봅니다. 관람가이드에서 질문을 보내면 도슨트가 지금 보고 있는 작품과 질문을 이어받습니다. 답변이 실패해도 질문이 남아 다시 보낼 수 있고, 관람을 계속해 아트 영수증까지 볼 수 있습니다.

## 완료보고서 기술 검증 초안

ARTI는 작품 다섯 쌍에서 수집한 선택을 바탕으로 취향을 확인하고, 선택한 관람 시간에 맞춰 작품과 관람 순서를 제안한다. 관람객은 작품 해설과 관찰 질문을 보고, 선택적으로 도슨트와 대화하거나 반응을 남긴다. 회원은 지난 관람을 마이페이지에서 영수증으로 다시 열 수 있다.

- **관람 검증** · 취향 V2를 켠 합성 환경에서 비회원 3·5·7점과 회원 3점 관람을 완료했다. 추천과 지도·영수증의 작품 순서가 일치했고, 회원 관람은 한 건 저장됐다. 비회원은 PNG를 내려받았고 관람 저장 요청은 없었다. [V2 검수 결과](2026-11-15_즉시개발과시연로드맵.md#1115-pc-기준과-v2-실행-결과)
- **관리자 검증** · 전시를 등록·공개하고 도면 교체 후 입구와 작품 좌표를 다시 저장했다. 새 관람의 추천 순서는 A→B→C에서 C→B→A로 바뀌었고, 관람자 지도도 새 좌표를 표시했다. 이미지 주소를 비워 두면 새 작품 등록이 실패하는 결함을 수정했다. [관리자 검수 기록](../작업기록/2026-11-15_관리자전시등록과도면반영.md)
- **운영과 복구** · 로컬 Nginx의 정적 화면과 Django API 연결, 빈 PostgreSQL의 마이그레이션 8개, 별도 볼륨 복원을 확인했다. 복원한 회원 영수증 두 건과 관리자 기록이 일치했고, 공개·비공개 미디어 두 파일의 SHA-256과 접근 권한을 대조했다. [운영형 검수 기록](../작업기록/2026-11-15_운영형로컬기동과합성복원.md)
- **최종 확인 범위** · 실제 유영국 작품은 승인된 도판·문안·좌표와 도슨트 응답을 확인한다. 현장 시연 주소, 두 기기의 관람과 HTTPS PNG 공유, 대상 배포 환경 검증은 각각 시험 결과를 받아 최종본에 반영한다.
