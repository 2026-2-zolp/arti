2026-11-09 / [교수님 수정 요구](https://app.notion.com/p/41334713f16781d7af64feabbc012ea2) / [기존 양식 대조 기록](https://app.notion.com/p/3d434713f167812c91d8c24ff78e2b70). **본문은 문구 초안이며 HWP 수정본·팀원 최종 확인·실제 재제출이 아니다.** 원본 HWP는 이번 작업에서 직접 열지 않았으므로 행/열·정확한 기존 세부기능명에 맞춘 배치·시각 검수가 필요하다.

## 작성·확인 순서

1. 마지막10주차 HWP를 보존하고11주차 수정 사본을 만든다. 과거 주차 동그라미/결과는 임의 소급 변경하지 않는다.
2. 계획 칸과 결과 칸을 분리한다. 결과에는 본인이 실제 수행한 작업을 기능별 한 문장으로 기재한다.
3. 완료·진행·검증 대기를 구분하고 관련 커밋/로그/자료와 대조한다. 다른 사람이 통합한 기능을 본인 신규 구현으로 쓰지 않는다.
4. 아래 문구를 원본의 대응 기능 행에 나눠 배치한다. 전체를 한 칸에 몰지 않고 용지·페이지 넘침을 확인한다.
5. 팀원별 문구를 확인하고 취합/업로드 담당을 정해 사이버캠퍼스에 제출한다. 파일명·제출시각·접수 상태를 남긴 후 완료 처리한다.
