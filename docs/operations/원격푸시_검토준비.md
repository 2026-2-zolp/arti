원격 저장소 push/admin 권한은 연결 메타데이터에서 확인했으나 실제 Git 전송 인증·branch rule 통과까지 실행한 것은 아니다. 원격이 나중에 바뀌면 다시 fetch하고 차이를 검토한다. 별도 인수할 로컬 고유자료는 원본보존 정책이며 미수령/unknown을 유지한다.

## 확인 이후 실행 절차

```powershell
git status --short
git fetch origin refs/heads/dev/임준억:refs/remotes/origin/dev/임준억
git merge-base --is-ancestor origin/dev/임준억 HEAD
git log --oneline --first-parent origin/dev/임준억..HEAD
git diff --stat origin/dev/임준억...HEAD
```

작업트리 clean·대상브랜치 일치·조상 검사 성공과 사용자 확인을 전제로 다음 **일반 push만** 실행한다. 원격이 갈라졌으면 중단해 차이를 검토하며 force로 덮어쓰지 않는다.

```powershell
git push origin HEAD:refs/heads/dev/임준억
```

위 push는 아직 실행하지 않았다. 푸시 후 원격 SHA를 대조한다. 기존 main/팀원 브랜치를 지우거나 바꾸지 않는다. 최초 준비 이후 CI workflow를 추가했다. dev/** push 시 4job이 실행되지만 실행 결과를 확인하기 전 성공으로 처리하지 않는다. AWS 배포는 포함하지 않는다.
