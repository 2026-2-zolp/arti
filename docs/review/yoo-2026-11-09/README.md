# 유영국16점 독립 라벨링 사용 안내

이 도구는 검수자가 그림을 보고 개인 의견을 남기기 위한 별도 로컬 도구다. 현재 서비스의 관리자 확정 기능이나 이미지 이용 허락을 대신하지 않는다. 원래 평가표는 보존하며 새 의견은 별도로 수집한다.

## 검수자에게 전달할 것

이 폴더의 labeling.html과 원본 이미지16점이 필요하다. HTML에 파일 식별 manifest가 포함돼 있어 이름이 바뀌어도 원본 바이트가 같으면 식별한다. 이미지를 Git에 올리거나 외부 사이트에 업로드할 필요가 없다. 검수 자료는 사용자가 밝힌 교내 졸업프로젝트 기간의 범위로 다룬다. 개별 취득 URL/이용 조건은 별도 확인한다.

1. 검수자는 먼저 모델 점수/AI 후보 태그/다른 사람의 답을 보지 않고 시작한다. 이미 본 적이 있다면 별도 검수자 기록에 표시한다. 첫 판단을 마친 뒤에만 의견을 대조한다.
2. labeling.html을 브라우저에서 열고 별칭(R01 등)을 입력한다. 파일 열기에서 동작하지 않으면 저장소 루트에서 아래 로컬 서버를 실행한 뒤 http://127.0.0.1:5199/labeling.html 로 연다.
3. 판단 기준을 읽고 전달받은 이미지 파일16점을 선택한다. 파일명 대신 SHA-256을 확인한다. 16/16점 준비 여부를 확인한다.
4. 작품 순서는 페이지를 열 때 섞이며 제목·해설·AI 점수·이전 사람 답은 표시하지 않는다. 태그마다 해당/비해당/모르겠음을 명시한다. 비워 둔 항목은 부정 라벨이 아니다.
5. 분위기 의견은 선택 사항이다. 본인의 감상이며 작가 의도/정답 감정이 아니다. 참여하지 않으면 미검수로 남긴다.
6. JSON을 내려받는다. 전부 답하지 않아도 draft로 받을 수 있지만 완료/승인으로 처리하지 않는다. 자동 저장/초안 재불러오기 기능은 없으므로 같은 페이지를 유지하며 진행하고 닫기 전에 저장한다.
7. 결과 파일을 프로젝트의 비공개 인수 경로로 전달한다. 이 도구가 자동 제출하지 않는다. 실제 검수에서는 내부 동작 시험 체크를 하지 않는다. TEST 응답은 집계에서 제외한다.

실행 예: python -m http.server 5199 --bind 127.0.0.1 --directory docs/review/yoo-2026-11-09

## 인수자 확인

python scripts/yoo_labels.py 응답파일.json 으로 형식·작품ID·파일해시·버전·순서·완료 수를 확인한다. 내부시험만 --allow-test를 사용한다. 검증기가 valid라고 해도 콘텐츠나 전시가 승인됐다는 뜻은 아니다. responseStatus는 제출/초안이고 관리자 reviewed/confirmed와 구분한다. 서로 다른 별칭이 실제로 독립적인 사람인지 검증기가 확인해주지는 않는다.

가능하면3명 이상의 독립 의견과 팀 외 관점을 일부 확보한다. 인원이 적어도 억지로 합의시키지 않고 인원·동점·모르겠음·불일치를 보존한다. 모든 태그에 대해 판단 인원과 유효 판단 분모를 함께 보고한다. 수집 전 사용한 정의 버전과 과거 모델/자료 노출을 기록한다. 이미 탐색한 핵심3점은 독립 holdout으로 주장하지 않는다.

라벨 후에는 별도 단계에서 작품 식별/판본·출처·설명·요약·가이드·시연 배치와 이미지 취득/사용 조건을 확인한다. 단계가 다르므로 그림의 태그를 제출했다고 이 항목들이 통과하지 않는다.
