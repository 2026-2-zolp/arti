# ARTI 팀 검수 · 이 문서부터 읽어 주세요

## 왜 하는 작업인가요?

ARTI는 취향에 맞는 작품을 추천하고, 작품해설·관람가이드에서 AI 도슨트 대화로 이어지는 서비스입니다. 기능 연결은 격리 환경에서 확인했고, 이제 실제 그림을 보았을 때 태그와 설명이 납득되는지 확인하려 합니다. 유영국 핵심 3점은 시연 콘텐츠를 점검하고, 여러 작가의 후보 21점은 전시와 별도로 사용할 취향 조사 그림을 고르기 위한 검토에 씁니다.

모델 점수나 다른 분의 답을 먼저 보면 첫 판단이 달라질 수 있어 아래 순서로 진행해 주세요. 애매한 판단과 개선 의견도 그대로 받습니다. 그림의 감상에 정해진 정답은 없습니다.

## 준비와 전체 순서

- Windows 탐색기에서 받은 ZIP을 우클릭하고 ‘모두 압축 풀기’를 선택합니다. 압축을 푼 폴더 안에서 실행합니다. 준비물은 PC의 Chrome 또는 Edge와 메모를 수정할 프로그램입니다. HTML은 브라우저로, MD는 메모장이나 VS Code로 열면 됩니다.
- 진행 순서는 **01 태그 → 02 후보 비교 → 03 콘텐츠 확인**입니다. 03 폴더는 01·02 결과 파일을 저장한 다음 열어 주세요.
- 임시 배정은 동섭님 R01·V1, 성현님 R02·V2, 광권님 R03·V1입니다. 다른 참여자는 준억님께 R04 이후 번호와 V1/V2 중 하나를 배정받습니다. 같은 사람이 여러 별칭이나 두 버전으로 중복 참여하지 않도록 합니다.
- 처음 그림을 본 적이 있거나 모델 결과·다른 사람의 답을 이미 본 적이 있어도 참여할 수 있습니다. 무엇을 미리 보았는지 메모와 화면의 사전 질문에 남겨 주세요.
- 팀이 밝힌 사용 범위는 교내 졸업프로젝트 기간입니다. 전달받은 그림과 응답은 팀 비공개 경로에서 다뤄 주세요.

## 01 · 유영국 3점의 태그 판단

1. `01_태그/labeling.html`을 Chrome 또는 Edge로 엽니다.
2. ‘검수자 별칭’에 배정된 R01 등의 번호를 입력합니다. ‘내부 동작 시험’ 체크는 비워 둡니다.
3. ‘이미지 선택’에서 `01_태그/images` 폴더 안의 PNG 3개를 모두 선택합니다. 화면에 이미지 3/3점 준비가 표시되는지 확인합니다. 파일을 브라우저로 끌어다 놓으면 다른 페이지로 이동할 수 있으니 선택 버튼을 사용해 주세요.
4. ‘판단 기준 먼저 읽기’를 펼칩니다. 풍경·인물·추상·빛·강렬한 색감·차가운 색감·따뜻한 색감·부드러운 색감 각각에 해당함/해당하지 않음/모르겠음을 고릅니다. 한 작품에 여러 태그가 해당할 수 있습니다.
5. ‘다음’으로 세 작품을 모두 확인합니다. ‘분위기 의견’은 원하는 경우에만 답합니다. 라벨 3/3점 완료를 확인하고 ‘JSON 내려받기 · 초안도 가능’을 누릅니다.
6. 브라우저 다운로드 목록(Ctrl+J) 또는 다운로드 폴더에서 `arti-labels-R01.json`처럼 본인 번호가 담긴 파일이 생겼는지 확인합니다. 이 파일은 보관한 뒤 다음 단계로 이동합니다.

자동 저장과 초안 재불러오기가 없는 도구입니다. 작업 중에는 탭을 유지하고 닫기 전 JSON을 저장해 주세요. 중단한 초안은 준억님께 함께 보내고, 다시 진행했다면 마지막 파일과 초안 중 어느 것이 최종인지 적어 주세요.

## 02 · 취향 조사 후보 비교

1. `02_후보비교` 폴더에서 배정된 `V1.html` 또는 `V2.html` 하나를 엽니다. 이미지는 화면에 포함돼 있습니다. 별도로 이미지 파일을 고를 필요가 없습니다.
2. 01과 같은 별칭을 입력하고 모델 결과·운영자 가설·다른 답의 사전 노출 질문에 사실대로 답합니다. ‘내부 동작 시험’은 비워 두고, 본인이 직접 답한다는 확인 항목을 읽고 체크합니다.
3. 그림 21점의 표시 상태와 익숙함을 답합니다. 너무 작거나 흐려 판단하기 어렵다면 해당 상태를 골라 주세요. 특징 메모는 선택입니다.
4. 그림 확인을 마치면 화면의 다음 단계 버튼으로 18쌍 비교를 진행합니다. 더 오래 보고 싶은 그림, 차이를 설명하기 쉬운 정도, 표시 품질의 영향을 답합니다. 둘 다 좋음/둘 다 선호하지 않음/고르기 어려움도 선택할 수 있습니다.
5. 끝나면 ‘완료 JSON 저장’을 누릅니다. 예를 들어 `arti-review-R01-V1-submitted.json` 파일이 생깁니다. 미응답 안내가 나오면 빠진 항목과 시작 전 확인을 채워 주세요.
6. 쉬었다 하려면 ‘초안 JSON 저장’을 누릅니다. 같은 V1/V2 파일을 다시 열고 ‘초안 JSON 불러오기’에서 저장 파일을 고르면 이어서 답할 수 있습니다. 파일 선택이 어려우면 ‘파일 선택이 어려우면 JSON 붙여넣기로 복원’을 펼쳐 저장 파일의 전체 내용을 붙여넣습니다.

21점·18쌍은 후보 검토 묶음입니다. 예상 15~25분은 실제 사람 소요 시간을 재기 전의 참고값입니다. 실제로 걸린 시간과 어려웠던 질문을 결과 메모에 적어 주세요. 다른 버전을 다시 풀 필요는 없습니다.

## 03 · 작품과 콘텐츠 확인

01·02 JSON을 저장한 뒤 `03_콘텐츠/검토할 내용.md`를 엽니다. 01에서 보았던 이미지와 작품 정보·해설·요약·질문·힌트를 대조합니다. 그다음 `03_콘텐츠/회신양식.md`를 복사해 본인 번호를 붙이고, 메모장이나 VS Code에서 작성·저장합니다.

작품별로 식별/해설/요약/가이드/출처·사용 근거에 대해 확인·수정·판단 보류를 남겨 주세요. 확인할 자료가 없으면 ‘판단 보류’와 필요한 자료를 적으면 됩니다. 광권님은 실제 캡처 URL 또는 캡처한 사이트와 당시 맥락을 아는 범위에서 적어 주세요. 소장품 참고 링크와 실제 캡처한 주소가 다르면 둘 다 기록합니다.

## 결과는 어떻게 보내나요?

아래 파일을 **준억님 개인 카카오톡에 파일로 첨부**해 주세요. JSON을 채팅 본문에 붙여넣으면 일부가 빠질 수 있으니 파일로 보내 주세요.

- `arti-labels-본인번호.json`
- `arti-review-본인번호-V1또는V2-submitted.json`
- 본인 번호를 붙인 `회신양식.md`

단계마다 끝난 파일을 먼저 보내도 됩니다. 함께 ‘R01 / 01 완료·02 초안·03 대기 / 사전 노출 내용 / 걸린 시간’처럼 진행 상태를 알려 주세요. 초안이나 수정 제출이면 어떤 파일이 마지막인지 적어 주세요. 원본 파일 이름과 내용을 유지하고, 새 의견은 새 파일로 남기면 준억님이 이전 의견과 함께 확인하겠습니다.

## 막히면 이렇게 해 주세요

- HTML이 글자로 열리면 우클릭 → 연결 프로그램 → Chrome 또는 Edge를 선택합니다.
- 01 이미지가 3/3으로 준비되지 않으면 압축을 푼 폴더의 PNG 3개를 골랐는지 확인합니다. 이미지 이름·크기·내용을 편집했다면 받은 ZIP에서 다시 풉니다.
- 계속 파일 확인 오류가 나면 화면 메시지와 사용 브라우저를 준억님께 보내 주세요. Python이 설치된 경우에는 압축을 푼 최상위 폴더의 주소 표시줄에 `powershell`을 입력하고, 열린 창에서 `python -m http.server 5199 --bind 127.0.0.1`을 실행한 뒤 `http://127.0.0.1:5199/01_태그/labeling.html`을 엽니다. 종료할 때는 그 창에서 Ctrl+C를 누릅니다.
- 다운로드 파일이 보이지 않으면 Ctrl+J에서 저장 위치를 확인합니다. 저장을 확인한 뒤 탭을 닫습니다.
- 애매한 태그는 모르겠음, 애매한 콘텐츠는 판단 보류로 남깁니다. 설명이 이해되지 않는 부분 자체도 개선 의견이니 그대로 적어 주세요.
