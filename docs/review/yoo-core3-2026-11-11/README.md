# 유영국 핵심 3점 검수와 인수 기준

TP4에서 격리 여정을 기술 검증했다. 이 문서는 실제 작품의 태그, 작품 식별, 해설과 이미지 사용 조건을 팀이 확인하는 순서다. [기존 16점 블라인드 절차](../yoo-2026-11-09/README.md)의 태그 정의와 원본 해시를 재사용한다. [취향 조사 5쌍 검수](../taste-survey-2026-11-10/review-protocol.md)는 별도 과업이다.

## 1차 · 독립 태그 검수

- 저장소 루트에서 `python scripts/build_yoo_core3_review.py`를 실행하면 `data/private/independent-review-20261111/core3-blind.zip`이 생성된다. 팀에는 ZIP만 먼저 건넨다. 작품 제목·해설·출처·모델 결과·기존 답변은 ZIP에서 제외했다.
- 검수자가 각자 작업하고 원본 응답을 먼저 고정한다. 기존 절차대로 3명 이상을 목표로 하고 프로젝트 범위 안에서 제3자 관점을 확보한다. 인원과 사전 노출을 기록하고, 노출 응답은 독립 응답과 구분해 해석한다.
- `python scripts/yoo_labels.py 응답.json --core3`으로 묶음 버전·ID·이미지 해시·완료 상태를 확인한다. TEST는 실응답에서 제외한다. 초안과 미응답은 보존하되 완료로 세지 않는다. 모르겠음과 미응답을 비해당에 합치지 않는다.
- 작품·태그별 해당/비해당/모르겠음/미응답 수와 유효 분모(해당+비해당)를 기록한다. 2/3처럼 분자·분모를 함께 제시하고 동점·불일치·유효 응답 부족은 보류한다. 모델 비교는 독립 응답 고정 후 진행한다. 핵심 3점은 기존 탐색에 사용됐으므로 이 검수로 모델 일반화 성능을 주장할 수 없다.

응답을 고정한 뒤 아래 표와 [해설·요약·가이드 v2 초안](../../operations/2026-11-09_유영국핵심3점_콘텐츠검수준비.md)을 함께 전달한다. 국립현대미술관 개별 소장품에서 제목·연도·관리번호를 재대조했다. 원본 캡처와 소장품의 동일성은 검수자가 구도·형태·색면을 함께 비교해 기록한다.

2차 회신은 작품별로 `인수 번호 / 검수자·날짜 / 항목 / 확인·수정·보류 / 근거 URL 또는 관찰 내용 / 수정안·남은 확인`을 남긴다. 식별과 콘텐츠 확인이 끝나도 사용 조건이 대기면 그 상태를 유지한다. 응답 JSON의 형식 통과는 검수 접수 단계이며 관리자 확정, 서비스 반영, 공개 여부는 사람 판단으로 남긴다.
