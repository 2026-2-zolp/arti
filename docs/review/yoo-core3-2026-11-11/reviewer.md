# 핵심 작품 3점 독립 태그 검수

1. 압축을 풀고 `labeling.html`을 브라우저로 엽니다. `images` 안의 세 파일을 한 번에 골라 3/3점이 준비됐는지 확인합니다. 로컬 파일에서 해시 확인이 안 되면 압축을 푼 폴더에서 `python -m http.server 5199 --bind 127.0.0.1`을 실행하고 `http://127.0.0.1:5199/labeling.html`을 엽니다.
2. 검수자 별칭을 입력하고 판단 기준을 읽습니다. 작품 설명, 모델 결과, 다른 사람의 답을 확인하기 전에 작품별 8개 태그에 해당함·해당하지 않음·모르겠음을 표시합니다. 작품 순서는 무작위입니다. 분위기 의견은 선택입니다.
3. 라벨 3/3점이 표시되면 JSON을 내려받습니다. 페이지를 닫기 전에 저장하세요. 시험 체크는 동작 시험에만 씁니다. 이미 작품이나 모델·다른 사람 결과를 본 경우, 별칭과 어떤 자료를 보았는지 결과와 함께 별도 메모로 남겨 주세요.
4. JSON과 메모는 교내 졸업프로젝트 기간의 팀 비공개 경로로 전달합니다. 이미지 묶음은 팀 밖 공유나 공개 업로드 없이 보관합니다. 내용·출처 검수는 독립 응답을 제출한 뒤 진행합니다.
