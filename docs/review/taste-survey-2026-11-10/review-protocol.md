# 운영자 진행·판정 절차

## 검수 시작 전

1. 현 묶음21점/18쌍·버전·manifest digest를 고정한다. 기준표를 고쳤으면 매핑 digest도 갱신하고,이미 받은 응답에 새 가설을 소급 적용하지 않는다. 운영자는 배정표에 별칭·버전·배정일·기기 종류·실제 사용 크기·사전 노출을 기록한다. 개인정보나 연락처는 응답 파일에 넣지 않는다.
2. 가능하면 팀 외 처음 보는 사람을 일부 포함한다. 소규모라도 가능한 인원과 실제 응답 수를 보고한다. 팀원 수·고정3명 등을 이번 도구 준비의 자동 통과 조건으로 만들지 않는다. 작성자·모델 결과 열람자·시험자는 실제 미노출 검수와 분리한다.
3. 처음 한두 명의 질문 이해도·소요 시간·기기 표시를 점검하는 준비 시험을 먼저 권한다. 이후 문구/이미지를 변경하면 새 묶음으로 구분한다. 시험/본 검수 범위와 모집 방식은 수집 전에 정한다.
4. V1/V2를 가능한 고르게 배정한다. 같은21점과18쌍을 쓰되 작품순서·쌍순서는 반대,좌우는 모두 교환한다. 이는 완전한 실험 설계나 위치 편향 제거를 보장하지 않는다. 같은 작품이 여러 쌍에 반복되어 학습/피로/순서 효과가 남는다.
5. 작품명·정답 태그·대비 의도·AI 결과를 말하지 않는다. 검수자가 묻는 경우 정답을 알려주지 않고 `잘 모르겠음` 또는 본인 의견으로 남길 수 있음을 안내한다. 가설에 맞추도록 답을 수정시키지 않는다.

## 수집·대조

- 생성된 HTML 하나만 전달하고 실제 응답은 Git 제외 비공개 폴더로 인수한다. 운영자 문서와 매핑은 같이 보내지 않는다. 원본 캡처·출처 조건에 따라 교내 프로젝트 범위를 지키며 인터넷 게시/배포를 승인한 것으로 보지 않는다.
- 응답 검사기로 manifest·버전·행수·순서·좌우·해시·값·완료 상태를 확인한다. `--allow-test`는 내부시험 전용이며 실제 집계에는 시험 응답을 넣지 않는다. draft·미응답·불확실은 각각 보존한다. submitted도 approved가 아니다.
- 같은 별칭·동일/유사 응답의 재제출 여부를 운영자가 확인한다. 자동으로 마지막 파일을 정답으로 덮어쓰지 않는다. 외부 노출·사람 독립성·동의/일정은 이 도구가 검증하지 못한다.
- 모델 결과를 대조하기 전 원 응답을 잠근다(원본 파일 보존·SHA256 기록). 분석용 사본에서만 익명 매핑을 연결한다. 결과 열람 후 수정 의견은 새 라운드로 남긴다.

## 무엇을 보고 어떻게 판단할 것인가

| 구분 | 보고 방법 | 금지할 해석 |
| --- | --- | --- |
| 표시 품질 | 각 이미지 adequate/limited/unsure의 인원·분모,자유메모;쌍의 표시영향 여부 | 화질이 낮아 밀린 작품을 취향이 없다고 단정 |
| 익숙함/노출 | known/unknown/unsure,세 가지 사전노출을 분리 | 같은 팀·미노출 자기신고를 독립성 증명으로 제시 |
| 개인 선호 | 좌우를 실제 코드로 환산해 각작품/둘다/둘다아님/어려움의 수와 분모 | 공동선호/기권 삭제,왼쪽 선택을 고정태그 정답으로 환산 |
| 대비의 설명 가능성 | clear/partial/little/unsure와 자발적 이유를 보존;운영자 가설과 일치/불일치/불명확을 사후 기록 | 가설과 불일치한 응답 제외,모델 점수로 자유응답을 정답 판정 |
| 반복·교란 | 같은작품의 다른쌍 결과,V1/V2 좌우·순서·화질·익숙함 차이를 원수와 함께 확인 | 적은 인원에서 통계적 유의/취향 정확도/일반화 주장 |

임의 만족도 퍼센트·자동 후보 랭킹은 이번 단계에서 만들지 않는다. 비율을 쓸 경우 `해당 응답 n / 유효 응답 N`과 기권/미응답·노출층을 함께 적고,선호 확률이나 모델 정확도로 부르지 않는다. 인원이 적으면 수와 개별 이견이 우선이다.

후보별 후속 상태는 `유지 검토/표시 교체 검토/비교쌍 재설계/자료 보강/판단 보류`처럼 근거를 붙인다. 자동 채택 기준이나 임의 점수 임계값은 정하지 않았다. **최종10점 결정은 출처·표시·다양성·응답 해석을 함께 검토하는 별도 작업**이다.

이번 묶음은 후보 대비/선호의 준비 도구다. CLIP·mDeBERTa의 태그 정확도를 재려면 별도 고정 정의에 따른 독립 라벨이 필요하다. 기존 유영국 라벨 도구를 이21점에 그대로 쓰거나 개인 선호를 태그 정답으로 바꾸지 않는다. 실제 추천 만족도 역시 사용자가 보지 않은 대상에 대한 별도 평가가 필요하다. 외부8점은 이미 탐색·노출되므로 이후 새 holdout으로 주장하지 않는다.
