# 취향 조사 후보 대비·블라인드 검수 준비

2026-11-10 / [이전 실제 점수 비교](../../execution-plan/2026-11-07/records/W07-preparation/survey-comparison-2026-11-10/README.md)의 후속이다. **후보21점·검토18쌍이며 최종 조사10점·5쌍이 아니다.** 실제 사람 응답은 아직 없고,선정·공개 활성화·모델 설정·DB는 변경하지 않았다.

## 자료를 읽는 순서

- 운영자: [후보별 대비 기준표](candidate-contrast-table.md) → [진행·판정 절차](review-protocol.md). 작품별 식별·출처·사용/표시 미확정과 쌍별 대비 가설·공통 특징·교란을 구분한다.
- 검수자: 아래에서 생성한 `V1.html` 또는 `V2.html` **하나만** 받는다. 이 README·기준표·matrix.json·manager-mapping.json·이전 모델 점수는 먼저 전달하지 않는다.
- 인수자: [응답 형식](reviewer-manifest.json), `scripts/survey_blind_review.py validate`와 [준비 검증](validation.json)을 확인한다. 제출 완료는 콘텐츠 승인·정확도 측정이 아니다.

앞13쌍은 이전 A/B/C 조사안의 중복을 제거했다. 뒤5쌍은 꽃/사과 정물·인물 시점·밝고 어두운 풍경·도시/자연·실내외 군상 등으로 검수 폭을 넓힌 **새 제안**이다. 이5쌍으로 새 모델/추천 측정을 한 것은 아니다. 현8태그에 정물·꽃·동물 선호를 강제로 대응시키지 않는다. 외부 추상·비서양/현대·매체 다양성은 여전히 보강 대상이다.

## 실행·전달

표준 Python 라이브러리만 사용한다. 추가 다운로드·모델 호출·GPT키·DB연결이 없다. 고정 원본21개는 Git 캡처9개·비공개 유영국1개·이전 외부 비교11개이며 신규 체크아웃은 비공개 원본을 별도 인수해야 한다. 누락/해시 불일치 시 생성하지 않고 실패한다.

```powershell
python docs/review/taste-survey-2026-11-10/verify.py
python scripts/survey_blind_review.py build --output data/private/survey-blind-review-20261110/new-pack
python scripts/survey_blind_review.py validate data/private/reviewer-response.json
# 내부 시험 응답에만 사용
python scripts/survey_blind_review.py validate data/private/TEST-response.json --allow-test
```

생성 목적지는 `data/private` 아래 **새 폴더**만 허용한다. 기존 응답/묶음 덮어쓰기는 거절한다. 생성물은 이미지가 내장된 HTML2개와 익명 manifest다. 운영자 매핑·가설·작품명·출처·AI점수·이전 답은 HTML에 넣지 않는다. 원본 바이트를 바꾸거나 색·크롭을 보정하지 않으며 이미지 자체/서명/메타데이터/유명도에 의한 식별 가능성은 남는다. 완전한 작품 신원 은폐가 아닌 **모델 결과·예상 답 비노출**이다.

로컬 생성 완료본: `data/private/survey-blind-review-20261110/pack-v2/V1.html`, `V2.html`. 파일을 브라우저에서 직접 열어도 동작하도록 외부 자원을 쓰지 않는다. 이번 실제 UI 시험은 localhost Chrome으로 했다. Git에 이미지 내장 HTML이나 실제 응답을 추가하지 않는다. 저장소에는 재생성 도구·틀·기준/코드 매핑만 남는다.

## 검수자 사용법

1. 운영자가 익명 별칭(R01 등)과 V1/V2 중 하나를 배정한다. 이름·연락처는 넣지 않는다. 같은 사람이 두 버전을 작성해 사람 수를 늘리지 않는다.
2. 모델 결과·운영자 가설·다른 답을 이미 보았는지 `예/아니요/불확실`로 각각 남긴다. 이미 본 사람도 기록할 수 있으나 미노출 독립 응답과 구분한다.
3. 그림21점의 표시 상태·익숙함을 확인한다. 특징 메모는 자유 선택이다. 예상 태그나 모델 점수는 표시하지 않는다.
4. 쌍 비교18개에서 더 오래 보고 싶은 그림·차이를 설명하기 쉬운 정도·표시 상태 영향을 남긴다. `둘 다 비슷하게 좋음/둘 다 선호하지 않음/고르기 어려움`이 가능하며 기본 선택은 비어 있다. 강제로 승자를 만들지 않는다.
5. 초안 또는 완료 JSON을 직접 저장한다. 자동 저장/서버 전송은 없다. 탭을 닫기 전에 저장하고 실제 파일 존재를 확인한다.
6. 파일 선택 또는 저장 JSON 붙여넣기로 같은 버전 초안을 복원할 수 있다. 다른 버전·순서·이미지해시·변조 값은 거절하고 기존 화면 응답을 유지한다. 파일 접근을 위해 브라우저 보안 설정을 바꿀 필요는 없다.
7. 결과 파일은 별도 비공개 경로로 인수한다. 이 작업에서 팀원에게 자동 발송하거나 응답을 수집하지 않았다.

15~25분은 준비용 예상이며 실제 사람 소요 시간은 미측정이다. 피로하면 초안으로 나누고,먼저 소규모로 질문 이해도·표시 크기·실제 소요 시간을 점검한다.

## 실제 검증과 한계

Chrome에서57개 이미지(단독21+쌍36) 로드,기본 미선택,그림 확인 전 다음단계 잠금,미완료 제출 차단,21점 후18쌍 진입,시험 초안·완료 JSON 다운로드와 Python 검사 통과,붙여넣기 초안 복원·다른 버전 거절을 확인했다. 확장 파일 선택 API는 로컬 파일 권한 제한으로 검증하지 못해 보안 설정을 변경하지 않고 붙여넣기 복원 경로를 추가·확인했다. 모바일 실기기·실제 사람 응답/사용성 검증은 별도다.

기술/시니어·방문자·운영/데이터·팀/교수/외부 평가위원 관점의 **작성자 자체검토**이며 독립 평가자 검수가 아니다. 준비 통과와 사람 품질 인수는 구분한다. 다음은 동점 단독 정책 계약(누락·동일점수·버전·사용자 수정·기존저장호환)이다. 검수 회신 수집은 병렬로 가능하며 최종 선정과 공개 활성화는 별도 결정이다.
