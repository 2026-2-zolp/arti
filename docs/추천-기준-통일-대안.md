## 문제: 같은 작품을 두 벌의 단어로 설명하고 있다

```text
사용자 카드:  빛, 고요한 풍경, 강한 색감, 부드러운 색감, 감정 표현, 추상적 형태  ┐ 같은 단어
관리자 태그:  (위와 같은 6개)                                              ┘
AI 분석:     평온, 기쁨, 슬픔, 긴장, 경외, 그리움                            ← 다른 단어
                    ↑ 둘을 잇는 것은 개발자가 정한 변환표("빛 = 기쁨 0.7 …") 하나뿐 → 근거가 약함
```

- 태그 = 그림이 **어떻게 생겼나** (색·형태·소재) / 감정 = 그림을 보면 **어떤 기분이 드나**
- 그래서 이름만 맞추는 게 아니라 **어느 쪽 단어로 통일할지**를 정해야 한다.
- 현재 AI는 태그를 대신 골라 주지 않는다. 태그(관리자)와 감정 점수(AI)는 따로 저장된다.

## 대안 A · B · C

| | A. 감정으로 통일 | **B. 태그로 통일 (추천)** | C. 둘 다 유지 + AI가 둘 다 분석 |
|---|---|---|---|
| 사용자 카드 | "평온한 작품", "기쁜 작품" … 6개로 변경 | 그대로 (빛, 강한 색감 …) | 그대로 |
| 관리자 태그 | 감정 6개 | 그대로 | 그대로 |
| AI가 분석하는 것 | 감정 6개 (지금 그대로) | **태그 6개를 0~1 점수로** | 태그 6개 + 감정 6개 |
| 변환표 | 필요 없음 | 필요 없음 | 필요 없음 |
| 화면 설계서 U-05 | ❌ 카드 내용 변경 | ✅ 그대로 | ✅ 그대로 |
| 감정 정보 | 추천에 직접 사용 | 추천에서 빠짐 | 추천은 태그, 감정은 설명·영수증용 |

**추천: B를 기본으로, 감정은 설명용으로 남기기(= C)**
1. 사용자·관리자·AI가 같은 단어 6개를 써서 변환표 없이 바로 비교 → 임의로 정한 값이 사라짐
2. CLIP은 '그리움' 같은 감정보다 색·형태·풍경 같은 겉모습을 더 잘 맞힐 가능성이 큼 (노트북으로 검증 필요)
3. "태그 고르기 귀찮으면 AI가 대신" → AI가 태그 점수를 「AI 제안」으로 채우고 관리자는 확인만
4. 화면 설계서 U-05를 바꾸지 않아도 됨
5. 감정 분석은 U-10 "이 작품의 분위기", U-12 아트 영수증 해석에 계속 사용

> 팀 설계서에 "감정 기반 추천"이 명시돼 있다면 A가 설계 의도에 더 가까울 수 있으니 먼저 확인.

## B의 세부 설계

**작품에 저장되는 것:** 태그 6개 각각의 점수(0~1). 예) 「수련」 고요한 풍경 0.85 · 부드러운 색감 0.80 · 빛 0.70 · 추상적 형태 0.30 · 강한 색감 0.15 · 감정 표현 0.10

**AI 태그와 관리자 태그의 관계** — AI가 초안, 관리자가 확정 (감정 분석과 같은 흐름)

```text
「AI 분석」 → AI가 태그 점수 6개 → 「AI 제안」 (점수 높은 태그는 버튼이 미리 켜짐)
          → 관리자가 그대로 두거나 켜고/끄고 → 「확정」 → 최종 태그 점수 저장
```

| 상황 | 최종 점수 |
|---|---|
| AI 점수 그대로 둠 | AI 점수 (예: 빛 0.70) |
| 관리자가 켬 | 1.0 |
| 관리자가 끔 | 0 |
| AI 분석 없이 관리자가 버튼만 고름 | 켠 태그 1.0, 나머지 0 (현재 방식과 같음) |

**추천할 때 실제로 쓰는 것**

| 작품 상태 | 태그 점수는 어디서 오나 | 추천 점수 |
|---|---|---|
| AI 태그 분석 ✅ + 관리자 확정 ✅ | AI 점수, 관리자가 고친 태그는 켬 1.0 / 끔 0 | 고른 카드의 태그 점수 평균 |
| AI 태그 분석 ✅ + 아직 확정 안 함 | 관리자가 켠 태그만 1.0 (AI 제안은 아직 안 씀) | 고른 카드의 태그 점수 평균 |
| AI 분석 없음 + 관리자가 태그 고름 | 관리자가 켠 태그 1.0, 나머지 0 | 고른 카드의 태그 점수 평균 (현재와 같음) |
| 둘 다 없음 | 전부 0 | 0점 |

감정 분석은 이 표에 들어가지 않음 (설명·영수증 전용).

**예시** (사용자: 「빛」+「고요한 풍경」)

| 작품 상태 | 태그 점수 | 추천 점수 |
|---|---|---|
| 수련: AI 분석 + 확정 | 빛 0.70, 고요한 풍경 0.85 | 0.78 |
| 수련: 확정 전, 관리자가 「고요한 풍경」만 켬 | 빛 0, 고요한 풍경 1.0 | 0.50 |
| 수련: AI 없음, 관리자가 둘 다 켬 | 빛 1.0, 고요한 풍경 1.0 | 1.00 |
| 아무것도 없음 | 0, 0 | 0 |

- 어떤 경우든 **계산식이 하나**(고른 카드의 태그 점수 평균)이고, 태그 점수의 출처만 다름
- 관리자가 직접 켠 태그(1.0)는 AI 점수보다 높아 사람이 확인한 작품이 약간 유리 — 의도된 우선순위
- "성격이 다른 카드마다 최소 1점 보장"은 유지, 추천 이유는 "빛 · 고요한 풍경이 돋보이는 작품"
- 관람 순서(동선)는 지금처럼 고른 작품을 입구에서 가까운 순서로 정렬

**바뀌는 것 요약**

| | 현재 | B 적용 후 |
|---|---|---|
| 태그 | 관리자가 켜고 끔 (1/0) | AI가 점수 제안 → 관리자 확정 (0~1) |
| 추천 기준 | 감정 70% + 태그 30%, 변환표 필요 | 태그 점수만, 변환표 없음 |
| 임의로 정한 값 | 변환표, 70/30 비율 | 사라짐 (태그를 켤 기준값 하나만 남음) |
| 감정 분석 | 추천 + 설명 | 설명만 |

**적용할 때 할 일:** AI 서버에 태그 6개용 CLIP 문장 추가(예: 빛 = "a painting with dramatic light and luminous colors") · 관리자 화면에 AI 태그 점수와 「AI 제안」/「확정」 · 검증 노트북에 태그 정확도를 감정과 비교하는 장 추가
