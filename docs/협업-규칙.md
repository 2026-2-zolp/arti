## 한 줄로 기억하기

**`main`은 모두가 공유하는 기준본, `dev/이름`은 개인 작업공간, PR은 `main`에 합치기 전에 변경 내용을 서로 확인하는 과정**입니다.

```text
Notion에서 맡은 작업 확인
      ↓
내 dev/이름 브랜치에서 개발·테스트
      ↓
커밋 + 개인 브랜치에 push
      ↓
PR 작성 (base: main / compare: dev/내이름)
      ↓
다른 팀원이 확인 → main 병합
      ↓
다음 작업 전 개인 브랜치에 최신 main 반영
```

## 브랜치 구분

| 브랜치 | 무엇을 하나요? |
| --- | --- |
| `main` | 팀 공통 통합본. **직접 push하지 않고 PR로 합치는 것**을 팀 규칙으로 적용 |
| `dev/임준억` | 임준억 개인 작업 |
| `dev/김광권` | 김광권 개인 작업 |
| `dev/지성현` | 지성현 개인 작업 |
| `dev/김동섭` | 김동섭 개인 작업 |

각 브랜치에는 저장소 전체가 들어 있습니다. 다른 파트를 절대로 수정하면 안 된다는 뜻이 아니라, **자기 브랜치의 수정 내용을 팀이 확인하고 합치기 위한 구분**입니다.

## 커밋과 PR 작성

**영어 유형 + 한국어 작업 내용**으로 제목을 씁니다.

| 유형 | 예시 |
| --- | --- |
| `feat` 기능 추가 | `feat: 작품 취향 선택 화면 구현` |
| `fix` 오류 수정 | `fix: 지도 마커 위치 표시 오류 수정` |
| `docs` 문서 작성 | `docs: 작품 출처 검수 기준 정리` |
| `refactor` 코드 개선 | `refactor: 추천 API 응답 처리 함수 분리` |
| `chore` 설정·유지보수 | `chore: 개발 환경 설정 보완` |
| `test` 테스트 | `test: 작품 조회 API 테스트 작성` |

- PR 제목·본문·리뷰도 **한국어**로 씁니다. 고유 기술명·코드명은 그대로 사용해도 됩니다.
- PR에는 **변경 내용 / 확인 방법 및 결과 / 참고·미완료 사항**을 적습니다.
- 화면 작업이면 가능하면 화면 캡처, 서버 작업이면 간단한 요청/응답 또는 실행 방법을 함께 남깁니다.
- **Issue 등록은 선택사항**입니다. 작업 담당·일정은 Notion을 기준으로 관리합니다. PR에는 관련 Notion 작업 링크가 있으면 남깁니다.

## 개인 브랜치에서 `main`으로 합치기

1. 새 작업 전 개인 브랜치에서 `git fetch origin`, `git merge origin/main`으로 최신 통합본을 받아옵니다.
2. 자신의 브랜치에서 수정·테스트·커밋하고 원격에 push합니다.
3. PR 작성 시 **base: `main` / compare: `dev/본인이름`**인지 확인합니다.
4. **PR 작성자 외 팀원 1명이 변경 내용·실행/검증 결과를 확인**합니다. 문제가 없다면 PR 작성자가 병합합니다. 급한 예외는 팀에 공유합니다.
5. PR 병합 후 개인 브랜치에도 최신 `main`을 다시 반영합니다.

**장기 개인 브랜치를 재사용하기 때문에 초기에는 `Create a merge commit`을 권장합니다.** `Squash and merge` 후 과거 커밋이 개인 브랜치에 남으면 다음 PR에 이전 내용이 섞일 수 있으므로 정리 방법을 합의한 뒤 사용합니다. 강제 푸시·브랜치 초기화는 개인 작업이 사라질 수 있어 주의합니다.

> **중요:** 위 내용은 팀 협업 규칙이며, GitHub 서버에서 직접 push를 기술적으로 차단하는 **브랜치 보호 설정이 적용됐다는 뜻은 아닙니다.** 별도 관리자 설정이 필요합니다.

## 코드 및 데이터 주의사항

- API 키, `.env`, 비밀번호, 개인정보, 미허가 작품 이미지를 커밋하지 않습니다.
- 실제 전시 소속, 이미지 사용권, 공식 해설, 지도 좌표의 실제/모의 여부를 구분합니다.
- 프론트·백엔드 사이 ID·API 규격을 변경한다면 미리 협의합니다.
- AI가 생성한 설명을 검증된 공식 정보인 것처럼 보여주지 않습니다.
- 실행 방법이나 의존성이 바뀌면 해당 폴더 README를 함께 갱신합니다.
