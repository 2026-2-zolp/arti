# ARTI 🎨

가천대학교 2026학년도 2학기 졸업프로젝트 팀입니다.

**ARTI는 미술 감상 초보자가 작품을 더 쉽게 발견하고, 이해하고, 자신의 방식으로 감상할 수 있도록 돕는 AI 기반 미술관 관람 어시스턴트**를 만들고 있습니다.

### 만드는 경험
- 전시 입구 QR/URL을 통한 간단한 시작
- 선호 작품·관람 시간에 맞춘 추천과 추천 이유
- 2D 전시 지도·추천 관람 순서
- 출처가 확인된 작품 해설과 관찰 질문(Guided Looking)
